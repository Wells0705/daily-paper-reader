## 摘要
多模态大语言模型（MLLM）能够整合长视觉历史，在部分可观测性下推理，并从少量示例中推断行为。然而，视觉-语言-动作（VLA）模型通常继承预训练表示，而不将这种上下文能力用作情节记忆。依赖记忆的策略通过专门构建的历史机制来解决这一差距。PonderPounce则重新利用MLLM的原生因果上下文作为机器人记忆。Ponder，一个System2 MLLM，在其原生因果上下文中累积情节观察、演示和先前认知，并可以生成子目标文本和演示推理供内部使用。Pounce，一个System1 VLA，直接接收当前观察、指令和本体感觉；通过Ponder-Pounce接口，它异步仅接收最新的连续认知令牌及其年龄。两者无需专门构建的记忆模块或单独的桥接预训练即可端到端联合训练。优化后的服务实现了认知刷新78毫秒和动作模型调用25毫秒的p50延迟，支持20Hz动作回放。在RoboMME上，使用基础规模训练数据，PonderPounce在相同Pounce架构和接口下，9B达到60.83%，0.8B达到50.04%，而FrameSamp+Modul为44.51%，当前观察π_{0.5}为17.93%。使用9倍数据，达到75.54%，而FrameSamp+Modul为57.88%。在RoboCasa-DC上，相同接口仅从动作监督中学习，达到12.5%，而最强的已发表演示条件基线为11.6%，当认知被学习的空状态替代时降至8.6%。

## Abstract
Multimodal large language models (MLLMs) can integrate long visual histories, reason under partial observability, and infer behavior from a few examples. Yet vision-language-action (VLA) models generally inherit pretrained representations without using this contextual capacity as episode memory. Memory-dependent policies address this gap through purpose-built history mechanisms. PonderPounce instead reuses an MLLM's native causal context as robot memory. Ponder, a System2 MLLM, accumulates episode observations, demonstrations, and prior cognition in its native causal context and can generate subgoal text and demonstration reasoning for internal use. Pounce, a System1 VLA, receives the current observation, instruction, and proprioception directly; through the Ponder--Pounce interface, it asynchronously receives only the newest continuous cognition token and its age. Both are jointly trained end to end without a purpose-built memory module or separate bridge pretraining. Optimized serving achieves p50 latencies of 78ms for cognition refresh and 25ms for action-model invocation, supporting 20Hz action playback. On RoboMME with base-scale training data, PonderPounce reaches 60.83% with 9B and 50.04% with 0.8B under the same Pounce architecture and interface, versus 44.51% for FrameSamp+Modul and 17.93% for the current-observation π_{0.5}. With 9x data, it reaches 75.54% versus 57.88% for FrameSamp+Modul. On RoboCasa-DC, the same interface learns from action supervision alone and reaches 12.5% versus 11.6% for the strongest published demonstration-conditioned baseline, falling to 8.6% when cognition is replaced by a learned null state.

## 一、论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：机器人的操作控制常常依赖于当前观测中不存在的信息，例如被遮挡的物体、先前发生的事件、指代对象的身份，或是演示过的操作流程。这一类"上下文依赖型"控制（如长时程记忆、测试时演示条件化）对 VLA（Vision-Language-Action，视觉-语言-动作）模型构成挑战。
- **现有方法的不足**：
  - VLA 模型虽然继承了视觉和语言预训练表示，但通常**不会**将 MLLM（Multimodal Large Language Model, 多模态大语言模型）的上下文能力用作情节记忆（episode memory）；
  - 现有记忆增强策略大多依赖**专门构建的记忆机制**，如帧采样、存储与检索、压缩、交叉注意力、中间规划图等，架构复杂且需专门设计。
- **总体含义**：论文提出一种全新设计思路——**直接复用预训练 MLLM 的原生因果上下文（native causal context）作为机器人记忆**，通过一个异步的双系统架构免去专门记忆模块，使慢速推理系统（System 2）与快速动作系统（System 1）解耦运行。

## 二、论文提出的方法论：核心思想、关键技术细节

### 1. 核心思想：双系统（Dual-System）架构

- **Ponder（System 2，慢思考）**：一个 9B 参数量（或 0.8B）的预训练 MLLM（默认基于 Qwen3.5-9B）。它维护一个仅追加（append-only）的因果上下文，包含指令、演示片段、历史观测以及此前生成的认知状态，并据此产生子目标文本（subgoal text）和演示推理（demonstration reasoning），但这些文本仅限内部使用，不直接进入动作模型。
- **Pounce（System 1，快行动）**：一个预训练 VLA 动作模型（RoboMME 上为 π0.5 3.6B，RoboCasa-DC 上为 GR00T N1.5 3B）。它仅接收当前观测、指令、本体感觉，以及通过接口异步到达的**最新连续认知 token 及其"年龄"（age）**，直接输出动作块（action chunk）并以 20Hz 回放。
- **关键接口设计**：Ponder 每次查询会产出 K 个载体状态（carrier states，K=1），形成认知向量 Ct；Pounce 以 `[年龄编码, 认知投影]` 的前缀形式注入该向量。若尚无认知就绪，则使用可学习的零状态（null state）。

### 2. 关键技术细节

- **上下文路由**：Ponder 有独立的查询节奏，每约 1 秒追加当前观测、预测一个转移门（transition gate）Tt∈{TYes, TNo}。当需要时生成内部子目标文本 St 和（在演示情节首次执行转移处）演示推理 DR，随后通过载体位置的隐藏状态直接形成认知 Ct，无需解码或池化。
- **联合训练**：两个预训练组件**端到端联合训练**，无需桥接预训练或专门记忆模块。损失为：
  - L = w₁L_fm + w₂L_ground
  - L_fm 为动作 flow-matching 均方误差（仅通过认知向量回传至 Ponder）；
  - L_ground 为 LM 头的 token 交叉熵（监督转移门、子目标文本、演示推理）。
  - 在无标注的 RoboCasa-DC 上，设置 w₂=0，仅用动作监督训练。
- **梯度缩放**：因多次 Pounce 调用会引用同一个认知状态，动作梯度可能压倒 LM 头梯度，故将进入 Ponder 的动作梯度缩放为 0.5。
- **异步调度**：Ponder 和 Pounce 使用**独立时钟**，Pounce 在每次调用时选择最新已就绪的认知状态，并计算其年龄差；训练时通过 log-normal 分布采样间隔和计算延迟，使模型在多种年龄下暴露。
- **推理优化**：
  - 使用 Append-only StaticCache 避免重编码历史上下文，实现认知刷新 p50 延迟 **78ms**、45-token 子目标解码 p50 **820ms**；
  - 融合 Triton 内核将 Pounce 调用延迟从 142ms 降至 **25ms**（5.7× 加速），支持 1Hz 模型时钟 + 20Hz 动作回放。

## 六、论文的主要结论与发现

1. **原生 MLLM 上下文可作为强效通用记忆基底**：以 RoboMME 基准计，1× 数据下 60.83%（vs. 最强基线 44.51%）、9× 数据下 75.54%（vs. 57.88%），证明无需专门记忆模块即可使记忆信息有效作用于控制。
2. **更大规模的 System 2 容量能直接改善控制**：在控制器架构和接口不变的情况下，9B 预训练上下文引擎（60.83%）比 0.8B（50.04%）高出 10.79pp；预训练初始化至关重要（随机初始化不收敛）。
3. **认知通道确实承载了任务相关状态**：将认知替换为零状态使 RoboCasa-DC 成功率从 12.5% 降至 8.6%；冻结认知仅在转移时更新使 RoboMME 成功率降至 1.83%，说明控制器高度依赖及时的认知刷新。
4. **LM 头接地（grounding）有助于下游控制**：去除演示推理目标使成功率从 60.83% 降至 48.21%，完全去除 LM 头监督则降至 27.96%；但接地并非必要条件——RoboCasa-DC 在无任何文本监督时认知仍显著影响控制。
5. **刷新鲁棒性与即时拟合存在权衡**：用更慢的刷新间隔训练可使模型对陈旧认知更鲁棒（4.3s 年龄下归一化损失从 9.22× 降至 1.14×），但会牺牲新鲜状态下的拟合质量。
6. **连续认知接口与子目标文本接口精度相当**：两者相差 0.87pp（60.83% vs. 59.96%，小于运行间波动 2.63pp），连续通道在精度上具有竞争力而非绝对优势。
7. **并非所有任务类型都同样受益**：PonderPounce 在 Permanence（永存性）和 Reference（指代）任务上显著领先，但 FrameSamp+Modul 在 Imitation 类任务和 9× Counting 上仍保持优势——原生上下文利于隐藏状态跟踪和指代消解，而直接帧复用对模仿仍重要。

## 七、优点

- **概念创新的简洁性**：直接复用 MLLM 的原生因果上下文作为记忆，免去采样器、检索库、压缩器、交叉注意力等专门记忆机制，架构更加优雅。
- **异步双系统解耦**：Ponder 的容量、刷新频率和模型规模可独立于控制器扩展，无需修改 Pounce 架构即可升级记忆能力，具有清晰的可扩展路径。
- **端到端联合训练**：无需专门桥接预训练；文本目标仅用于接地 Ponder 的 LM 头，不污染控制器输入，保持了系统设计的纯度。
- **工程落地意识强**：推理优化措施具体而有效（StaticCache、融合 Triton 内核），且报告 p50/p95 延迟与可持续频率，给出的 20Hz 动作回放能力具备实际部署参考价值。
- **分析深度较好**：不仅报告基准分数，还围绕"认知通道到底编码了什么"进行了针对性干预实验（持有状态、陈旧度诊断、规模对比、随机初始化对比），有系统性的实证探索意识。

## 八、不足与局限

- **监督不公平性**：RoboMME 的子目标/演示推理由模拟器模板生成，PonderPounce 独享该监督信号，对比基线未获同等文本监督，两者的性能差距混杂了架构差异与监督差异；标注生产成本亦未量化。
- **评估范围有限**：仅两个仿真基准（RoboMME 与 RoboCasa-DC），缺乏真实机器人实验验证；RoboCasa-DC 绝对成功率低（12.5%），仅能视为接口迁移的初步证据而非跨体现泛化的广泛证明。
- **认知载体宽度受限**：仅验证 K=1（单一认知载体），未探索宽度扩展的影响。
- **上下文长度受限**：append-only 上下文局限于 16K token，在更长时程任务上的可扩展性未知。
- **某些分析是诊断性而非结论性**：
  - 陈旧度实验是 teacher-forced 离线损失，不是闭环成功率测量；
  - "仅转移时刷新"的干预并未针对稀疏传输进行训练，不能排除其可行性；
  - 认知与年龄同时变化，两者贡献无法分离。
- **随机初始化实验不收敛**，无法在匹配优化条件下隔离预训练收益，削弱了关于预训练必要性的论证强度。
- **算力开销偏高**：9B 上下文模型 + 3–3.6B 动作模型的组合带来了额外训练与推理成本；延迟 profile 描述的是 batch-1 调用而非并发吞吐。
- **干预实验机制未完全打开**：论文确认"认知确实影响控制"，但 Ponder 表示层的具体编码内容以及 Pounce 如何使用它仍是黑盒，有待表征探测研究。
