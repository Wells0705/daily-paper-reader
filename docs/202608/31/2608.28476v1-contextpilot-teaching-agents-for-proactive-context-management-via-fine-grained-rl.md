## 摘要
长 horizon 的智能体任务要求大型语言模型（LLMs）在多轮交互中迭代地检索、整合和维护分散的信息，但保留所有交互历史会导致工作上下文不断增长。最近的主动上下文管理方法允许模型使用专用工具编辑其自身的工作上下文，但仍面临三个关键限制：（1）工具集有限，仅限于搜索、删除和摘要，不支持全局规划、长期记忆和自适应压缩；（2）探索效率低下，将上下文管理动作视为同质，尽管它们对最终结果的影响各不相同；（3）粗粒度的信用分配，在强化学习中将最终的轨迹级奖励分配给所有中间的上下文编辑动作。为弥合这些差距，我们引入了 ContextPilot，一个用于长 horizon 智能体推理的主动上下文管理框架。我们的方法系统地扩展了工具集，增加了规划、长期记忆和软上下文卸载工具。我们进一步提出了一种针对上下文管理定制的强化学习方法，该方法利用上下文和熵的变化来识别关键编辑决策以进行分支采样，并从所有经过相应上下文编辑动作的分支轨迹中估计动作级优势。在长上下文问答和深度搜索任务上的实验表明，ContextPilot 在更紧凑的工作上下文下实现了更强的性能，在各种基础模型和基准测试中持续优于现有基线。代码可在 https://github.com/Tencent/ContextPilot 获取。

## Abstract
Long-horizon agentic tasks require large language models (LLMs) to iteratively retrieve, integrate, and maintain dispersed information across multi-turn interactions, but preserving all interaction histories leads to a continuously growing working context. Recent proactive context management methods allow models to edit their own working context with specialized tools, yet they still face three key limitations: (1) a limited toolset restricted to search, deletion, and summarization, with no support for global planning, long-term memory, and adaptive compression; (2) inefficient exploration that treats context management actions uniformly despite their heterogeneous impacts on final outcomes; and (3) coarse-grained credit assignment that assigns the final trajectory-level reward to all intermediate context editing actions during RL. To bridge these gaps, we introduce ContextPilot, a proactive context management framework for long-horizon agentic reasoning. Our approach systematically augments the toolset with planning, long-term memory, and soft context offloading tools. We further propose an RL method tailored for context management, which uses context and entropy variation to identify critical editing decisions for branch sampling and estimates action-level advantages from all branched trajectories that pass through the corresponding context editing action. Experiments on long-context QA and deep search tasks show that ContextPilot achieves stronger performance with a more compact working context, consistently outperforming existing baselines across various base models and benchmarks. Code is available at https://github.com/Tencent/ContextPilot.

## 2. 方法论

### 2.1 核心思想
将上下文管理视为一种需要全局规划、记忆维持和灵活卸载的“元任务”，并针对其特殊性设计专用的强化学习训练策略。

### 2.2 上下文管理工具集设计（Table 1）
- 在 StateLM 基础工具上新增三类工具：
  - **规划与感知**：`plan`（提出简洁计划）、`analyzeText`、`checkBudget`；
  - **长期记忆**：`memorize`（抽取实体/时间/事件片段并建立关联）、`updateMemory`、`readMemory`；
  - **软上下文卸载**：`summarizeContext`、`compressContext`（用 LLMLingua-2 压缩）、`foldHistory`（折叠历史为关键词+摘要，可检索恢复）。
- 上下文编辑类工具（如删除、摘要、压缩、记忆写入/更新）会把轨迹切分为“快照”（snapshots），供细粒度训练使用。

### 2.3 SFT 数据合成
- 使用 Qwen3.5-397B-A17B 作为教师模型，配合一个“上下文管理 harness”进行轨迹生成。
- harness 提供**动态工具可见性**（仅满足前置条件时展示）、**错误提示与重试机制**（无效参数、未按要求调用等），但这些提示只作为生成脚手架，最终从 SFT 轨迹中剔除。
- 三层过滤：结果过滤（正确性，可重试两次）、基于 GPT-OSS-120B 的过程过滤（清理不当管理行为）、峰值上下文长度过滤（≤32K）。
- 最终得到 3,068 条合格轨迹，切分为 51,469 个快照（见 Table 6）。

### 2.4 强化学习：上下文感知部分展开 + 细粒度信用分配
- **上下文感知部分展开（Context-Aware Partial Rollout）**：
  - 对每个上下文管理动作计算两类指标：
    - 上下文变化：\(\Delta C^{cm}_t = \frac{len(c^{cm}_{t+1}) - len(c^{cm}_t)}{len(c^{cm}_t)}\)
    - 熵变化：\(\Delta H^{cm}_t = H^{cm}_t - H^{initial}\)（熵为生成 k 个 token 的平均熵，以初始熵为参考，避免局部波动干扰）
  - 敏感度得分：\(S(a^{cm}_t) = \alpha \cdot \Delta C^{cm}_t + \beta \cdot \Delta H^{cm}_t\)（实验取 α=β=1）
  - 先做轨迹级 rollout 得到 M 个快照；若总快照预算 N=128 未满，则按敏感度排序，取前 N−M 个动作作为分支点，额外采样子轨迹，将更多探索预算分配给影响更大的操作。
- **细粒度信用分配（Fine-Grained Credit Assignment）**：
  - 对终止快照计算奖励：\(R(S_M) = R_{out} + R_{fmt} + R_{pen}\)（结果奖励 + 格式奖励 + 惩罚项）；
  - 对中间快照 \(S_i\)，取其所有后续终止轨迹的奖励均值：\(R(S_i) = \frac{1}{|\mathcal{T}(S_i)|}\sum_{T \in \mathcal{T}(S_i)} R(T)\)；
  - 在同一 query 的快照组内进行标准化，得到优势：\(\hat{A}^{(j)}_t = \frac{R(S^{(j)}_t) - mean}{std}\)；
  - 使用 GRPO 目标优化，将每个快照视为独立样本。
- **理论支撑**：附录 A 证明该估计器相对于轨迹级信用分配具有更低方差（\(\sigma^2/n_S\) vs \(\sigma^2\)），且仍保持无偏性。
