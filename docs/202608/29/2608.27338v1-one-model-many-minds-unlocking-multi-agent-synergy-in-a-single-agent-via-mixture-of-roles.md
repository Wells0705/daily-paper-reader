## 摘要
将大型语言模型（LLMs）特化以赋予不同能力，是从个性化助手到多智能体系统（MAS）等成功应用的基础。单智能体范式依赖预定义的角色或引导向量来实现特化，但它们强加了一个固定的特化，无法适应多样化的查询。相反，MAS通过编排具有不同基于文本角色的智能体来实现动态的多视角问题求解，但融合这些特化需要多轮交互，这增加了上下文长度和推理成本。为了解决这些限制，我们提出了角色混合（MoRe），它将多个特化自适应地组合成单个引导向量，用于单轮推理。具体来说，MoRe学习一个多样化的引导向量码本，每个向量编码一个潜在角色。一个查询感知的路由器动态地将码本融合为一个包含多个角色的引导向量。通过用组合后的向量引导骨干LLM，MoRe在单智能体、单轮推理过程中实现了多视角特化。所提出的MoRe可以通过三阶段SFT课程和GRPO后训练高效地训练，而骨干LLM保持冻结。在推理和人格基准上的实验表明，MoRe平均比单智能体基线高出2.2%，并实现了与MAS相当的性能，同时将token成本降低了20倍。

## Abstract
Specializing Large Language Models (LLMs) toward distinct abilities underpins successes ranging from personalized assistants to multi-agent systems (MAS). Single-agent paradigms rely on pre-defined personas or steering vectors to induce specialization, yet they impose a single fixed specialization that fails to adapt to diverse queries. Conversely, MAS achieves dynamic multi-perspective problem solving by orchestrating agents with distinct text-based roles, but fusing these specializations requires multi-turn interactions that inflate context length and inference cost. To address these limitations, we propose Mixture of Roles (MoRe), which adaptively composes multiple specializations into a single steering vector for single-turn inference. Specifically, MoRe learns a diversified codeboox of steering vectors, each of which encodes a latent role. A query-aware router dynamically fuses the codebook into a steering vector that encompasses multiple roles. By steering the backbone LLM with the composed vector, MoRe enables multi-perspective specialization in a single-agent, single-turn inference process. The proposed MoRe can be efficiently trained via a three-stage SFT curriculum and GRPO post-training, while the backbone LLM remains frozen. Experiments across reasoning and personality benchmarks show that MoRe outperforms single-agent baselines by 2.2% on average, and achieves performance on par with MAS while reducing token cost by 20x.

## 二、方法论：MoRe 的核心思想与关键技术

**核心思想**：MoRe 并不预先固定某个角色，而是学习一个包含多个候选特化方向的"码本"（codebook），由一个轻量级、查询感知的路由器为每条输入动态地将若干候选方向组合成一个复合引导向量，注入 LLM 隐藏层实现多视角引导。

**关键组成模块**：

- **特化码本（Specialization Codebook）**：可学习的候选向量集合 \(\{\mathbf{e}_n\}_{n=1}^{N}\)，每个 \(\mathbf{e}_n \in \mathbb{R}^d\) 编码一个潜在角色方向。初始化采用对比激活方向（CAA）暖启动，其余条目用凸组合初始化，使码本锚定在行为学上有意义的激活区域。
- **查询感知路由器（Query-aware Router）**：
  - 为每个候选向量配备一个可学习的探针向量 \(\mathbf{u}_n\)，构成探针矩阵 \(U\)；
  - 采用**多头交叉注意力**（MHA），以探针 \(U\) 为 Query、输入 token 嵌入为 Key/Value，得到查询感知的候选表征；
  - 经 MLP 生成路由 logits，再经 **Top-K 稀疏路由**与 Softmax 加权，合成复合向量：
    \[
    \mathbf{v}_Q = \sum_{n \in \mathcal{T}_K} w_n \mathbf{e}_n, \quad w_n = \frac{\exp(g_n)}{\sum_{j \in \mathcal{T}_K} \exp(g_j)}
    \]
  - 通过 \(\tilde{\mathbf{h}}_t^{(\ell^\star)} = \mathbf{h}_t^{(\ell^\star)} + \alpha \frac{\|\mathbf{h}_t^{(\ell^\star)}\|_2}{\|\mathbf{v}_Q\|_2} \mathbf{v}_Q\) 将合成向量注入中间层，选择最后一个 prompt token 作为引导位置。

**训练流程（骨干 LLM 全程冻结）**：
- **三阶段课程式 SFT**：
  1. **阶段一**：仅优化码本，均匀采样单个候选向量进行引导，确保每个候选单独有效；
  2. **阶段二**：冻结码本，训练路由器，配合负载均衡损失（load-balancing loss）防止路由坍缩；
  3. **阶段三**：联合优化码本与路由器，使候选向量适配查询相关的组合方式。
- **GRPO 后训练**：将 RL 的动作空间从 token 空间迁移到**角色子集空间**，把冻结 LLM 视为黑盒环境。策略 \(\pi(S|Q)\) 由路由器在 Top-K 子集上随机采样决定，使奖励完全归因于路由器动作，避免 LLM 解码随机性的干扰，且 rollout 可无梯度执行，大幅节省内存与计算。

## 六、主要结论与发现

1. **单智能体特化确实能提升性能**：相比 Vanilla，各类特化方法均带来平均准确率与排名的提升；且不同角色在不同任务上各有优劣，**不存在全局最优的单一角色**。
2. **MoRe 显著超越单智能体基线**：平均准确率比最优单智能体基线 ActAdd 高出约 0.96–0.97 分（约 2.2%），在长链路推理任务上优势更明显。
3. **MoRe 以极低成本接近 MAS 性能**：排名分别位列两个骨干模型的第一与第二，而 token 消耗仅为 MAS 平均的约 **1/20**，实现了性能与效率的帕累托改进。
4. **人格特化效果尤为突出**：在 Big Five 全部人格维度上排名第一，平均分超越最佳基线 0.23（Llama）与 0.61（Qwen），且跨模型稳定性最佳。
5. **码本与路由器确实学到有意义的结构**：码本中候选向量呈低相似度、分布聚簇；路由器对不同数据集有不同偏好（如数学相关任务重用它初始化为数学家的 Expert 0），说明学到的特化具有任务可迁移性。
6. **引导位置很重要**：最后一个 prompt token 是最优引导位置——它汇总上下文且是生成起点；过度扰动（引导所有 token）反而损害性能。

## 七、方法亮点

- **范式创新**：首次将"多智能体多视角协同"压缩到"单智能体单轮推理"，用激活空间组合替代文本多轮通信，避免了上下文膨胀与"lost in the middle"问题。
- **训练极轻量**：仅训练 0.017% 参数，骨干模型完全冻结，SFT + GRPO 后训练均可高效完成。
- **GRPO 策略设计精巧**：将动作空间定义为角色子集空间，使奖励完全归因于路由器，规避了 LLM 解码随机性对策略梯度估计的污染；同时 rollout 无需梯度跟踪，节省大量显存与计算。
- **码本初始化具备可解释性**：用 CAA 对比激活方向暖启动，使码本锚定在语义有意义的区域；并在端到端训练中自然地实现功能分化（无需显式多样性正则）。
- **稳健的超参数表现**：在较宽的超参数范围内保持稳定，易于调参。

## 八、不足与局限

- **依赖内部状态访问**：MoRe 需要读取骨干 LLM 的隐藏激活，**无法直接应用于黑盒 API 模型**（如 GPT-4、Claude 等），限制了实际部署场景。
- **可解释性有限**：虽然码本由文本角色暖启动，但端到端训练后的候选向量是潜在的、难以解释的，难以确知每个候选向量在行为层面究竟编码了什么。
- **粒度较粗**：MoRe 在查询级别合成一个固定人设并贯穿整个生成过程，未实现 token 级或推理步骤级的细粒度路由；更细粒度可能带来进一步性能提升，但也会增加额外开销。
- **评估的潜在偏差**：人格评估使用 LLM-as-judge，评价模型可能自带偏见或不一致性；论文虽遵循标准评估协议，但未能完全消除这一风险。
- **实验规模有限**：仅验证了 8B 级模型，未在更大规模模型或更多模型族上验证方法的泛化性。
- **超参选择需人工设定**：码本大小 N 与 Top-K 的选择依赖验证集调优，且存在一定敏感区间（如 Top-K 过小失去多视角、过大稀释特化）。
- **可能放大偏差**：学习到的引导向量在分布外输入上可能放大潜在偏见，论文在风险讨论中也承认了这一点，但未做系统性的安全性评测。
