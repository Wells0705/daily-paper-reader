## 摘要
组织多模态智能体的长期记忆仍然具有挑战性，因为现有方法要么依赖于代价高昂的、与查询无关的离线摘要，要么采用朴素的嵌入相似度匹配，从而引入不完整和冗余的上下文。为解决这些问题，我们提出了GraphMemix，一种组合优化的图记忆框架，将记忆组织建模为查询感知的证据森林构建。具体而言，我们的方法由三个关键组件组成：(1) 候选图构建，通过模式和语义关系扩展多视角种子记忆，以获取查询感知的原始上下文；(2) 证据效用与激活成本，将直接记忆支持与锚定条件的关系验证解耦，以抑制冗余或冲突信息；(3) 森林优化，在最大证据预算及其可靠关系结构下，联合选择森林格式的记忆上下文。通过将记忆组织为查询相关的子图，该方法避免了大量生命周期成本，并恢复了低相似度的补充证据。在四个长期多模态记忆基准上的实验结果表明，在不同基础模型下均取得了显著改进，并在准确性与生命周期成本之间建立了新的帕累托前沿。

## Abstract
Organizing long-term memory for multimodal agents remains challenging because existing methods either suffer from expensive question-agnostic offline summaries or naive embedding similarity matching that introduces incomplete and redundant context. To address these issues, we propose GraphMemix, a combinatorial-optimization graph memory framework that models memory organization as query-aware evidence-forest construction. Specifically, our method consists of three key components:(1) candidate graph construction, which expands multi-view seed memories through schema and semantic relations to acquire query-aware original context; (2) evidence utility and activation costs, which decouples direct memory support from anchor-conditioned relation verification to suppress redundant or conflicting information; and (3) forest optimization, which jointly selects a forest-format memory context under a maximum evidence budget and its reliable relational structure. By organizing memory into a query-relevant subgraph, the method avoids substantial lifecycle cost and recovers low-similarity complementary evidence. Experimental results across four long-term multimodal memory benchmarks demonstrate significant improvements with different foundation models and establish a new Pareto frontier between accuracy and lifecycle cost.

## 1. 论文的核心问题与整体含义（研究动机和背景）

长期记忆是支撑大视觉语言模型（LVLM）智能体在长时间、多模态交互中保持一致性并吸收新信息的关键组件。个人助理智能体需要记忆历史交互、相册、邮件、聊天记录、工作文档等海量异构多模态数据，因此如何在查询到来时精准检索并组合出完整、相关的证据上下文，是当前的核心挑战。

现有方法主要分两条路线，各有缺陷：

- **问题无关的离线摘要路线**（如 A-MEM、SGM、MIRIX 等）：在问题未知前，预先将全部历史压缩为通用表示。该方法导致高昂的冷启动和持续更新成本，且压缩过程可能丢失后续起决定性作用的视觉属性、状态转换或局部上下文。
- **多模态 RAG 路线**（如 MuRAG、Pensieve 等）：直接基于嵌入相似度检索原始记录。该路线保留了原生视觉访问且处理成本低，但单纯依赖相似度排序会导致过选近重复项、遗漏措辞不同但语义互补的记录，且无法建模多个记忆间的联合证据效用。

**核心含义**：GraphMemix 将问题定位为“查询时的证据组织问题”，主张在查询到达后再从大规模记忆档案中重建必要的证据森林，通过显式建模记忆之间的协同、冗余与冲突关系，同时提升答案质量并降低生命周期成本。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 核心思想

GraphMemix 是一个组合优化图记忆框架，将记忆选择建模为**查询条件证据森林优化**问题：
- **节点**代表单条记忆的直接证据效用；
- **边**代表在锚定条件下该记忆的增量价值；
- 优化目标是在不超过读者上下文预算（K 条记忆）的前提下，联合选择节点与可信边，形成无环的证据森林。

### 2.2 三大关键组件

**（1）候选图构建（Candidate Graph Construction）**
- **多视角检索**：同一记忆可通过不同信号（原始图像、标题、OCR、视频帧、元数据等）被检索，采用最大池化融合多视图相似度作为初始分数，提供多条进入候选集的路径。
- **查询相关子图发现**：利用两类关系构建发现图 $G^{disc}$：
  - **模式边（Schema edges）**：来自可观测交互结构（如同一会话、同一轮次、同一地点）；
  - **语义边（Semantic edges）**：基于互 k 近邻的嵌入相似关系。
- 从 top-L 个多视图种子出发，进行 H-hop 有界扩展，保留至多 M 个候选节点，兼顾局部上下文完整性与后续语义推理的可控性。

**（2）证据效用与激活成本（Evidence Utility and Activation Costs）**
- **直接节点效用**：将检索相似度（全局先验）与列表式节点验证器（listwise node verifier）分数融合，经 sigmoid 映射为节点效用 $p_i(q)$。
- **锚定条件关系验证**：从高置信锚集合出发，仅检查锚与候选之间的模式边，由 E证链验证器（ECV）预测增量支持分数和六种关系角色（新事实、澄清、佐证、冗余、冲突、无关），仅保留正向且非冗余冲突的边，形成可信图。
- **独立链成本**：对每个连通分量（独立证据链）收取开启成本，使得孤立的低效用记忆被抑制，而有价值的互补证据因连接而受益。

**（3）森林优化（Forest Optimization）**

优化目标形式化为：
$$\max_{S,F} \sum_{i\in S} p_i(q) - \lambda\sum_{e\in F} c_e(q) - \kappa\, m(S,F)$$

其中 $m(S,F)$ 为森林中连通分量数。由于边成本非负，最优边集必为森林，目标可等价转化为节点贡献 $p_i - \kappa$ 与结构增益 $B_e = \kappa - \lambda c_e$ 的求和。

求解采用确定性两阶段策略：
1. **固定基数提议**：基于 top-K 节点效用初始化，通过 1-swap 局部搜索逐步交换选择/未选择节点，每次交换用 Kruskal 算法精确重算该节点集下的最大权重森林；
2. **可变基数精确优化**：在冻结的提议集内，对所有非空子集精确求解最优森林（Kruskal + 正增益边），并在目标值相同时偏好更少记忆和更早的提议排名。

### 2.3 证据序列化

将每个连通分量中效用最高的节点设为根，按根效用排序分量，对每个分量进行广度优先遍历，最终形成有序多模态证据包送入冻结的读者模型生成答案。

## 7. 优点

- **查询条件化**：完全在查询到达后组织证据，天然绕开问题无关摘要的冷启动和持续更新成本。

- **效率与质量双赢**：在生命周期成本-准确率图上建立了新帕累托前沿，打破了“高质量必然高成本”的直觉。
