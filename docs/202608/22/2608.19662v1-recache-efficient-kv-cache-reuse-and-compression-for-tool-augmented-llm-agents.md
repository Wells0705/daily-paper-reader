## 摘要
智能体语言模型反复编码工具和技能模式，这些模式在不同请求中以不同的组合和顺序出现，阻碍了标准前缀缓存重用其键值（KV）状态。我们引入了\textbf{ReCache}框架，用于独立缓存资源表示，同时降低推理时的计算和内存开销。资源级注意力消除了跨资源交互并分配资源局部位置，生成组合不变的KV块。然后，ReCache将资源可见性限制在贡献选择层- KV头组路由上，并通过结构和语义剪枝仅保留调用关键字段。我们在由七个公共工具和技能使用数据集组成的基准上评估了ReCache，包括资源不相交测试。资源级注意力与密集调用性能相匹配（82.3\%对比82.4\% Inv-F1），同时提供3.655$\times$的首令牌时间加速。完整的框架将分配的KV张量内存减少92.43\%，并将注意力加速1.423$\times$。这些结果表明，将可重用模式编码与选择性资源访问相分离可大幅降低智能体推理成本，且有效性损失有限。代码可在https://github.com/EIT-NLP/ReCache获取。

## Abstract
Agentic language models repeatedly encode tool and skill schemas that recur across requests in different combinations and orders, preventing standard prefix caching from reusing their key--value (KV) states. We introduce \textbf{ReCache}, a framework for independently caching resource representations while reducing their inference-time computational and memory overhead. Resource-wise attention removes cross-resource interactions and assigns resource-local positions, producing composition-invariant KV blocks. ReCache then restricts resource visibility to contribution-selected layer--KV-head-group routes and retains only invocation-critical fields through structural and semantic pruning. We evaluate ReCache on a benchmark assembled from seven public tool- and skill-use datasets, including resource-disjoint tests. Resource-wise attention matches dense invocation performance (82.3\% versus 82.4\% Inv-F1) while providing a 3.655$\times$ time-to-first-token speedup. The complete framework reduces allocated KV-tensor memory by 92.43\% and accelerates attention by 1.423$\times$. These results show that separating reusable schema encoding from selective resource access substantially reduces agentic inference costs with limited effectiveness loss. The code is available at https://github.com/EIT-NLP/ReCache.

### 1. 核心问题与整体含义（研究动机与背景）

工具增强型 LLM 智能体在处理用户请求时，需要动态检索并调用外部工具和技能（合称“资源”）。这些资源 schema 在多个请求中反复出现，但组合和顺序各不相同，导致以下问题：

- **反复预填充开销**：同一资源在每次请求中都会被重新编码，造成大量重复计算。
- **前缀缓存失效**：标准前缀缓存要求复用内容形成完全相同的词元前缀，而资源是动态组合的，很少满足这一条件。
- **KV 缓存占比高**：随着资源池扩大，存储和传输完整资源缓存所需的 KV 张量内存和注意力计算成本持续增长。

论文的核心洞察是：在资源调用场景中，资源内部语义（如参数名、名称）比全局资源顺序/位置更重要——实证分析（Qwen3-4B）显示模型对资源内部的注意力强度远高于跨资源注意力。据此，ReCache 将“资源编码”与“资源访问”分离，使资源 KV 块可以被独立缓存和复用，再通过结构性和语义性剪枝降低推理时的计算与内存开销。

### 2. 方法论

ReCache 由三个渐进式阶段组成：

**（1）资源级注意力（Resource-Wise Attention）**

- 取消不同资源块之间的注意力交互，资源内 token 仅关注共享前缀和本地资源 token；跨资源注意力从 **O(D_R²)** 降为 **O(Σ D_i²)**。
- 对每个资源分配**局部位置索引**（pos(t_ij)=j），使资源 KV 表示与检索组合和全局顺序无关，实现真正的组合不变性。
- 该配置通过轻量级全参数微调使模型适应新的注意力与位置模式，保持调用可靠性。

**（2）结构剪枝（Structural Pruning）**

- 观察事实：Transformer 层和 KV 头组对预测的贡献高度不均。
- 采用 **leave-one-in** 分析：从 Ω=∅（资源不可见）出发，逐一激活某层（所有头组）或某头组（所有层），测量调用损失（仅对目标响应 Y 的 token 位置计算）的边际降低量，归一化为贡献权重 w_i。
- 按预算 K_L、K_G 选取 Top-k 层与头组，构造路由集合 **Ω\* = L\* × G\***。只有 Ω\* 中的层–头组路由暴露资源 KV 状态（使用 M_resource），其余路由使用 M_context（完全屏蔽资源 token）。

**（3）语义剪枝（Semantic Pruning）**

- 工具/技能 schema 中不同字段对调用成功率贡献不同——无效名称和错误参数是调用失败的主要来源。
- 保留三类关键字段：**资源名称**（标识）、**参数名称**（接口对齐）、**参数描述**（约束语义），外加**最终后缀 token**（作为自然聚合的摘要表示）。其余字段（如资源描述、格式元素）被剪除。

最终推理时，会话文本仅通过 Ω\* 中路由关注保留的语义字段，同时降低资源–上下文注意力开销。

### 3. 实验设计

**数据集**

- 构建了统一工具/技能使用基准，整合 7 个公开数据集：ToolACE、APIGEN、ToolMind、ToolRet、Toucan、SkillRouter、WildToolBench。
- 采用**多样性优先采样**（两阶段）：先保证每条样本的候选配置签名与调用资源均为新出现的，再按来源配额补充；过滤幻觉调用和格式错误样本。
- 最终训练集 **49,424 条**，两个测试集各 **1,000 条**：T_IND（资源在训练中出现过）与 T_OOD（资源完全未见），后者用于评估泛化。

**评估指标**

- 有效性：Inv-F1（完整调用匹配，含资源名和全部参数）、Resource ID 的 P/R/F1、幻觉率（Halluc.）。

**对比方法**

- 基线：Dense（标准全注意力）、Block（仅去跨资源注意力、保留原位置）、Ω_full（+位置重置）。
- 结构剪枝对比：Ωfull + SPEED（层非对称 KV 可见性）、SA20,3（注意力质量排序替代贡献排序）。
- 语义剪枝对比：Gist（单摘要 token）、Beacon（分块摘要）、SMP（ReCache 的字段感知语义剪枝）。

**骨干模型**

- 主模型 Qwen3-4B（全参数微调），辅助模型 Qwen3-1.7B（用于结构预算敏感性分析）。

### 6. 主要结论与发现

- **资源级注意力在有效性上几乎无损**：Ω_full 的 Inv-F1 82.3% 对 Dense 的 82.4%（差 0.1%~0.2%），TTFT 加速 **3.655×**（26.3 ms → 7.2 ms），证明跨资源注意力和全局资源顺序对调用任务价值有限。
- **结构剪枝显著降低内存与计算**：完整 ReCache 减少 **92.43%** KV 内存分配，加速注意力 **1.423×**。
- **贡献引导的剪枝优于注意力/启发式基线**：在相同预算下，Ω20,G 的 Inv-F1 比 SPEED 高 3.2%（T_IND）和 10.0%（T_OOD）；OOD 幻觉率从 13.4% 降至 0.5%，泛化性更强。
- **语义剪枝中字段选择至关重要**：Gist（单摘要向量）严重失效（OOD Inv-F1 仅 9.7%、幻觉率 79.9%），Beacon 也不如字段感知剪枝；资源名、参数名、参数描述是核心保留字段，资源描述增益有限。
- **效率随资源规模扩展表现稳定**：ReCache 在 XL（≥10K tokens）下 TTFT 仍约 5 ms、注意力延迟 <0.2 ms，KV 内存封顶 0.03 GiB，而 Dense 接近 8 GiB。
- **结构预算因模型规模而异**：Ql 仅需 3/8 头组即可恢复性能，Qs 需要 7/8——较大模型在保留路由上提供更大的功能余量，但统一的贡献度判据可跨规模选择预算。

### 7. 优点

- **方法设计契合任务特性**：利用资源数据“内部语义强、跨资源交互弱”的结构特点，从位置与注意力两个层面解耦资源编码，理论清晰、有实证支撑（图 1 的分析）。
- **三维度渐进式压缩**：从构造（注意力）、路由（层-头组）、存储（token/字段）三个维度协同压缩，各环节的收益和代价被独立量化与叠加评估。
- **贡献度驱动的剪枝准则**：基于 loss 边际贡献而非注意力质量选择层/头组，更直接地优化调用目标，在 OOD 上泛化表现显著优于对比方法。
- **评测基准更严谨**：注意到直接聚合七个数据源带来的记忆偏差和候选配置重复问题，设计两阶段多样性采样与 OOD 资源分隔，提升了评测的可靠性和区分度。
- **工程实现开放**：代码开源，便于复现。
