## 摘要
持久化记忆可以使LLM智能体个性化，但错误的持久性更新可能会悄然扭曲未来的行为。我们研究记忆-澄清边界：交互中获取的信息是应被持久化、仅在当前上下文中使用、重新验证，还是与用户澄清。MCB包含140个主要场景，分为70个开发项和70个留出项，外加一个独立的70项对比集。它同时评估动作标签和结构化工具调用选择。两位非作者独立标注了70个留出的主要项目和70个对比项目（一致性97.1%，Cohen's kappa = 0.962）；一位盲测的第三方解决了4处分歧，用非作者多数票替换了8个作者标签。在Claude和Qwen中，模型验证变化事实的可靠性高于询问用户以解决歧义。裸Qwen在0/12个澄清项上提问，同时验证了12/18个新鲜度项。少样本提示将准确率从0.557提升至0.771（配对差异 = +0.214，Holm校正的精确McNemar检验 p_H = 0.002），但澄清召回率仍为0.333。策略提示将错误持久化从0.243降至0.100（p_H = 0.038），但其准确率提升并不显著。每个Claude模型的标签-工具一致性为57%，Qwen为23%；Qwen的准确率从0.557降至0.343（p_H = 0.047）。记忆评估必须同时测试明确的决策和工具调用的选择。

## Abstract
Persistent memory can personalize an LLM agent, but an incorrect durable update can silently distort future behavior. We study the memory-clarification boundary: whether interaction-derived information should be persisted, used only in the current context, re-verified, or clarified with the user. MCB contains 140 primary scenarios, split into 70 development and 70 held-out items, plus a separate 70-item contrast set. It evaluates both action labels and structured tool-call selection. Two non-authors independently label the 70 held-out primary and 70 contrast items (97.1% agreement, Cohen's kappa = 0.962); a blind third resolves four disagreements, replacing eight author labels by non-author majority. Across Claude and Qwen, models verify changing facts more reliably than they ask users to resolve ambiguity. Bare Qwen asks on 0/12 clarification items while verifying 12/18 freshness items. Few-shot prompting raises accuracy from 0.557 to 0.771 (paired delta = +0.214, Holm-adjusted exact McNemar p_H = 0.002), yet clarification recall remains 0.333. The policy prompt reduces erroneous persistence from 0.243 to 0.100 (p_H = 0.038), although its accuracy gain is not significant. Label-tool agreement is 57% for each Claude model and 23% for Qwen; Qwen accuracy falls from 0.557 to 0.343 (p_H = 0.047). Memory evaluation must test both stated decisions and tool-call choices.

## 一、核心问题与整体含义（研究动机与背景）

- **核心问题**：LLM智能体在交互中会获取大量候选记忆信息，但并非所有信息都应当被持久化。错误地持久化一条本应临时的信息，可能悄无声息地扭曲智能体未来的全部行为。本文研究的是"记忆-澄清边界"（memory–clarification boundary）：面对一条候选更新，智能体应该选择四种互斥操作之一——**持久化**（persist）、**仅临时使用**（ephemeral）、**向世界验证**（verify）、**向用户澄清**（clarify）。
- **关键洞察**：验证与澄清不可互换——世界是变化事实的真相来源，而用户是意图与范围的真相来源。现有研究多聚焦于记忆的"回忆"能力（retrieval），而非"承诺"能力（commitment），即决定什么信息可以安全地影响未来行为。
- **研究意义**：该问题直接关系到个性化记忆系统的安全性与隐私保护。一次错误的持久化更新可能造成不可见的、难以回溯的行为偏差，而多问一个问题则是可见且可恢复的。因此，本文主张采用"不对称成本"视角：宁可多问，不可错记。

## 二、方法论：核心思想与技术细节

### 核心思想
- 构建一个**审计性强、防捷径、可独立验证**的基准测试基准——MCB（Memory–Clarification Boundary），用于评估LLM智能体在候选记忆更新时刻的"承诺决策"能力。
- 每一条测试项包含三个部分：**获取上下文**（acquire context）、**候选更新**（candidate update）、**后续复用上下文**（later reuse context）。模型需要根据规则判断该更新应当采取的行动。

### 标签规则（四条核心规则）
1. **persist（持久化）**：明确持久的偏好、被授权的策略或稳定事实；
2. **ephemeral（临时）**：信息限定于单个工件、会话或时间窗口；
3. **verify（验证）**：世界状态可能改变或仅有单一噪声信号，需要重新核查；
4. **clarify（澄清）**：指代不明、持久性/范围不清、冲突或二手偏好，只有用户才能裁决。
- 规则中内置了一个**不对称性偏好**：当持久化与较弱的行动（如临时使用）并存时，优先选择较弱的承诺。这体现了"错误记忆比多余提问代价更大"的设计哲学。

### 两种评估模式
1. **标签模式（Label mode）**：模型输出四种行动之一（JSON格式）。
   - *Bare*：仅定义行动，无额外指导；
   - *Policy*：附加五条承诺规则（含弱行动优先规则）；
   - *Few-shot*：每类行动给出一个开发集示例。
2. **工具调用模式（MCB-Act）**：去掉标签词汇，模型必须输出一个结构化的工具调用——`memory_write`、`use_now`、`check_source`、`ask_user`，每个都带有必填字符串参数，并通过确定性的最小内容与相关性检查。该模式隔离了"从陈述性选择到具体工具调用"的行为差异。

### 统计方法
- 准确率采用2,000次重采样的百分位bootstrap 95%置信区间；
- 显著性检验采用**精确配对McNemar检验**（对不一致的正确性），行为事件（如错误持久化）同样采用配对事件检验；
- 多重比较采用**Holm校正**，分六个准确率比较族、六个过记忆比较族、三个工具调用比较族、两个对比验证比较族分别控制族系误差；
- 关键推断声明报告调整后p值（pH）；其他精确检验仅作描述性报告、不校正。

## 三、实验设计

### 数据集/基准（MCB）
- **140个主场景**，按排序标识符在类别内确定性分为70个开发项和70个留出项；另加独立的**70项对比集**（含35个证据翻转对、7个线索冲突陷阱）。
- 场景覆盖6大类：稳定偏好、情景偏好、新鲜度敏感事实、一次性修正、策略约束、模糊更新、噪声失败（每类20项）。
- 经审计后的行动分布为：38持久、40临时、33验证、29澄清。
- 设**8个词汇陷阱**（如"always""today"出现在其通常启发式判断错误的情境中），防止模型依赖表层线索。
- **独立标注**：两位非作者盲测独立标注（一致性97.1%，κ=0.962）；盲测第三方解决4处争议，以非作者多数票替换8个作者标签，确保评估客观性。
- 基线系统包括：Always-Persist、Majority Action（多数行动，即预测出现最多的"临时"）、关键词启发式、类别oracle（使用隐藏类别标签的分布泄漏诊断）。

### 评估模型与条件
- **Claude Haiku 4.5** 和 **Claude Sonnet 4.6**（API独立逐项调用）；
- **Qwen3.5-9B**（本地Ollama 0.24.0运行，Q4 K M量化，9.7B参数，temperature=0，seed=13，关闭思考，输出限制96/128 tokens）。
- 每个模型在三种提示条件（bare/policy/few-shot）下独立评估，另加MCB-Act工具调用模式（仅bare条件）。

### 充分性评估
- 全部共享相同测试项，支持**精确配对检验**而非重叠独立区间推断；
- 每个条件70次独立调用，合计280个Qwen输出全部解析成功；
- 报告了多种指标：准确率、macro-F1、过记忆（OM）、澄清召回率、验证召回率；
- 在对比集上冻结了70项独立验证，两位非作者标注者完全复现（κ=1.000）；
- 提供完整的可复现工件：数据、盲测标注、提示词、运行程序、逐项预测、模型元数据、测试与配对分析脚本。

## 六、主要结论与发现

### 1. 跨家族一致发现"欠询问"（under-asking）
- Claude系列：验证召回率0.889–1.000，但澄清召回率仅0.500–0.750；
- **裸Qwen区分度最大**：澄清项0/12提问，却能验证12/18个新鲜度项。其澄清案例被映射为persist（7）、verify（4）、ephemeral（1）——模型能识别不确定性，却去咨询世界而非用户，即**来源真相混淆**。

### 2. 提示策略影响"总准确率"与"安全相关行为"是可分离的
- **Qwen few-shot**：准确率从0.557升至0.771（Δ=+0.214，pH=0.002），修复16个错误并破坏1个正确；澄清召回率从0升至0.333，但仍有8/12的澄清机会丢失——**示例缓解但不能消除欠询问**。
- **Qwen policy**：准确率提升0.071（pH=0.539，不显著），但**错误持久化从0.243降至0.100（pH=0.038）**——移除11个错误并引入1个。它将不确定性主要转移到验证（召回率0.667→0.944），而非用户（澄清0→0.083）。
- **Claude**：Haiku的policy和few-shot增益均通过Holm校正（pH=0.002和0.047）；Sonnet的均不通过——表明基准测的是**提示条件依赖的承诺策略**，而非固定模型特质。

### 3. 陈述性选择不能可靠预测工具调用选择
- **标签-工具一致性**：两个Claude模型均为57%（30/70决策在标签变为工具时改变）；Qwen仅23%。
- **Sonnet**：准确率从0.814降至0.529（Δ=-0.286，pH<0.001）；
- **Qwen**：准确率从0.557降至0.343（Δ=-0.214，pH=0.047），在54/70项上调用`use_now`，验证召回率从0.667崩塌至0.056。
- 所有参数都通过了格式检查，说明瓶颈是**工具选择**而非参数生成。

### 4. 基线与扩展验证
- Always-Persist仅0.257准确率、0.743过记忆；Majority Action达0.314准确率但macro-F1仅0.120——频率规则本质上是弱的。
- 在组合140项上，Qwen的bare/policy/few-shot准确率分别为0.614/0.757/0.843；澄清召回率仍是最弱类别（0.074/0.407/0.519）。

## 七、优点

1. **高审计性基准**：非作者独立标注与多数票仲裁机制（一致性97.1%、κ=0.962），显著提升标签客观性；防捷径词汇陷阱（8个反表层线索项）和类别-行动解耦设计使模型无法走捷径。
2. **双模式评估**：同时评测显式标签决策与结构化工具调用选择，揭示了标签与行为之间的显著断裂——这是记忆评估中此前未受重视的维度。
3. **跨家族验证**：同时覆盖Claude（闭源API）与Qwen（本地开源量化模型），且所有模型共享完全相同的测试项，支持精确配对显著性检验。
4. **行为与准确率分离分析**：将"对话总准确率提升"与"安全相关行为重塑"（如减少错误持久化）作为独立维度分别检验，避免了单一指标掩蔽关键行为变化的陷阱。
5. **可复现性极佳**：数据集、盲测标注、提示词、运行程序、逐项预测、模型元数据、分析脚本全部发布，确定性的组成部分可脱离模型完全复现。
6. **不对称成本设计**：规则偏好较弱承诺，体现了对有害持久化风险的合理建模。

## 八、不足与局限

1. **测试规模有限**：主留出集仅70项，置信区间较宽；10项/类的类别级结论只能定性处理，无法支撑紧凑的排名声明。MCB-Act每族仅一个checkpoint及bare条件，跨条件工具调用对比缺失。
2. **作者偏差风险**：虽然测试标签已由非作者独立仲裁，但场景内容和标注规则仍由作者编写，无法完全排除设计者意图偏差；对比集中的完美复现可能反映规则-模板对齐过紧，外部效度存疑。
3. **模型覆盖局限**：Qwen仅测试一个量化检查点（Q4 K M），量化方式、推理服务栈和禁用思考均作为评估系统的一部分，不代表Qwen模型的全部能力；未涉及其他主流家族模型。
4. **MCB-Act不执行真实工具**：只记录工具选择与参数，不模拟用户回答、不执行源查询、不观察下游任务分数——只能证明标签-工具选择鸿沟，不能量化端到端效用增益。
5. **场景全为合成英文数据**：缺乏多语言、真实对话或自然场景语料；交互时间跨度、噪声类型等现实维度的代表性有限。
6. **整体判定**：实验设计相当扎实、统计严谨，但在规模与生态效度上仍属小规模受控基准，结论推广需谨慎。对于探索性质的研究，此规模的实验在当前阶段是充分且合理的，但作为最终基准仍留有扩展空间。
