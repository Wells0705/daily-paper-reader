## 摘要
将可重用的技能文档加载到有界上下文窗口中，现在是大型语言模型（LLM）智能体获取任务特定能力的主要方式，这使得技能选择成为任务性能和令牌成本的一阶决定因素。然而，当前的智能体通过语义相关性独立地对技能进行评分，并通过top-k或贪心打包来组装技能集，对所选技能集没有质量保证或成本意识。因此，冗余或选择不当的技能会浪费稀缺的上下文令牌，甚至可能降低性能。我们首次对所选技能集如何影响执行结果进行了建模，并将技能选择视为一个优化问题：在硬令牌预算下选择技能集，以最大化单调子模收益减去上下文惩罚。针对这个问题，我们开发了最佳前缀选择（BPS），一种多项式时间算法，并证明了据我们所知第一个技能选择的性能保证：一个双准则(1-1/e,1)近似，其收益系数在多项式时间内是最优的。在受污染控制的BigCodeBench变体上，BPS优于所有基线，在比最强发布的技能路由器少28%的令牌下，实现了0.73的实测任务成功率，而发布的技能路由器、文本检索器和执行器自身选择的成功率则为0.20--0.52。

## Abstract
Loading reusable skill documents into a bounded context window is now the primary way large language model (LLM) agents acquire task-specific capabilities, which makes skill selection a first-order determinant of task performance and token cost. Yet current agents score skills independently by semantic relevance and assemble the set by top-$k$ or greedy packing, with no quality guarantee or cost awareness on the selected set. As a result, redundant or poorly chosen skills waste scarce context tokens and can even degrade performance. We give the first model of how the selected skill set shapes execution outcomes and cast skill selection as an optimization problem: choose a skill set under a hard token budget to maximize a monotone submodular benefit minus context penalty. For this problem, we develop Best Prefix Selection (BPS), a polynomial-time algorithm, and prove, to our knowledge, the first performance guarantee for skill selection: a bicriteria $(1-1/e,1)$ approximation whose benefit coefficient is optimal in polynomial time. On a contamination-controlled BigCodeBench variant, BPS outperforms all the baselines, reaching $0.73$ measured task success versus $0.20$--$0.52$ for released skill routers, text retrievers, and the executor's own selection, on $28\%$ fewer tokens than the strongest released router.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **研究背景**：现代LLM智能体（如Codex、Claude Code）普遍采用"两阶段"技能交互机制——**选择（selection）与执行（execution）**：先根据查询从技能库中筛选技能，再将选中的技能文档加载到有限的上下文窗口中执行任务。
- **核心问题**：现有智能体对技能进行**独立语义相关性评分**，再通过top-k或贪心打包组装技能集，存在三个关键缺陷：
  1. **缺乏质量保证**：独立评分无法刻画技能之间的互补性与冗余性；
  2. **缺乏成本意识**：忽略加载技能文档占用的上下文令牌成本；
  3. **实际后果严重**：冗余或选择不当的技能浪费稀缺上下文令牌，甚至将成功率压低至无技能基线以下（已有研究在87个任务中的13个上观察到该现象）。
- **问题的理论本质**：技能选择本质上是**预算约束下的集合级决策**，而非独立技能的排序问题。作者用真实实验证明：单个技能的相关性与集合整体效用之间不存在简单对应关系（图1）。
- **整体含义**：本文首次将技能选择形式化为**带硬令牌预算约束的规则化子模最大化**（regularized submodular maximization）问题，并给出了具有**可证明双准则 \((1-1/e,1)\) 近似保证**的多项式时间算法BPS。

## 2. 论文提出的方法论

### 2.1 核心思想：结构化目标函数

作者的建模分三步完成：

**第一步：结构化能力收益（Capability Benefit）**。假设存在 \(d\) 维潜在能力空间：
- 每个技能 \(s_i\) 具有潜在能力供给向量 \(\boldsymbol{u}_i = (u_{i,1}, \ldots, u_{i,d}) \in \mathbb{R}_+^d\)；
- 每个查询 \(q\) 具有潜在能力需求向量 \(\boldsymbol{w}_q \in \mathbb{R}_+^d\)；
- 用非降凹函数 \(h_k\)（取 \(h_k(x) = 1 - e^{-x}\)）刻画同一能力维度内的**边际收益递减**；
- 总收益定义为：\(G_E(q, S) = \sum_{k=1}^{d} \eta_k^E w_{q,k} \cdot h_k(\lambda_k^E \sum_{i \in S} u_{i,k})\)，该函数是**单调子模**的；

**第二步：线性退化惩罚（Degradation Penalty）**。每个技能文档 \(s_i\) 的令牌长度记为 \(\ell_i\)，惩罚为 \(c_E(S) = \kappa_E \cdot \ell(S)\)，即每令牌线性收费，与上下文过长导致性能下降的观测一致。

**第三步：组合成优化问题**。最终目标为最大化 \(F_E(q, S) = G_E(q, S) - \kappa_E \ell(S)\)，受约束于硬预算 \(\ell(S) \le B\)，即求解公式(7)：
\[
\max_{S \in \mathcal{F}_B} F_E(q, S)
\]
该问题已被证明是NP-hard的，且惩罚项使目标函数可能为负，无法用常数乘法近似，因此需要**双准则保证**。

### 2.2 算法：Best Prefix Selection（BPS）

BPS是一种**带种子枚举的密度贪心算法**（seed size = 2），算法流程如下：
1. **预处理**：丢弃所有长度超过预算的单个技能；
2. **枚举种子**：枚举所有大小≤2且可行的技能种子 \(A\)，每个种子开启一条前缀链；
3. **密度贪心生长**：从每个种子出发，反复添加边际收益/令牌长度之比最高的技能，直到预算不足以容纳任何剩余技能；
4. **记录前缀**：沿链记录每一步的前缀集合，而非仅记录终点（这是面对非单调目标时与经典贪心的关键区别）；
5. **最优返回**：在所有记录前缀中选取使目标函数 \(\hat{F}\) 最大的集合 \(S_{\text{BPS}}\) 返回。

### 2.3 理论保证：核心定理

**定理1（双准则 \((1-1/e, 1)\) 近似保证）**。设 \(\hat{G}\) 是归一化、单调、子模的，\(\ell_i > 0\)，\(\hat{\kappa} \ge 0\)，则BPS的输出 \(S_{\text{BPS}}\) 对任意可行集 \(T\) 满足：
\[
\hat{F}(S_{\text{BPS}}) \ge \left(1 - \frac{1}{e}\right)\hat{G}(T) - \hat{\kappa}\ell(T)
\]
即收益系数为 \(1-1/e\)、惩罚系数为1，且**收益系数在多项式时间内不可改进**（由Feige的NP-hard界限保证）。

**证明的技术亮点**：论文提出了**预算对齐插值（budget-aligned interpolation）** 技术——利用预算约束与惩罚共享同一长度坐标这一事实，将分数点上的界转换为某个已记录整数前缀上的界。证明分为三步：种子构造与残差函数 → 有界函数支配（bounding-function domination，改造自Kulik等人的精化分析）→ 预算对齐插值收敛。

### 2.4 参数学习与误差传递

- 目标函数中的潜在参数通过**能力编码器**学习：需求编码器 \(\hat{\psi}_E\) 和供给编码器 \(\hat{\phi}_E\)，通过执行记录（通过/失败标签）以281个参数联合训练；
- **命题1（误差传递）**：若拟合目标函数满足一致性误差ε，则任何以δ次优性求解拟合问题的选择规则，其真实执行效果的遗憾值不超过 \(2\varepsilon + \delta\)。

## 6. 论文的主要结论与发现

1. **技能选择是集合级决策**：独立技能相关性排序不足以刻画集合层面的互补性、冗余性与成本；
2. **BPS达到理论最优**：以 \((1-1/e, 1)\) 双准则保证求解技能选择问题，收益系数 \(1-1/e\) 在多项式时间内不可改进，且无加法损失（区别于以往需额外 \(\kappa\varepsilon\) 的结果）；
3. **目标函数具有强拟合能力**：281个参数的查表编码器在持有集合预测准确性上超越所有对比模型（包括16.6k参数的神经集合回归器），仅凭通过/失败标签即可恢复隐藏的能力覆盖矩阵（AUC = 0.996），预测成功率达±1个百分点以内；
4. **BPS在优化质量上表现完美**：80/80实例达到精确最优，而top-k、MMR、DPP-MAP仅达到7.5%；
5. **端到端实测优势显著**：BPS达到0.73实测成功率，比最强发布路由器和检索器高0.30–0.53，比执行器自选高0.22，且比最强发布路由器少28%的令牌；神经编码器实例化也能达到0.68，仍比所有部署系统高0.17–0.48。
