## 摘要
基于要点的上下文压缩——将较旧的对话历史总结为紧凑的表示——是长时程语言模型代理中的常见方法，然而它对不同类型记忆检索的影响却知之甚少。我们使用显著性加权巩固（SWC）——一种受基于睡眠的记忆巩固启发的生物启发式压缩框架——作为诊断探针，来研究要点压缩何时有帮助、何时有损害。SWC根据显著性对对话历史进行评分，将其划分为优先级层级，并对中优先级内容应用结构化要点抽象。在全部十个LoCoMo对话上评估四种条件——总共1,935个匹配的纯文本问题，排除第5类（对抗性）问题后主要汇总中使用了1,501个——在温度为0的情况下，我们发现了一致的任务类型交互作用：在多跳推理和单跳事实性问题上，要点压缩显著优于截断；但在时间性问题上，压缩下的问题仍然明显更困难，在同时评估两者的对话中，压缩条件下的得分远低于全上下文参考。我们将这种失败归因于一个具体机制：要点抽象提示保留了关系和事件结构，却丢弃了日期和时间。对所有十个对话的保留分析证实了这一机制：通过一句话的提示修改，时间表达式的保留率大约增加了20倍（从3.05%到62.39%），而命名实体和事件的保留率几乎不变（x1.02和x1.11），这表明该修复是一个精确的工具。提示修改在匹配集中的第2类（时间性）问题上恢复了+0.314 [0.254, 0.375]的判定准确率。代码和结果：https://github.com/kyrkewood/sleeping-agent

## Abstract
Gist-based context compression---summarising older conversation history into compact representations---is a common approach in long-horizon language model agents, yet its effect on different types of memory retrieval is poorly understood. We use Salience-Weighted Consolidation (SWC), a biologically-inspired compression framework motivated by sleep-based memory consolidation, as a diagnostic probe to study when gist compression helps and when it hurts. SWC scores conversation history by salience, partitions it into priority tiers, and applies structured gist abstraction to mid-priority content. Evaluating four conditions on all ten LoCoMo conversations---1,935 matched text-only questions in total, 1,501 used in the primary aggregate after excluding Category 5 (adversarial) questions---at temperature 0, we find a consistent task-type interaction: gist compression substantially outperforms truncation on multi-hop reasoning and single-hop factual questions, but temporal questions remain substantially harder under compression, with compressed conditions scoring well below the full-context reference on the conversations where both are evaluated. We trace this failure to a specific mechanism: the gist abstraction prompt preserves relational and event structure while discarding dates and times. A preservation analysis across all ten conversations confirms the mechanism: an approximately 20-fold increase in temporal expression preservation (3.05% to 62.39%) with a one-sentence prompt modification, while named entity and event preservation rates barely change (x1.02 and x1.11), demonstrating that the fix is a precision instrument. The prompt modification recovers +0.314 [0.254, 0.375] judge accuracy on category-2 (temporal) questions in the matched set. Code and results: https://github.com/kyrkewood/sleeping-agent.

### 2. 方法论：核心思想与关键技术细节

- **框架名称**：Salience-Weighted Consolidation（SWC，显著性加权巩固），受睡眠记忆巩固机制启发，包含三个设计原则：
  1. **主动调度**（proactive scheduling）：在空闲窗口而非容量极限时进行巩固；
  2. **显著性加权保留**（salience-weighted retention）：按显著性打分并划分优先级层级；
  3. **分阶段压缩**（staged compression）：先显著性评分，再对中优先级内容做要点抽象。
- **Stage 1：显著性评分**（对每个 session chunk 计算三个信号加权得分）：
  - **下游相似度**（权重 0.4）：chunk 与后续 turn 嵌入的余弦相似度（使用 `all-MiniLM-L6-v2`，本地 CPU 计算）；
  - **近期性**（权重 0.3）：session 索引 ÷ 总 session 数；
  - **信息密度**（权重 0.3）：长度归一化的命名实体与数字计数。
  - 分区规则：≥0.6 高优先级（原样保留）、0.3–0.6 中优先级（gist 压缩）、<0.3 低优先级（丢弃）；最近两个 session 和 session 0 恒为高优先级。
- **Stage 2：Gist 抽象**：
  - **SWC-Full**：用 Claude Haiku 将中优先级内容压缩为 3–5 句段落，提示词要求保留：事实信息、因果关系、决策及其理由、未完成承诺/计划；**无任何保留日期/时间的指令**。
  - **SWC-Temporal**：与 SWC-Full 唯一区别是在提示词开头增加一句：*“You MUST preserve verbatim: all specific dates, times, durations, ages, and temporal expressions”*（必须逐字保留日期、时间、时长、年龄等时间表达）。
- **关键假设**：通过对比 SWC-Full 与 SWC-Temporal，可精确验证时间信息丢失是否由提示词遗漏导致。

  4. **SWC-Temporal**：SWC + 时间保护提示词（独立 REM 缓存）；

### 6. 主要结论与发现

1. **聚合结果（Table 1，Cat 1–4，N=1,501）**：
   - SWC-Temporal：0.468；SWC-Full：0.379；Sliding window：0.238；Truncation：0.171；

   - 多跳（Cat 1）：SWC-Full/Temporal 0.407/0.429，显著优于基线（0.157/0.271）；
   - 单跳（Cat 4）：SWC-Full/Temporal 0.459/0.486，显著优于基线（0.170/0.238）；
   - **时间类（Cat 2）**：SWC-Full 仅 0.156，接近截断（0.137）；**SWC-Temporal 提升至 0.470**；
   - 开放域（Cat 3）：所有条件 CI 重叠，无法得出结论。
3. **机制确认（保留率分析，Table 3）**：
   - 时间表达逐字保留率：3.05%（SWC-Full）→ **62.39%**（SWC-Temporal），约 20 倍提升；

4. **精确修复效果**：

5. **设计原则**：任何使用 gist 抽象的存�储系统都应**显式保护时间锚点**；类别级评估 + 保留率分析比单一聚合准确率更能揭示记忆策略的真实得失。

### 7. 优点

- **诊断式方法设计**：用简单可控的 SWC 作为探针而非竞争系统，避免了复杂系统间不可归因的问题；
- **机制证据链完整**：类别准确率模式、保留率量化、单变量消融三个独立来源相互印证，论证闭环；
- **精准确认与修复分离**：保留率分析确认了“选择性丢弃时间”这一具体机制；+0.314 的恢复效果证明了修复的精准性（时间 ×20，实体/事件 ×1.02/×1.11）；
- **评估方法严谨**：使用人类验证的 LLM-judge（95% 一致性）、温度 0 控制方差、Bootstrap CI、配对 delta 及逐对话方向一致性，客观性较好；
- **排除混淆**：排除类别 5（对抗性）问题，避免“删除内容”被误判为“记忆质量高”；报告了温度敏感性和原文滑动窗口基线；
- **可复现性**：公开代码与结果文件，模型/参数/提示词均详细公开。

### 8. 不足与局限

- **全上下文参考覆盖不全**：Full context 仅在对话 0–1 上评估（299 题），无法在所有对话上量化 gist 压缩相对于完整记忆的差距；
- **类别 3（开放域）无结论**：所有条件 CI 重叠，无法确定压缩策略对常识推理的影响；
- **保留率指标的保守性**：逐字保留率可能低估语义等价改写（paraphrase），即真实保留效果可能高于报告数值；
- **时间保护的泛化性未验证**：SWC-Temporal 的修复是否适用于其他压缩框架（如滑动窗口或 LightMem 式系统）未测试，属于未来工作；
- **调度机制不可验证**：SWC 的“主动调度”设计在离线基准上无法体现（无真正空闲窗口），SWC-Reactive 初步结果差异不大（0.452 vs 0.462），调度贡献未能作为有效结论；
- **对抗性问题被排除**：排除类别 5 虽有合理性（评分规则混淆），但意味论文未评估压缩策略在对抗性/不可答问题上的鲁棒性；
- **模型依赖与迁移限制**：实验仅在 Anthropic 系列模型（Sonnet 4.6 / Haiku）上验证，未检验其他厂商模型的通用性；
- **资源报告不完整**：未报告 API 调用成本、总体算力消耗或环境足迹，无法评估方法的实用性成本；
- **单个对话的异常值**：对话 1 中滑动窗口在类别 2 上异常高（0.520），虽以样本量小解释，但提示小 cell 可能带来不稳定统计。
