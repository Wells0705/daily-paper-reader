## 摘要
本研究探讨了使用大型语言模型的应用中会话交接的方法论和理论特性。当上下文达到模型输入限制、应用重新启动或要求另一个代理完成某项任务时，任务可能会在新会话中继续。此时，应用必须决定从先前会话中传递哪些信息。我们将交接定义为任务相关上下文学习（ICL）状态的转移，并区分了早期材料的精确恢复与目标分布的保持。在外生性条件下，预测等价性表征了最粗略的确定性充分交接，并给出了固定长度的比特需求。该分析隔离了记忆约束、编写者和续接过程的影响，并量化了在实现的下游查询已知之前进行编写的成本。我们提出了一种三部分记录，它精确存储决策和约束，对重复证据使用任务合理的统计量，并保留那些效果未被这些统计量保留的原始观测。高斯线性回归给出了精确的有限维交接和有限比特扰动界，而非参数回归则给出了将记忆与平方预测误差联系起来的上界和下界。这些结果为决定交接必须保留什么以及其记忆需求如何依赖于续接任务提供了理论和方法。

## Abstract
This study investigates the methodological and theoretical properties of session handover in applications that use large language models. A task may continue in a new session when the context reaches the model's input limit, when the application restarts, or when another agent is asked to finish the task. The application must then decide which information from the earlier session to pass on. We formulate handover as the transfer of a task-relative in-context learning (ICL) state and distinguish exact recovery of earlier material from preservation of the target distribution. Under an exogeneity condition, predictive equivalence characterizes the coarsest deterministic sufficient handover and gives a fixed-length bit requirement. The analysis isolates the effects of the memory constraint, the writer, and the continuation procedure, and quantifies the cost of writing before the realized downstream query is known. We propose a three-part record that stores decisions and constraints exactly, uses task-justified statistics for repeated evidence, and retains original observations whose effect is not preserved by those statistics. Gaussian linear regression gives an exact finite-dimensional handover and finite-bit perturbation bounds, while nonparametric regression gives upper and lower bounds that relate memory to squared prediction error. These results provide a theory and method for deciding what a handover must retain and how its memory requirement depends on the continuation task.

## 1. 核心问题与整体含义（研究动机与背景）

- 在大型语言模型（LLM）驱动的应用中，一个任务通常需要多次调用模型才能完成。当上下文长度达到模型输入上限、应用重启、或任务被转交给另一个代理时，任务必须在一个**新会话**中继续。
- 在会话边界，应用需要决定将哪些信息从旧会话传递给新会话。作者将这一过程称为**“会话交接”（session handover/handoff）**，传递的信息称为**“交接记录”（handover record）**，而生成该记录的程序或模型称为**“编写者”（writer）**。
- 论文的核心研究问题是：**一个交接记录必须保留什么信息，才能让新会话在预测或决策上等价于拥有完整旧上下文？** 以及**存储需求如何依赖于续接任务的性质？**
- 与常见的“提示压缩”（prompt compression）不同，会话交接通常发生在**下游查询尚未实现之前**，因此是一个“查询前状态编码”问题，而非“查询感知压缩”问题。
- 论文强调：交接的目标不是逐字复现旧对话，而是**保持任务相关的目标分布**。

## 2. 方法论：核心思想、关键技术细节与公式

### 2.1 形式化框架

- 用一个四元组 `ω = (C, T, X, Y)` 表示一个完整会话，其中：
  - `C`：交接前已有的对话、指令、示例、工具结果等；
  - `T`：编写者已知的任务信息（目标形式、评分规则等）；
  - `X`：交接后到达的未来查询或任务状态观测；
  - `Y`：用于评分的最终答案、状态或允许的动作。
- 交接记录 `H = (V, M)`，其中 `V` 是放入新会话提示中的记录，`M` 是外部文件/数据库等保留信息。
- 评价指标为期望损失 `R(E, D)`，其中 `E` 是编写者，`D` 是交接后所有下游行为（如提示构建、模型生成、解析、环境交互等）。

### 2.2 预测充分性

- **预测充分性（Predictive Sufficiency）** 定义为：

  `P(Y | C, X, T) = P(Y | H, X, T)`

  即给定交接记录后，目标分布与给定完整上下文时相同。
- **外生性条件（exogeneity）**：在固定任务 `t` 下，未来查询 `X` 的条件分布与上下文 `C` 无关（给定 `T = t`）。在此条件下，命题3.1证明：预测等价关系 `c ~t c'`（即对几乎所有后续查询，`P(Y|C=c,X=x,T=t)` 与 `P(Y|C=c',X=x,T=t)` 相同）给出了**最粗的确定性充分交接状态**。
- 推论3.2给出**固定长度码的比特下界**：若有 `N_t` 个不同的等价状态，则至少需要 `⌈log₂ N_t⌉` 比特。

### 2.3 损失分解

- 总超额风险可分解为：

  `R(E, Dθ) − R*_full = (R*_B − R*_full) + (R*_E − R*_B) + (R(E, Dθ) − R*_E)`

  三项分别表示：记忆预算导致的不可避免损失、所选编写者的额外损失、续接过程相对于理想解码器的额外损失。
- 对数损失下，信息丢失量精确等于条件互信息：

  `R*_log(H) − R*_log(C) = I(Y; C | H, X, T)`
- 定理3.5给出有限动作空间下决策损失的界：

  `0 ≤ R*_E − R*_full ≤ L_max √( I(Y; C | H, X, T) / 2 )`

### 2.4 查询前编码的代价

- 命题3.6用一个“伯努利坐标 → 均匀随机索引 → 异或输出”的例子说明：若编码器在实现查询前只能使用 `B` 比特，则实现查询后仍存在至少 `max(0, 1 − B/m)` 比特的对数损失；而查询感知编码器只需1比特即可零损失。这量化了“先写后问”的信息代价。

### 2.5 提出三部分记录方法

  `H = (H_exact, H_stat, H_residual)`

- `H_exact`：精确记录当前目标、决策、约束、未解决问题及其来源（不可模糊化或改写）。
- `H_stat`：仅当任务提供显式保证或误差界时，用统计量（如充分统计量或带误差界的近似量）替换重复出现的示例或工具结果。
- `H_residual`：保留那些未被 `H_stat` 覆盖的原始观测——当统计量无法保证保留其作用时。
- 该方法要求在预算 `B` 内最小化理想风险，同时满足 `S_exact = r_exact(H, T)` 的精确可恢复性。

### 2.6 回归统计结果

#### 高斯线性回归（参数情形）

- 模型：`y_i = x_i^T β + ε_i, ε_i ~ N(0, σ²)`，先验 `β ~ N(m0, V0)`。
- **定理5.1**：记录 `H_n = (G_n, b_n)`（其中 `G_n = X_n^T X_n`，`b_n = X_n^T y_n`）是预测充分的，即

  `I(Y; X_n, y_n | H_n, x, T) = 0`

  这是一个有限维实值状态，不随样本数增长。
- **定理5.2**：通过特征分解构造“合成充分演示” `(Ẋ, ẏ)`，使得 `Ẋ^T Ẋ = G_n`，`Ẋ^T ẏ = b_n`，从而原样本与合成样本具有相同的后验分布和岭估计。
- **定理5.3**：量化了当统计量被量化后，后验协方差和均值扰动的上界。
- **推论5.4–5.6**：给出有限精度下的预测对数损失界、有限比特编码长度以及指数衰减的预测KL散度界。

#### 非参数回归

- 模型：`Y_i = f(X_i) + ε_i`，其中 `f` 属于 β-Hölder 类，输入在 `[0,1]^d` 上。
- 简单方法：将输入空间划分为 `M = m^d` 个单元，记录每个单元中的计数 `N_j` 和响应和 `S_j`（或均值），并对均值量化。
- **定理5.7**：风险上界为

  `C1 M^{-2β/d} + C2 M/n + C3 exp(−n p_min / M) + C4 q²`

  其中分别对应逼近误差、抽样误差、空单元误差和量化误差。
- 当选择 `M ≍ n^{d/(2β+d)}`，`q ≍ n^{−β/(2β+d)}` 时，风险达到全数据情形下的最优率 `n^{-2β/(2β+d)}`。
- **推论5.8**：达到该率所需比特数为 `O(n^{d/(2β+d)} log n)`。
- **定理5.10**：给出下界

  `R_{n,B} ≥ c max( n^{-2β/(2β+d)}, (B+1)^{-2β/d} )`

  表明记忆限制与样本量会各自产生误差下限。

### 2.7 信息等价记录

- **命题6.1**：若 `H2 = s(H1, T)` 且反之 `H1 = r(H2, T)`（互相可确定），则两个记录的理想风险相等。

## 6. 主要结论与发现

- 会话交接本质上是一个**查询前状态编码问题**，与查询感知压缩有本质区别。
- 在持有外生性条件时，预测等价性给出了**最粗的确定性充分交接状态**及其比特下界。
- 所提出的三部分记录方法能够在理论上同时保证：决策/约束的精确性、重复证据的压缩安全性、以及特殊观测的保留。
- 高斯线性回归中，存在**有限维充分统计量**（ `G_n, b_n`），其大小与样本数无关；量化后仍可获得有限的预测误差界。
- 非参数回归中，记忆需求必须随函数类的复杂度和目标精度增长；下界表明需要 `Θ((B+1)^{-2β/d})` 级别的误差。
- 理想风险相等的记录之间，任何差异都来源于**续接过程的表示能力**，而非信息量差异。
