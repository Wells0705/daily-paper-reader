## 摘要
虽然大型语言模型（LLM）智能体越来越多地依赖长期记忆进行持久交互，但管理这种记忆的检索机制很少被视为可进化的组件。这种静态方法限制了在异构记忆查询上的性能，这些查询通常需要多样化的证据构建策略。为了解决这个问题，我们引入了 \textbf{ERSkill}，一个以检索为中心的自我进化、技能引导的记忆访问框架。ERSkill 将交互历史编译为结构化的记忆存储，并将检索行为表示为由基本原语组成的可执行技能。在推理时，训练好的路由器动态地将每个查询匹配到最优技能，以构建针对性的证据用于答案生成。为了实现持续改进，ERSkill 在训练期间共同进化技能集和路由器。它采用经验前缀树来高效记录已探索的检索路径，并采用双前沿机制，将新技能能力的扩展与稳定的、面向路由器的部署安全地解耦。在多个智能体记忆基准上的实验表明，ERSkill 显著优于强大的非进化和自我进化基线。值得注意的是，在使用 Qwen3-Next-80B-A3B-Instruct 时，它在 F1、BLEU-1 和 LLM-judge 分数上的总体平均值提高了 31.3\%，在使用 GPT-5.4-nano 时提高了 28.1\%。

## Abstract
While Large Language Model (LLM) agents increasingly rely on long-term memory for persistent interactions, the retrieval mechanisms governing this memory are rarely treated as evolvable components. This static approach limits performance on heterogeneous memory queries, which often demand diverse evidence construction strategies. To address this, we introduce \textbf{ERSkill}, a retrieval-centric framework for self-evolving, skill-guided memory access. ERSkill compiles interaction histories into a structured memory store and represents retrieval behaviors as executable skills composed of fundamental primitives. At inference time, a trained router dynamically matches each query to the optimal skill to construct tailored evidence for answer generation. To enable continuous improvement, ERSkill co-evolves the skill set and the router during training. It employs an experience trie to efficiently record explored retrieval paths, alongside a double-frontier mechanism that safely decouples the expansion of new skill capabilities from stable, router-facing deployment. Experiments across multiple agent memory benchmarks demonstrate that ERSkill substantially outperforms strong non-evolving and self-evolving baselines. Notably, it improves the overall average across F1, BLEU-1, and LLM-judge scores by 31.3\% with Qwen3-Next-80B-A3B-Instruct and by 28.1\% with GPT-5.4-nano.

- **研究动机**：LLM 智能体在长期交互中依赖外部记忆存储历史信息，但现有记忆系统的检索机制通常是**静态固定的**，很少被当作可进化的组件。
- **核心问题**：不同的查询（如事实性单跳、多跳因果推理、时间敏感检索）需要不同的证据构建策略，固定检索策略无法适应这种异构信息需求，因此性能受限。
- **整体含义**：论文提出将记忆访问建模为**技能引导的自适应证据构建**，使检索行为本身能够通过历史经验持续进化，从而提升长期记忆问答的效果。

## 2. 方法论

- **核心思想**：把检索行为抽象为可执行技能，并让技能集与路由器在训练中共同进化。

- **记忆存储**：将交互历史 D 编译为结构化记忆 M(D) = (A, I, G)：
  - A 为原子级记忆记录（含文本、元数据、时间戳）。
  - I 为索引集合（稠密索引、实体-原子索引等）。
  - G 为图结构（相似度图、关系图），用于扩展证据。

- **检索原语库**：固定不随进化变化，包括三类：
  - 搜索原语：`entity_search`、`lexical_search`、`dense_search`
  - 扩展原语：`temporal_focus_expand`、`similarity_expand`、`relation_expand`
  - 处理原语：`llm_process`（查询重写、证据过滤、控制变量生成等）

- **检索技能**：一个技能 κ = (c_κ, ρ_κ)，其中 c_κ 是技能描述与信息偏好，ρ_κ 是原语序列。技能按序执行原语更新证据状态，最终形成供答案生成的证据视图。

- **技能路由器**：通过共享编码器 Enc(·) 编码查询和技能，再用可学习的打分函数 u_θ(q, κ) 计算匹配度，经 softmax 归一化得到技能选择概率：
  
  R_θ(κ | q, K) = exp(u_θ(q, κ)) / Σ_{κ'∈K} exp(u_θ(q, κ'))

- **技能-路由器共进化**：
  - **技能候选生成**：基于当前能力前沿，通过编辑原语路径生成新技能候选；利用经验 trie 记录已探索的路径，避免重复探索。
  - **能力前沿更新**：使用前沿重组算子 Φ，在保证所有查询 oracle 最优分数不下降的前提下，剪除冗余技能。先通过训练批次粗筛，再在验证集上精化。
  - **路由器更新**：使用历史 rollout 数据，以 soft-label 交叉熵损失训练路由器，目标分布由真实分数 softmax 生成。
  - **部署前沿更新**：仅在能力前沿变化时尝试更新部署前沿，需满足路由性能提升（或小幅下降但集合更紧凑）的条件，否则保持原部署前沿。
  - **命题 2.1** 证明两个前沿在验证集上的 oracle 覆盖率均非下降，保证进化安全。

## 6. 主要结论与发现

- ERSkill 在全部基准上取得最佳整体性能，将 F1、BLEU-1 和 LLM-judge 的平均分数相对最强基线提升：
  - Qwen3-Next-80B-A3B-Instruct 上提升 **31.3%**
  - GPT-5.4-nano 上提升 **28.1%**
- 在 LongMemEval 上直接跨数据集复用训练好的技能与路由器，仍然最强，说明学到的检索技能具有一定的可迁移性。
- 成本-性能分析显示，ERSkill 在记忆构建和推理开销方面均处于较优区间，同时达到最高 L-J 分数，说明提升来自针对性的证据构建而非简单的检索量增加。
- 消融结果显示，技能进化与路由器学习是性能提升的关键；双前沿和经验 trie 则分别保证稳定性和探索效率。
- 进化过程能稳定提升 oracle 覆盖并控制前沿规模，多轮运行结果波动小，进化稳健。
