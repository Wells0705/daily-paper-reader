## 摘要
随着智能体任务日益复杂，LLM智能体越来越依赖经验记忆以跨任务复用程序性知识。有效的记忆设计必须同时处理存储内容、记忆的结构与检索方式，以及记忆的演化。现有系统仅部分地解决这些问题：它们将轨迹、洞察或工作流存储为孤立条目，丢弃了子任务与可复用技能之间的组合关系；通过平面嵌入相似度进行检索，忽略了关系信号；并且在维护记忆时未利用其关系结构。我们提出HyperSkill，一个基于超图的记忆框架，同时改进这三个方面。HyperSkill将记忆表示为具有两种节点类型的超图：子任务步骤和可复用技能，其中每条超边连接来自单一轨迹的子任务和技能。双路径检索同时查询子任务层和轨迹层，根据检索轨迹中的共现情况对技能进行排序。周期性的结构感知维护通过质量加权传播剪除低效用节点并合并冗余技能。在xBench、GAIA和WebWalkerQA上，结合GPT-4o和Qwen3-30B-A3B，HyperSkill优于十个记忆基线，在GAIA上最高提升+11.51，在WebWalkerQA上最高提升+11.18。

## Abstract
As agentic tasks grow in complexity, LLM agents increasingly rely on experiential memory to reuse procedural knowledge across tasks. Effective memory design must jointly address what to store, how memory is structured and retrieved, and how memory evolves. Existing systems tackle each only partially: they store trajectories, insights, or workflows as isolated entries, discarding compositional relationships among subtasks and reusable skills; retrieve by flat embedding similarity that ignores relational signals; and maintain memory without leveraging its relational structure. We propose HyperSkill, a hypergraph-based memory framework that jointly improves all three. HyperSkill represents memory as a hypergraph with two node types, subtask steps and reusable skills, where each hyperedge links the subtasks and skills from a single trajectory. Dual-path retrieval queries both subtask and trajectory levels, ranking skills by co-occurrence across retrieved trajectories. Periodic structure-informed maintenance prunes low-utility nodes and merges redundant skills via quality-weighted propagation. Across xBench, GAIA, and WebWalkerQA with GPT-4o and Qwen3-30B-A3B, HyperSkill outperforms ten memory baselines, yielding gains of up to +11.51 on GAIA and +11.18 on WebWalkerQA.

## 2. 论文提出的方法论

### 2.1 核心思想
HyperSkill 将经验记忆组织为超图 \( G = (V, E) \)。每个轨迹被存储为一条超边，绑定该轨迹中的子任务分解和技能节点，并用超边同时记录原始任务描述、蒸馏课程（lesson）与效用分数（utility score），从而在单一统一记忆结构中同时编码组合式任务分解与可复用执行知识。

### 2.2 关键设计细节

**节点设计**（\( V = V_u \cup V_s \)）：

- **子任务节点** \( V_u \)：编码任务分解中的一个步骤（含前置条件），反映组合性工作流结构；
- **技能节点** \( V_s \)：通过结果条件提示提取的可复用知识，成功轨迹产出正向策略，失败轨迹产出错误模式；
- 每个节点带效用分数 \( \gamma \in [0,1] \)，综合经验成功率与步数效率：
  \[
  \gamma = \beta \cdot \frac{\sigma}{\nu} + (1-\beta) \cdot \left(1 - \frac{\bar{T} - T_{\min}}{T_{\max} - T_{\min}}\right)
  \]

**超边设计**：每条超边对应一条轨迹，由子任务节点集合 \( V_u^j \)、技能节点集合 \( V_s^j \)、任务描述 \( d_j \) 与蒸馏课程 \( \ell_j \) 组成，用于检索的嵌入为 \( h_e = \phi(d_j \| \ell_j) \)。

**双路径检索**：
- **子任务路径**：将当前任务分解为子任务序列 \( P_0 \)，匹配存储的子任务节点，通过关联超边扩展得到候选轨迹集 \( E_{\text{sub}} \)；
- **轨迹路径**：直接将任务描述与超边嵌入匹配，得到候选轨迹集 \( E_{\text{traj}} \)；
- 两路融合 \( E^* = E_{\text{sub}} \cup E_{\text{traj}} \)，前者捕获表面不同但程序结构相似的轨迹，后者捕获高层语义相关的轨迹。

**共现排序的技能检索**：
- 候选技能为融合轨迹集中所有超边的技能节点并集；
- 按技能在**检索到的超边中的出现次数** \( \kappa(v) \) 排序——这是一个纯结构化信号，语义相似度无法提供；
- 平局时以嵌入相似度打破。

**周期性的结构感知维护**（每 \( \lceil 0.1N \rceil \) 个任务触发一次）：
- **质量驱动修剪**：删除被检索次数足够多但效用持续低于阈值的节点；
- **结构信息合并**：对技能节点构造质量加权共现矩阵，经 L 步对称传播获得结构嵌入，对相似度超阈值的节点对调用 LLM 合并为高阶技能，并重新分配超边成员关系。
