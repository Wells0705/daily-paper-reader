## 摘要
大型语言模型（LLM）代理通过多角色、多阶段工作流协调复杂任务。上游状态被反复转换为中间语言产物，如摘要、计划、工单、记忆和交接说明，下游组件据此行动。对于约束行动的状态，主题保留是不够的：一个产物可能提及一个未解决的条件，同时将其从执行前必须解决的要求转变为可能仅仅为下一个行动提供信息的信息。我们将这种行动绑定作用研究为操作状态保留。安全阻断器提供了一个受控实例，因为每个源状态都有明确的先决条件、权限、回退和执行后果。我们以正确的上游识别为条件，改变交接转换，并评估限于所得产物的执行器。在1,296个受控合成情节中，直接交接控制保留了每一个阻断器，而压缩、计划同化、收敛、所有权推迟和先例替换反复将绑定状态变成警告或非绑定考虑。正常交接压缩产生100.0%的失活和54.2%的禁止行动。恢复所有四个状态字段将保留率提高到100.0%，并将禁止行动降至0.0%。固定产物干预进一步将保留与遏制分开：下游验证消除了禁止行动，而产物失活仍为95.3%。这些结果识别了信息提取与行动之间的状态传输失败。交接转换可以保留状态内容，同时削弱其对下游行动的约束。语义可用性并不能保证操作保留。

## Abstract
Large language model (LLM) agents coordinate complex tasks through multi-role and multi-stage workflows. Upstream state is repeatedly transformed into intermediate language artifacts, such as summaries, plans, tickets, memories, and handoff notes, from which downstream components act. For action-constraining state, topical retention is insufficient: an artifact may mention an unresolved condition while changing it from a requirement that must be resolved before execution into information that may merely inform the next action. We study this action-binding role as operational state preservation. Safety blockers provide a controlled instance because each source state has an explicit prerequisite, authority, fallback, and execution consequence. We condition on correct upstream identification, vary the handoff transformation, and evaluate an executor restricted to the resulting artifact. Across 1,296 controlled synthetic episodes, direct-handoff controls preserve every blocker, whereas compression, plan assimilation, convergence, ownership deferral, and precedent substitution repeatedly turn binding state into caveats or non-binding considerations. Normal handoff compression produces 100.0% deactivation and 54.2% forbidden action. Restoring all four state fields raises preservation to 100.0% and reduces forbidden action to 0.0%. Fixed-artifact interventions further separate preservation from containment: downstream verification eliminates forbidden action while artifact deactivation remains 95.3%. These results identify a state-transmission failure between information extraction and action. Handoff transformations can retain state content while weakening its constraints on downstream action. Semantic availability does not guarantee operational preservation.

## 1. 核心问题与整体含义

- **研究动机**：LLM 智能体通过多角色、多阶段工作流协调复杂任务。上游状态（如审查结论、审批状态、安全约束）被反复转化为中间语言产物——摘要、计划、工单、记忆、交接笔记等，下游组件仅依据这些产物执行操作。问题在于：**中间产物可能保留了命题内容，却削弱了该命题对下游行动的约束力**——"必须解决"变成了"仅供参考"。
- **核心矛盾**：论文提出关键公式 `语义可用性 ⇏ 操作保留`。传统事实性研究（summarization faithfulness）只关心压缩文本是否忠实于源命题；但在代理工作流中，还需要一个**操作坐标**：一个被保留的命题是否继续约束它原本为之引入的那个行动。
- **研究对象**：论文将其定义为 **操作状态保留（Operational State Preservation）**——即已确立的绑定状态（binding state）在经过语言转换后，能否继续以同样的强制力约束下游行动。
- **整体含义**：工作流协调不仅仅是传递信息，更是**传递状态的操作角色**。这一中间转换层（信息提取与行动之间）长期被复合评估所掩盖，论文首次将其隔离为独立可测的估计目标。

## 2. 方法论

### 2.1 核心思想

论文采用**阶段分离设计（stage-separated design）**，将状态确立、制品转换和端点执行三个环节拆开，使得"上游是否正确识别"与"转换是否丢失约束力"是两个独立可检验的问题。科学对象是 **绑定工作流状态**，以 **安全拦截器（safety blockers）** 作为受控实例。

### 2.2 状态四字段表示

每个安全拦截器源状态用四元组表示：

```
z = (s, q, o, f)
```

- `s`：停止状态（stop status）——是否标记为"不得继续"
- `q`：未解决的先决条件（unresolved prerequisite）
- `o`：负责解决的权威/否决点（authority / veto point）
- `f`：可接受的回退方案（admissible fallback）

### 2.3 核心指标

- **P（操作保留）**：制品是否继续让执行以解决源状态为条件
- **D（去活化）**：有明确证据表明绑定角色已被降级（如变为警告、延迟检查、省略）
- **U（残余态）**：P = 0 且 D = 0，两种规则均不满足
- **C（四字段完整保留）**：四个字段全部可恢复，独立于 P
- **Y（禁止动作）**：执行器在默认放行执行层下实施了被禁止的动作

P 和 D 互斥但非逻辑互补。

### 2.4 五种语言转换族

| 变换族 | 操作 | 测试的状态变化 |
|--------|------|----------------|
| 压缩 Compression | 摘要、工单、多跳交接 | 先决条件/所有者/回退消失，停止变为提示 |
| 收敛 Convergence | 重复低风险框架、一致同意 | 反对状态被同化，显式阻断变为表面共识 |
| 计划同化 Plan assimilation | 拦截器被并入已有计划 | 停止条件变为对计划的一项修改 |
| 所有权延迟 Ownership deferral | 审批被推迟或本地化 | 责任移向下游，所有者变为未指定的后续检查 |
| 先例替换 Precedent substitution | 历史例外作为当前授权 | 缺失授权变为假定授权 |

### 2.5 估计量（Estimands）

以 `D_up = 1` 表示正确上游识别为条件：

- 变换导致的保留损失：`ΔPτ = E[P(hτ0) − P(hτ) | Dup=1]`
- 去活化增加：`ΔDτ = E[D(hτ) − D(hτ0) | Dup=1]`
- 禁止动作增加：`ΔYτ = E[Y(hτ) − Y(hτ0) | Dup=1]`

固定制品修复 `g` 与端点验证 `v` 分别估计制品层恢复与端点层遏制，二者针对不同的估计目标。

## 6. 主要结论与发现

1. **直接交接完全保留状态**：所有直接对照组均 100% 保留、0% 去活化、0% 禁止动作——正确检测与合法执行可同时实现。
2. **变换导致系统性约束弱化**：
   - 所有权延迟（P4）去活化 +76.7 点，禁止动作 +60.8 点
   - 多跳压缩（S3）去活化 +97.2 点，禁止动作 +31.9 点
   - 收敛框架（E4）去活化 +76.4 点，禁止动作 +33.3 点
   - 计划同化（C4）去活化 +65.3 点，禁止动作 +29.2 点
3. **退化模式是"角色转变"而非"内容遗漏"**：制品常保留风险语言，但先决条件或回退消失——从"约束行动"变为"仅供参考"。
4. **压缩存在阈值效应**：正常压缩即达到 100% 去活化；端点禁止动作率非单调（54.2% → 83.3% → 79.2%）。
5. **修复与遏制是可分离的系统功能**：恢复四字段将 P 和 C 拉回 100%、禁止动作归零；但端点验证（软/硬检查、权限查找、人工审批）在制品 P 仍仅 4.7% 的情况下可将禁止动作降到 0–1.6%——**修复改变制品，验证改变端点，二者互补不可替代**。
6. **语义可用性不保证操作保留**：这是论文最核心的结论——信息被保留 ≠ 约束力被保留。

## 7. 优点

- **阶段分离设计**：将"上游识别错误"与"转换过程退化"分开，精确归因失败环节，避免了复合评估的混淆。
- **受控合成 + 匹配对比**：零事件对照使每个变换的因果效应可独立识别，合成构造提供高质量匹配源状态。
- **固定制品干预**（leave-one-field-out 和端点验证）：在保持制品固定时分离"制品层修复"与"端点层遏制"，方法学上非常清晰。
- **测量严谨性**：盲审 240 制品 × 5 模型、留一评审者分析、检查器与人工标签一致性（macro F1 0.916）验证了测量工具的可迁移性；标签翻转压力测试为结论标注明确证据状态。
- **跨配置传输分析**：13 个模型变体、框架适配（LangGraph/AutoGen）、释义变体、上下文隔离审计，体现了对结论外部有效性的认真态度。
- **统计严谨**：任务聚簇 bootstrap 区间保留重复任务依赖结构，未以独立情节假设计算置信区间。

## 8. 不足与局限

- **任务覆盖面有限**：全部为合成企业任务中的安全拦截器类状态（6 个领域），是否适用于真实生产环境的复杂多状态流转、动态涌现约束等仍需验证。
- **模型配置抽样非穷尽**：13 个模型变体反映的是"该采样下可观测的迁移"，而非"所有LLM的普遍规律"；主面板中不同模型的退化率差异极大（如 GPT-5.4-mini 仅 0% 禁止动作，DS-V4-Pro thinking 达 58.3%）。
- **权威字段测量可靠性偏低**：所有权分配字段的评审间一致性为 65.25%（κ 0.636），因此关于该组件的结论证据范围更窄。
- **端点必要性排序不明确**：留一字段实验中，缺少先决条件/权威/回退均产生 0% 禁止动作，只有遗漏标签产生 7.0% 禁止动作——四个字段对端点行为的相对重要性在现有精度下无法判定。
