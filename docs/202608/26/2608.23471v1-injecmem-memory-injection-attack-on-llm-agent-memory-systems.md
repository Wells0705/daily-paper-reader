## 摘要
记忆正逐渐成为已部署LLM智能体中的默认子系统，以提供持久化的个性化和连续性。这自然引出一个问题：记忆系统是否会为智能体引入新的漏洞？为此，我们提出了InjecMEM，一种新颖的记忆注入攻击范式，仅需一次交互（无需对记忆存储的读取/编辑权限）即可将后续相关查询的响应引导至预设输出。在记忆系统“检索-然后-生成”机制的引导下，我们通过一个与检索器无关的锚点和一个对抗性命令来构造注入。锚点包含高召回率的主题线索，使得下游检索能将记录稳定关联到目标主题。命令是一个短序列，经过优化，在不确定的融合上下文、可变位置和长提示下保持有效，从而在检索到后可靠地引导输出。我们通过基于梯度的坐标搜索学习该命令，对合成提示模板和插入位置进行平均，并将其扩展到跨骨干网络的联合优化以研究迁移性。在多种记忆系统和骨干模型上的评估表明，InjecMEM实现了可靠的主题条件检索和定向生成，在记忆漂移下保持有效，且不影响非目标查询。我们的结果强调了加固记忆系统的必要性，并为研究智能体记忆提供了可复现的框架。

## Abstract
Memory is becoming a default subsystem in deployed LLM agents to provide persistent personalization and continuity. This naturally prompts a question: will memory system introduce new vulnerabilities into agents? Thus we propose InjecMEM, a novel memory injection attack paradigm that requires only a single interaction (no read/edit access to memory store) to steer later responses of related queries toward a pre-specified output. Guided by the retrieval-then-generate mechanism of memory systems, we craft the injection with a retriever-agnostic anchor and an adversarial command. The anchor contains high-recall topical cues so that downstream retrieval consistently associates the record with the target topic. The command is a short sequence optimized to remain effective under uncertain fused contexts, variable placements, and long prompts so that it reliably steers outputs once retrieved. We learn the command via gradient-based coordinate search, averaging over synthetic prompt templates and insertion positions, and extend it to joint optimization across backbones to study transfer. Evaluated across multiple memory systems and backbone models, InjecMEM achieves reliable topic-conditioned retrieval and targeted generation, remains effective under memory drift, and leaves non-target queries unaffected. Our results underscore the need to harden memory systems and provide a reproducible framework for studying agent memory.

## 2. 论文提出的方法论

### 核心思想

- 将一次注入输入拆分为两部分：
  - **检索侧锚点（retriever-agnostic anchor）**：负责使注入记录被后续目标主题查询稳定检索到。
  - **生成侧对抗命令（adversarial command）**：负责在注入记录进入最终提示（fused prompt）后，将模型输出导向预设目标输出 \(A^\star\)。

### 锚点构造

- 针对**窄主题**（如背痛）：在锚点中加入直接关键字指令和简短主题段落，以同时提升嵌入相似度和关键字重叠度。
- 针对**宽领域**（如健康）：构造“质心锚点”（centroid anchor），包含领域标签 + 高召回关键词（如 ache, symptom, treatment）+ 领域内常见意图列表，使混合检索在用户查询词汇多样时仍能稳定命中。
- 锚点不针对特定嵌入器优化，因此是检索器无关的。

### 对抗命令优化：Multi-GCG

- 传统 GCG 等方法假设固定提示布局，在记忆系统中因**动态上下文、可变注入位置、提示长度增长**而失效。
- **Multi-GCG**（Algorithm 1）通过以下机制增强鲁棒性：
  - 构造多个合成代理提示（surrogate prompts），模拟记忆系统融合后的最终提示格式。
  - 对每个代理提示定义多个插入位置。
  - 每次迭代采样一批“（代理提示，插入位置）”对，计算目标输出的平均负对数似然损失。
  - 用基于梯度的坐标搜索：对每个字符位置计算词汇梯度，选取 Top-K 候选，通过宽度为 \(W\) 的随机搜索替换 \(R\) 个位置，保留最小损失候选。
- 由此得到对**上下文漂移、位置稀释、长提示噪声**都具有鲁棒性的短命令。

### 扩展优化变体

- **FJ-Multi-GCG**（Algorithm 2）：针对同一模型族、共享 tokenizer 的多个骨干进行联合优化，提升家族内迁移（例如优化于 1.5B+7B，迁移到 3B/14B）。
- **CF-Multi-GCG**（Algorithm 3）：针对不同 tokenizer 的模型族进行联合优化，使用规范字符串表示，并引入 `MapGradient`（Algorithm 4）进行跨 tokenizer 梯度投影。

### 威胁模型

- **攻击者能力**：记忆子系统为黑盒；骨干 LLM 可白盒访问；仅一次交互；无存储读写权限。
- **攻击目标**：
  - Goal 1：最大化主题条件检索成功率（RSR）。
  - Goal 2：给定检索发生后，最大化指定输出的生成成功率（ASR-c）。
  - 同时要求对非目标查询不产生影响。

## 6. 论文的主要结论与发现

- **攻击有效性强**：在 MemoryOS 上，InjecMEM 平均 RSR@50 为 35.4%，ASR-c 为 76.6%，ASR-j 为 35.6%；而 DPI、BadChain、GCG 三类基线在生成侧均完全失败（0%），证明记忆系统动态融合环境会使传统静态注入失效。
- **锚点设计显著影响持久检索**：质心锚点比单纯主题段落具有更好的长期检索保持能力，在记忆漂移下更稳健。
- **跨系统泛化**：在 MemGPT 上同样取得非平凡结果（RSR 37.2%、ASR-c 48.6%、ASR-j 18.1%）。

  - 同一模型族内，命令可迁移；通过家族联合优化可显著提升到未参与优化的 3B / 14B 变体，并保持对微调模型有效。

- **防御评估结论**：论文测试了多种防御机制（LLM-as-a-Judge、ProtectAI、PromptGuard、困惑度过滤）。其中 LLM-as-a-Judge 对注入命令有一定识别能力，但存在较高的良性误拦截率（BBR），且对部分对抗命令仍会漏检；基于困惑度的过滤在现实对话分布下难以有效区分注入记录与正常内容；整体上现有防御尚未能同时实现高检出率与低误伤率，记忆系统的对抗鲁棒性仍处于空白状态。

- **核心理论意义**：InjecMEM 表明，记忆系统的“持久性”本质上是攻击者的“持久驻留”能力——一次注入、长期生效、多会话可用。这突破了传统提示注入的瞬时性，将攻击转化为对系统状态的控制。

## 7. 局限性与未来工作

- **局限性**：
  - 攻击假设攻击者能对骨干 LLM 进行白盒访问以优化命令，实际中许多 API 只提供黑盒访问，限制了该攻击的直接适用性。
  - 多目标联合优化（CF-Multi-GCG）依赖跨模型族的共享 tokenizer 映射，若模型族之间词汇重叠极低，优化效率会明显下降。
  - 评估主要基于英文数据和合成对话，对多语言、多轮长期交互场景的覆盖不足。
  - 对记忆系统的实现依赖（如检索算法、融合策略）未做系统性敏感度分析，不同记忆系统间的结论可能不完全一致。
- **未来方向**：
  - 探索无白盒条件的替代优化方法（如基于 RL 或进化策略的黑盒攻击）。
  - 研究针对记忆系统本身的防御设计，如记忆写入的语义检查、记录来源溯源、检索结果的可信度评分、以及对抗训练。
  - 建立更贴近真实部署的记忆系统基准，覆盖长期会话、多用户共享存储、多模态记忆等场景。
  - 将攻击扩展到隐式记忆（如向量数据库缓存、嵌入索引更新）与其他 agent 组件（规划、工具选择）交互上。
