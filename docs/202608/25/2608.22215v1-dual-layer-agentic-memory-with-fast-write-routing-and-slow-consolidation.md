## 摘要
大型语言模型（LLM）智能体在动态环境中运行，其中知识不断演变。现有记忆系统通常将外部记忆视为单调增长的存储库，不可避免地导致检索性能下降并随时间增加计算成本。我们认为核心挑战不仅仅是检索，而是管理知识生命周期：决定外部化、更新还是最终内化什么。受神经科学中互补学习系统（CLS）理论的启发，我们提出了双层智能体记忆（Dual-Layer Agentic Memory）框架，该框架通过成本感知的认知路由和周期性参数整合，将记忆管理转移到写入阶段。传入信息被分类为不写入、写入新内容或写入更新内容，并通过小到大的模型级联进行路由，以最小化路由开销同时过滤冗余记忆。后续的回写阶段通过监督微调选择性将高价值外部记忆整合到模型参数中。实验证明了我们方法的双重效率：一个1.7B/8B级联可剪除高达68%的冗余外部记忆，同时仅升级不到50%的输入，却保留了详尽保留基线所达到的下游问答精确匹配（EM）的98%以上。我们进一步表明，周期性整合能成功地将外部知识内化，使路由器能够随着模型认知边界的发展自适应地抑制冗余写入。总体而言，我们的框架为智能体记忆提供了一个统一范式：选择性外部化后接选择性内化。代码和数据集将在录用后发布。

## Abstract
Large language model (LLM) agents operate in dynamic environments where knowledge continuously evolves. Existing memory systems typically treat external memory as a monotonically growing repository, inevitably leading to retrieval degradation and increasing computational costs over time. We argue that the core challenge is not retrieval alone, but managing the knowledge lifecycle: deciding what to externalize, update, or ultimately internalize. Inspired by Complementary Learning Systems (CLS) theory in neuroscience, we propose Dual-Layer Agentic Memory, a framework that shifts memory management to the write phase through cost-aware epistemic routing and periodic parametric consolidation. Incoming information is categorized as non-write, write-new, or write-update, and routed through a small-to-large model cascade that minimizes routing overhead while filtering redundant memories. A subsequent write-back phase selectively consolidates high-value external memories into model parameters via supervised fine-tuning. Experiments demonstrate the dual efficiency of our approach: a 1.7B/8B cascade prunes up to 68% of redundant external memory while escalating fewer than 50% of inputs, yet retains over 98% of the downstream QA Exact Match (EM) achieved by an exhaustive retention baseline. We further show that periodic consolidation successfully internalizes external knowledge, allowing the router to adaptively suppress redundant writes as the model's epistemic boundaries evolve. Overall, our framework presents a unified paradigm for agent memory: selective externalization followed by selective internalization. Code and dataset will be released upon acceptance.

## 1. 核心问题与整体含义

**研究动机**：LLM 智能体长期运行在知识不断演变的动态环境中（如多轮对话、自主研究、个人助理）。现有记忆系统存在根本性缺陷——它们将外部记忆视为**单调增长的无条件日志**，读写过滤主要依赖查询驱动的读取阶段，无法在源头拒绝冗余信息。这导致随外部记忆膨胀，检索噪音增大、成本上升、延迟加剧，形成"存储-性能"的根本性权衡。

**核心洞见**：作者指出，记忆管理的真正挑战不在检索本身，而在**知识生命周期的完整管理**——决定哪些知识需要外部化、更新、或最终内化到模型参数中。基于神经科学中的互补学习系统（CLS）理论，论文将外部记忆类比为海马体（快速编码新经验的可编辑缓冲区），将参数记忆类比为新皮层（逐步巩固稳定知识的慢速长期表征），从而建立一个统一的双层知识生命周期框架。

## 2. 方法论

### 2.1 核心框架：载体层 + 决策层

- **载体层**：维持两类记忆基质——参数记忆 Θ（稳定、压缩、访问成本低）和外部记忆 E（显式、可编辑、适合动态或冲突性事实）。
- **决策层**：包含快速写入路由（决定新知识是否进入外部记忆）和慢速回写机制（通过 SFT 将高价值外部记忆内部化为参数）。

### 2.2 操作性记忆分类法

基于模型在零样本 vs 记忆支撑下的回答行为差异，将传入知识分为三类：

- **non-write**：模型零样本即能正确回答，无需外部存储；
- **write-new**：零样本下拒绝回答（暴露参数缺失），提供知识后回答正确；
- **write-update**：零样本下给出自信但错误的回答（表明参数知识过时），提供知识后回答正确。

### 2.3 小到大级联的快速写入路由

- **级联架构**：小模型路由器（qwen3-1.7B 骨干网 + 轻量 MLP 决策头）先做低成本前端筛选，只有不确定/模糊的样本才升级到大模型路由器（qwen3-8B 骨干网）。
- **路由目标**：写入奖励定义为 r(W) = EM(W) − EM(D) − λs，丢弃奖励为 0，其中 EM 表示下游 QA 精确匹配得分，λs 为存储惩罚项。
- **升级门控**：门控模块预测升级增益 g\* = Vlarge − Vsmall，其中 Vsmall 为小路由器决策的期望价值，Vlarge 为大路由器决策的期望价值减去升级惩罚 λe。推理时仅当 gpred > 0 才升级，从而在 EM 与计算开销之间折衷。
- **特征构造**：从冻结的 LLM 骨干网提取两类特征——语义特征（最后一层隐藏状态的均值池化）和不确定性特征（token 级负对数似然的均值 + 序列长度 + 重采样为 64 维的 NLL 曲线）。MLP 头以 MSE 损失回归奖励目标。

### 2.4 慢速回写整合（知识内化）

- 将保留的 write-new / write-update 事实转化为两类监督信号：独立问答样本 + 句子级目标，通过标准 SFT 因果语言建模目标优化参数。
- **验证机制**：只有当更新后的模型在无检索条件下正确回答该事实的探针问题（EM 均值 ≥ τflush）时，该事实才从外部记忆移除；否则保留。成功整合的事实完成整个生命周期：外部化 → 内化 → 从外部记忆驱逐。

## 3. 实验设计

### 3.1 基准数据集与流式评测场景

- **基础语料**：来自 Zero-Shot Relation Extraction（ZsRE）基准，经严格过滤后保留 201,352 个唯一事实，每个事实配 30 个多样化改写探针，共 6,040,560 个查询。
- **在线流式评测基准**（核心创新）：现有基准静态地同时呈现知识背景和查询，混淆了"是否存储"和"检索什么"两个挑战。本文设计了 300 个流式 episodes，每个 episode 含 500 轮交错对话，注入 100 条候选事实和下游 QA 交互。事实以时间顺序流式到达，系统必须在遇到关联查询**之前**做出写入/丢弃决策，从而有效解耦记忆准入与检索。关键性质包括：覆盖性（每个事实注入且至少被探测一次）、因果性（查询不早于其支持事实出现）、活跃性（第 0 轮至少注入一个事实）、干扰分布（类别分布与测试集自然分布一致）。

### 3.2 对比方法

- **静态策略**：No Store、Full Store、Random Store（p=0.5/0.8）
- **启发式策略**：Heuristic Store（显式探测模型置信度）、PPL-Conditional Store（基于困惑度阈值）
- **监督策略**：Logistic Regression、MLP Classifier（与本文大路由器共享架构，但用 BCE 优化）
- **本文方法**：Write Router（基于冻结基础模型特征）、Write Router SFT（1.7B 和 8B 骨干网均经过回写整合阶段）

### 3.3 主要评估指标

下游 QA 质量（EM、token 级 F1、拒绝率）、存储决策质量（存储率、存储精确率/召回率/F1）、系统效率（路由计算成本）。

## 6. 主要结论与发现

1. **级联路由实现"双效率"**：1.7B/8B 级联仅升级 39.7%–49.0% 的输入到 8B 模型（计算成本降低约 30%–39%），剪除高达 68% 的冗余外部记忆，同时保留 Full Store 基线上界的 98.3% 的 QA EM——在存储与计算双重维度上优于静态、启发式乃至完整 8B 监督策略。

2. **周期性整合实现知识内化与自适应偏移**：SFT 回写后，路由器感知到模型参数能力的提升，自适应地将存储率从 64.81% 压缩至 32.08%（同时保持 97.85% 的存储精确率），最终以极小的外部依赖实现 90.71% 的 QA EM（保留 Full Store 的 98.2%）。

3. **参数干扰（干扰现象）反向验证了双体架构的必要性**：事实级转移矩阵显示，SFT 虽使 10,683 个此前依赖检索的事实实现参数化内化（non-write），但有 **1,752 个此前稳定的事实退化**为 write-update（参数干扰/灾难性遗忘）。这实证地确认了保持外部记忆层作为纠错缓冲的必要性。

4. **消融实验确认技术选择的合理性**：语义特征 + 不确定性特征组合最优；均值池化 + MSE 训练优于末 token 池化和边距排序；学得的门控能有效弥合小/大路由器之间的差距。

## 7. 优点

- **概念创新**：将记忆管理从"读取阶段的被动过滤"前移到"写入阶段的主动准入控制"，把记忆建模为选择性外部化 + 选择性内化的闭环生命周期，创新性地将 CLS 理论系统化地映射到 LLM 智能体记忆架构。
- **系统设计精妙**：小到大级联路由器不仅优化了存储效率，还优化了**路由策略本身的推理成本**；门控机制通过预测升级增益实现了 EM-存储-计算三维空间的 Pareto 前沿追踪。
- **操作性定义清晰**：基于模型行为（零样本 vs 记忆支撑下的回答差异）而非抽象语义判断来定义记忆类别，使训练目标和评估指标高度可操作、可复现。
- **评测基准设计严谨**：在线流式评测通过严格的结构化调度算法（分层注入 + 前馈预算分配 + 因果探针流式采样）确保因果合法性和类别分布自然性，在 O(T log T) 时间内生成确定性、可复现的评测环境。
- **知识生命周期闭环验证**：从写入路由 → 外部存储 → SFT 整合 → 验证通过 → 驱逐 → 路由器感知参数变化并自适应丢弃重复事实，形成了完整的闭环验证链条。

## 8. 不足与局限

- **经验干扰缺少主动缓解**：论文观察到 SFT 引起的参数干扰（1,752 个事实退化），但框架本身仅依赖外部记忆缓冲来弥补，未在回写阶段主动实现防遗忘机制（如情节回放或权重正则化），作者在局限中也承认了这一点。
- **离线 SFT 的延迟与计算成本高**：回写整合是离线的批量过程，导致内化延迟和可观的计算开销。探索在线参数高效适配（如在线 LoRA）是未来方向。
- **缺乏冲突消解机制**：整合时将所有外部记忆视为均匀数据集，缺乏处理周期之间累积的**时间冲突更新**的原则性机制——如果两个周期中同一事实被不同地更新，系统如何解决冲突没有明确定义。
- **泛化性验证不足**：单一模型家族（Qwen3）、单一数据集（ZsRE）、单一关系抽取任务，缺乏跨模型规模、跨任务类型（如多跳推理、对话记忆）的验证。
- **统计报告不完整**：未报告误差条、置信区间或多随机种子方差，虽然大规模确定性评测部分缓解了这一问题，但严谨性仍有提升空间。
- **计算资源细节缺失**：未报告训练时长、能耗、单次实验的 GPU 利用率等可复现性关键信息。
- **可复现性受限**：代码和数据集需等论文接收后才发布，且未提供超参数搜索的完整配置细节（如学习率、epoch 数、批大小）。
