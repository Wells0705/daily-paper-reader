## 摘要
长期记忆对于个性化响应和长周期智能体交互至关重要。现有方法通常依赖LLM压缩或重写对话历史，并将转换后的记忆用作检索证据。尽管在组织碎片化上下文方面取得了进展，但仍存在两个主要缺陷：（1）压缩导致的信息丢失，丢弃了细粒度但后续有用的细节；（2）重写导致的语义漂移，削弱了原始语气和情境上下文。在这项工作中，我们提出了一种新颖的面向长期智能体记忆的人类画像增强检索优化框架（HERO）。具体而言，HERO将对话历史转换为可追踪的异构记忆图，保留原始对话文本作为推理证据，从而减轻信息丢失。在检索方面，HERO从当前查询中提取初始锚点，并通过迭代图遍历融入人类画像；这些锚点和画像提供引导信号，自适应地激活图中信息最丰富的区域。在两个基准数据集上的实验表明，HERO在事实推理和个性化推理上均优于强基线，同时提供对原始对话证据更忠实的访问。

## Abstract
Long-term memory is crucial for personalized responses and long-horizon agent interactions. Existing methods often rely on LLMs to compress or rewrite dialogue histories and use the transformed memories as retrieval evidence. Despite the progress in organizing fragmented contexts, two major drawbacks persist: (1) information loss from compression, which discards fine-grained but later useful details, and (2) semantic drift from rewriting, which erodes the original tone and situated context. In this work, we propose a novel Human-profile Enhanced Retrieval Optimization framework for long-term agent memory (HERO). Specifically, HERO converts the dialogue history into a traceable heterogeneous memory graph that preserves raw dialogue text as evidence for reasoning, thereby mitigating information loss. For retrieval, HERO extracts initial anchors from the current query and incorporates human profiles via an iterative graph traversal; these anchors and profiles provide guidance signals that adaptively activate the most informative regions of the graph. Experiments on two benchmark datasets show that HERO outperforms strong baselines on both factual and personalized reasoning, while providing more faithful access to raw dialogue evidence.

## 1. 核心问题与整体含义（研究动机与背景）

长期记忆是构建个性化、长周期智能体交互系统的核心能力。然而，现有长期记忆方法普遍存在两个关键缺陷：

- **信息丢失（Information Loss）**：基于LLM压缩或改写对话历史的方案，在写入阶段就不可逆地丢弃了当时看似次要、但后续可能关键的细节（如时间引用、因果条件、数值事实、细微偏好变化）。
- **语义漂移（Semantic Drift）**：将对话重写为摘要、画像或标准化记忆单元时，即使保留了主要事实，用户的原始措辞、情感色彩、说话人归属和情境上下文也会被削弱。

这两大问题源于现有方法对LLM抽象、压缩和再叙述能力的过度依赖，与人类认知科学中情节记忆（Episodic Memory）的工作方式相悖。作者主张：**原始对话痕迹应作为情节证据被完整保留，而高层画像信息仅用于引导记忆激活，而非替代记忆本身**。

## 2. 方法论：HERO框架

### 2.1 核心思想

HERO遵循人类认知启发的原则，将长期记忆组织为一个**以情节为中心的异构记忆图**（Episodic-centered Heterogeneous Memory Graph），实现"原始文本保真 + 画像引导检索"的协同工作方式。

### 2.2 记忆构建（Memory Construction）

图结构 G = (V, E)，包含两层：

**情节层（Episodic Layer）**——忠实记录原始对话：
- **Episodic Traces（Vt）**：按语义连贯的会话或时间窗口划分的局部场景记忆，包含完整原文、时间戳、顺序索引。
- **Episodic Units（Vu）**：由Trace进一步切分的原子级句子单元，是证据的基本载体，保留细粒度上下文约束。
- **Episodic Cues（Vc_epi）**：从单元中提取的实体和关键词，作为关联桥梁，不同单元中提取的实体经归一化合并为共享节点。

**画像层（Profile Layer）**——用于理解用户：
- **Profile Insights（Vp）**：从每个情节Trace中提炼的人类中心信息，涵盖事实（Facts）、洞察（Insights）、特质（Traits）。
- **Profile Cues（Vc_pro）**：从画像节点提取的细粒度实体，将抽象画像链接回全局语义空间。

**三类边：**
1. **结构包含边**：连接细粒度单元/画像节点到其来源Trace。
2. **语义索引边**：带权重的检索线索–情节Trace/画像连接，权重基于共现频率。
3. **时间链路边**：连接相邻Trace以保留时间顺序。

### 2.3 记忆检索（Memory Retrieval）

检索过程分三个阶段：

**阶段一：初始锚点识别**——从查询q中提取实体集Eq，与线索节点VC匹配，生成初始激活集S0。

**阶段二：迭代上下文扩展**——模拟人类"顺着线索回忆"的过程，执行K次迭代：
1. 语义扩展：通过余弦相似度纳入同义词节点。
2. 上下文收集：从当前线索的邻接节点中选取情节单元和画像洞察。
3. 查询相关性过滤：通过阈值τiter筛选与查询相关的上下文。
4. 新线索激活：激活与所选上下文相连的新线索节点，并通过前序线索权重 × 上下文–查询相似度传递激活权重。

**阶段三：全局相关性传播与证据排序**：
- 计算情节Trace的激活强度 W(vt)，结合稠密检索相关性和线索匹配奖励：
  - **W(vt) = α·sim(Φ(vt), Φ(q)) + log(1 + Σ_c W(c)·ln(1+f(c,vt))/Lc)**
- 构建重启向量r，在图中执行**个性化PageRank（PPR）**，同时掩蔽画像洞察节点（vp），确保传播仅流经证据承载节点。
- 最终按PPR分数排序，重排序后返回Top-k情节Trace作为LLM的推理证据。

## 6. 主要结论与发现

1. **保留原文优于压缩改写**：HERO在LoCoMo所有任务类型上全面超越基于LLM重写的基线（如Mem0、MemoryOS），证明原始情节证据的保真度对事实性问答至关重要。
2. **异质图支持跨会话推理**：HERO在多跳任务上达到85.11%准确率，说明图拓扑结构能有效链接时间上分散但语义相关的证据片段（如"yoga class→colleague→Rob"的推理链）。
3. **画像层提升个性化能力**：在PERSONAMEM上，HERO在偏好对齐推荐（80.00%）、追踪偏好演化（72.66%）等维度显著领先；消融实验显示去掉画像层后准确率下降约2个百分点。
4. **效率–性能兼顾**：HERO平均每次查询仅消耗248 token、延迟低于1秒，实现最高F1同时保持低开销，得益于将重活前置到构建阶段、检索阶段只做轻量图遍历。
5. **不依赖精细调参**：超参数在中等范围内变化时性能波动小（LoCoMo ACC稳定在0.801–0.829区间）。
6. **跨LLM稳健**：在GPT-4o-mini和不同Qwen骨干下均保持一致优势。

## 7. 优点

- **认知科学启发**：明确区分"情节记忆"（原始痕迹）与"语义记忆"（画像抽象），符合人类记忆系统的工作机制，而非简单依赖LLM的压缩能力。
- **保真性设计**：构建的异质图保留了完整的原始对话文本作为最终证据，从根源上避免压缩性信息损失和重写性语义漂移。
- **画像仅作导航**：画像节点只参与检索引导、不直接作为生成证据，在传播中被掩蔽，降低了将模型生成的有噪声抽象作为答案基础的风险。
- **双通道检索机制**：同时处理显式事实检索（线索–情节路径）和隐式跨会话依赖（线索–画像路径），并能通过查询相关性过滤控制主题漂移。
- **可增量更新**：新对话只需创建局部节点/边并合并新线索，无需全图重建，支持长期部署。
- **实验系统性较强**：涵盖了主实验、消融、超参数敏感性、骨干稳健性、效率、案例研究等多个维度，验证较全面。

## 8. 不足与局限

### 实验覆盖
- **生命周期机制缺失**：当前实现没有显式的记忆生命周期管理，如时间感知衰减、陈旧痕迹剪枝、用户控制删除等功能，长期部署可能面临记忆膨胀问题。
- **开放域任务表现相对偏弱**：LoCoMo开放域任务Recall仅0.604（@5），因为部分问题需要外部常识，对话历史本身不充分。
- **PERSONAMEM上的"Suggest New Ideas"维度仅37.63%**，远低于其他维度，说明该框架在创造性扩展方面的能力仍有明显短板。
- **消融实验使用Qwen3-30B-A3B而非主实验骨干**，与主结果存在一定的可比性差距。

### 偏差风险
- **画像抽取依赖LLM**：虽然画像仅作为检索导航信号，不直接影响生成证据，但不准确的画像线索仍可能将检索引向错误方向。
- **跨方法公平性**：不同基线使用各自官方管道或托管版本，底层预处理、评估代码可能不一致，存在比较偏差风险。
- **数据集规模有限**：LoCoMo仅10段对话，样本量较小；PERSONAMEM为模拟数据，真实场景效果有待验证。
- **未讨论多语言场景**：所有实验基于英文数据集，中文或其他语言下的表现未知（尽管作者来自中国移动，可能有内部应用场景）。

### 应用限制
- 需要LLM参与线索提取和画像提炼，构建阶段仍有一定token开销（每用户约20万token）。
- 隐私合规方面，存储用户对话历史和画像需要明确的数据治理政策，论文仅给出建议性说明，未提供具体机制。
- 与生产级RAG系统相比，异质图的维护复杂度较高，需要额外的工程投入。
