## 摘要
长期语言模型智能体会在多次交互中积累记忆，但其检索器通常不会积累检索经验。语义检索效率高，但嵌入相似度并不总能反映某段记忆是否包含与当前查询相关的证据。大型语言模型（LLM）重排序器能够提供更强的查询条件相关性评分，然而无状态重排序会反复对大量候选记忆进行评分，并在每次查询后丢弃这些分数。我们提出了 EARM，一种经验摊销重排序框架，将先前获得的 LLM 相关性分数视为可复用的检索经验。EARM 在在线矩阵中存储稀疏的查询-记忆相关性分数，通过因果矩阵补全学习其共享结构，并将少量新观测到的分数与估计分数相结合，以对剩余候选记忆进行重排序。评分预算随着经验积累而减少，使 LLM 重排序从每次查询的重复开销转变为在智能体生命周期中学习到的检索能力。在长期对话记忆上的实验表明，混合观测与估计的重排序相较于语义检索能将答案准确率提升最高达 6.62%，并且当仅有 17.5% 的候选记忆获得直接 LLM 相关性分数时仍保持有效，从而大幅降低 LLM 重排序的推理开销。这些结果促使人们以更广阔的视角看待智能体记忆：长寿的智能体不仅应记住过去的内容，还应记住这些内容如何被证明对检索有用。

## Abstract
Long-term language-model agents accumulate memories across interactions, but their retrievers typically do not accumulate retrieval experience. Semantic retrieval is efficient, but embedding similarity does not always reflect whether a memory contains evidence relevant to the current query. Large language model (LLM) rerankers provide stronger query-conditioned relevance scores, yet stateless reranking repeatedly scores a large candidate pool and discards these scores after each query. We introduce EARM, an experience-amortized reranking framework that treats previously acquired LLM relevance scores as reusable retrieval experience. EARM stores sparse query--memory relevance scores in an online matrix, learns their shared structure through causal matrix completion, and combines a small set of newly observed scores with estimated scores to rerank the remaining candidates. The scoring budget decreases as experience accumulates, changing LLM reranking from a repeated per-query expense into a retrieval capability learned over an agent's lifetime. Experiments on long-term conversational memory show that mixed observed-and-estimated reranking improves answer accuracy over semantic retrieval by up to 6.62% and remains effective when only 17.5% of candidates receive direct LLM relevance scores, thereby substantially reducing the inference overhead of LLM reranking. These results motivate a broader view of agent memory: a long-lived agent should remember not only past content, but also how that content has proved useful for retrieval.

长期语言模型智能体会在多次交互中持续积累记忆，但现有的检索机制存在一个基本不对称：**记忆库随交互不断演进，检索过程却对每次查询都从同一初始状态开始**。传统的语义检索（嵌入相似度）虽然高效，但“表示相似”并不等于“与查询相关的记忆证据”；而更准确的 LLM 重排序器虽然能提供更强的查询条件相关性评分，却在**每次查询后丢弃分数**，属于无状态重排序，导致重复计算开销。

## 2. 论文提出的方法论：核心思想、关键技术细节

### 2.1 总体框架

论文提出 **EARM（Experience-Amortized Reranking for Memory，经验摊销记忆重排序）** 框架，包含五个核心组件：

### 2.2 技术细节与流程

1. **语义候选生成（Semantic Candidate Generation）**：使用嵌入相似度检索，从全部记忆库中筛选出 N 个候选记忆（论文中 N=200）。这一阶段保持高召回率，但不决定最终排序。

2. **检索经验矩阵（Retrieval Experience Matrix）**：构建一个稀疏矩阵 R(t) ∈ ℝ^(|I_t|×t)，其中每行代表一条持久记忆，每列代表一个查询，已观测的条目记录 LLM 重排序器给出的相关性分数 s_LLM ∈ [0,1]。该矩阵区分两种未观测情形：
   - 记忆被检索但未直接评分
   - 记忆在库中但未被当前查询的语义检索召回

3. **分阶段经验获取（Stage-Wise Experience Acquisition）**：将查询流划分为多个经验阶段，观测比例 ρ 随时间递减（100% → 40% → 25% → 20% → 17.5%）。每个阶段将评分预算在“高相似度层”和“其余候选”之间各半分配，兼顾利用（exploitation）与探索（exploration）。

4. **因果相关补全（Causal Relevance Completion）**：采用偏置感知低秩模型估计缺失分数：

   R̂ᵢτ = μ + αᵢ + βτ + pᵢᵀzτ

   其中 μ 是全局偏差，αᵢ 是记忆偏置，βτ 是查询偏置，pᵢ 和 zτ 分别是记忆与查询的潜在因子。模型通过带 L2 正则化的最小二乘（ALS）最小化掩码重建误差，**采用热启动（warm start）** 从先前解继续优化，且强制严格因果掩码——不能使用未来查询的信息。

5. **混合重排序与上下文构建（Mixed Reranking）**：对于每个候选记忆，若观测到直接 LLM 分数则使用该分数，否则使用补全的估计分数；排序后取最高分的 K 个记忆，但**恢复为时间顺序**再交给答案生成模型，保持对话的时间连贯性。

### 2.3 关键创新

- 将传统“每次查询重复评分并丢弃”的无状态重排序，转变为跨查询累积“检索记忆”的持续学习过程。
- 补全矩阵中历史支持但被当前语义检索遗漏的记忆（“白格”），使语义检索从**不可逆的边界**变为**柔性的软边界**，支持搜索扩展。
- 与简单缓存（cache）不同，EARM 可跨不同查询泛化，只要新查询的锚点能连接到历史学习到的低秩结构即可，无需查询完全相同。

## 3. 实验设计

### 3.1 数据集与 Benchmark

- **数据集**：LoCoMo（Long-term Conversational Memory benchmark），包含长对话与测试长期对话记忆的问题。
- **问题类型**：多跳（multi-hop）、开放域（open-domain）、单跳（single-hop）、时间性（temporal）问题。
- **存储管道**：采用 Mem0 的记忆提取与存储管道，仅修改检索与重排序环节。记忆库在评估前构建完毕且固定，仅查询列与观测分数随查询时间累积。

### 3.2 模型与配置

- **LLM 相关性评分器**：Qwen3.5-4B-Q8₀
- **答案生成器**：GPT-4o-mini（将重排序后按时间顺序排列的 Top-K 记忆作为上下文）
- **答案评估器**：GPT-4o-mini（LLM-as-a-Judge）
- **语义检索**：检索 N=200 个候选；Top-K ∈ {10, 20}

### 3.3 基线方法

| 基线 | 定义 |
|------|------|
| Semantic | 仅语义检索，不进行 LLM 重排序 |
| Full LLM reranking | 对全部 200 个候选进行 LLM 评分再排序 |
| Observed-only | 禁用补全，仅将直接评分的记忆放入上下文 |
| Mixed（EARM）| 按公式 (6) 混合观测与补全分数排序 |

### 3.4 实验分组

- 查询按块分组（每块 10 个查询），对应 5 个经验阶段（B1–B5+），观测比例从 100% 降至 17.5%。
- 低秩维度 r ∈ {2, 8}；ℓ2 正则化系数 0.1；ALS 最多 5,000 次迭代，收敛阈值为 10⁻⁶。

## 6. 论文的主要结论与发现

1. **总体提升显著**：Top-10 设置下，r=8 的 EARM 将总体准确率从语义检索的 82.21% 提升至 88.83%（+6.62%），距全量 LLM 重排序（91.62%）仅 2.79% 的差距。多跳问题提升最大（+10.29%），单跳次之（+7.25%）。

2. **低直接评分比例下仍有效**：当观测比例降至 17.5%（B5+ 阶段），r=8 的 EARM 在 Top-10 仍比语义检索提高 5.53%。这表明累积的检索经验在直接评分稀疏时仍然有用。

3. **补全记忆并非多余，而是独立增益来源**：补全分数选择的记忆在每种配置下都带来额外 0.78–2.79% 的准确率提升，说明矩阵补全对上下文质量的贡献不亚于直接观测的分数。

4. **大幅降低推理开销**：EARM 的 LLM 重排序调用量仅为全量重排序的 25.57%（减少 74.43%），同时保留了全量重排序约 56%–70% 的收益。

5. **核心启示**：长期智能体不仅应积累内容记忆，还应积累“检索记忆”——即内容对检索有用性的经验。这使 LLM 重排序从固定成本转变为随时间摊销的学习能力。

## 8. 不足与局限

### 8.1 论文明确承认的局限

1. **预算调度过于静态**：观测比率按查询索引预定义，不对模型不确定性、分布偏移或冷启动记忆做自适应调整。某些阶段可能浪费评分预算，而另一些阶段可能预算不足。

2. **低秩结构假设**：矩阵补全假设可复用的低维结构；若查询流高度异构、相关性模式缺乏共享结构，历史分数对新查询的借鉴价值有限。

3. **评分噪声传播**：点式 LLM 相关性分数可能有噪声、校准偏差和提示敏感性，补全可能传播重排序器本身的错误而不仅仅是降低成本。

4. **假设约束**：记忆身份需保持稳定；若记忆条目被频繁合并、重写或语义漂移，行参数会失效。

### 8.2 额外可指出的不足

1. **实验范围有限**：仅在 LoCoMo 一个数据集上评估，缺少跨基准的泛化验证；也未见在真实智能体/生产环境中的部署测试。

2. **统计严谨性不足**：未报告多次运行的方差、置信区间或显著性检验，块级准确率差异（如 B4 的 81% vs B5+ 的 89.65%）可能部分来自评估方差而非方法差异。

3. **冷启动问题**：矩阵补全需要历史行支持；新写入的记忆（无历史评分记录）无法获得估计分数，只能依赖随机探索抽样，论文未对此进行深入分析。

4. **扩展性与存储开销未充分讨论**：在线矩阵随查询数量线性增长，ALS 每次更新的计算成本随时间累积；论文未评估长期运行中的时间与空间复杂度。

5. **与 RAG/推荐系统的对比不足**：尽管引用了推荐系统中的矩阵分解相关工作，但未与基于强化学习（如 MemRL）或其他经验复用方法做实验对比，仅做了理论区分。

6. **LLM 评估器的潜在偏差**：使用 LLM-as-a-Judge 评估答案质量，评估器本身可能有偏好偏差；且答案生成与评估均使用 GPT-4o-mini，存在模型同源偏差的可能性。
