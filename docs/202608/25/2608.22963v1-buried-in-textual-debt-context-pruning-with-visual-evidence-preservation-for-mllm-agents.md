## 摘要
多模态大语言模型（MLLM）正越来越多地被部署为多步骤智能体，其中显式推理支持任务分解和工具协调，但同时也会积累自生成文本。在长轨迹中，这些文本可能主导上下文并压制视觉证据，从而产生文本债务。我们观察到，一旦任务相关的视觉证据得到落实，推理就会变得冗余；而当落实仍不确定时，过时的假设可能会误导后续推理。因此，剪枝必须在不丢弃视觉证据的前提下移除冗余文本。我们提出SPARE，一个基于Kullback--Leibler（KL）散度引导的框架，用于修剪多模态工具使用智能体中累积的推理内容。SPARE使用紧凑的任务状态摘要作为特权诊断上下文。对于每个候选片段，它在原始上下文和摘要条件下重放同一模型。基于策略内自蒸馏（OPSD）的反向KL散度随后检验摘要在不干扰未来推理的情况下是否充分覆盖该片段。我们进一步使用监督微调（SFT）对摘要器进行微调，从而实现更紧凑的摘要、更广的覆盖范围和更激进的剪枝。在多个多步骤视觉工具使用基准上，SPARE在剪枝方法中实现了最高的平均准确率，同时移除了37.89–64.58%的推理令牌。这种优良的准确率–上下文权衡表明，减少文本主导地位能够恢复对视觉证据的依赖，并缓解对自生成语言的过度条件化。

## Abstract
Multimodal Large Language Models (MLLMs) are increasingly deployed as multi-step agents, where explicit reasoning supports task decomposition and tool coordination but also accumulates self-generated text. Over long trajectories, this text can dominate the context and suppress visual evidence, creating textual debt. We observe that reasoning becomes redundant once task-relevant visual evidence is grounded, while stale hypotheses can misguide later inference when grounding remains uncertain. Pruning must therefore remove redundant text without discarding visual evidence. We propose SPARE, a Kullback--Leibler (KL)-guided framework for pruning accumulated reasoning in multimodal tool-use agents. SPARE uses a compact task-state summary as privileged diagnostic context. For each candidate segment, it replays the same model under the original and summary-conditioned contexts. Reverse-KL divergence from on-policy self-distillation (OPSD) then tests whether the summary sufficiently covers the segment without disrupting future reasoning. We further fine-tune the summarizer with supervised fine-tuning (SFT), enabling more compact summaries, broader coverage, and more aggressive pruning. Across multi-step visual tool-use benchmarks, SPARE achieves the highest average accuracy among pruning methods while removing 37.89--64.58\% of reasoning tokens. This favorable accuracy--context trade-off shows that reducing textual dominance restores reliance on visual evidence and mitigates over-conditioning on self-generated language.

## 一、核心问题与研究动机

- **背景**：多模态大语言模型（MLLM）越来越多地被部署为多步骤智能体（agent），需要通过显式推理来分解任务、协调工具调用、解读中间观测结果。然而，每个交互步骤都会向工作上下文中追加自生成的文本。
- **核心问题（"文本债务"）**：在长轨迹中，累积的自生成文本逐渐主导上下文，压制视觉证据，使模型越来越依赖自己的计划、描述和假设，而非外部的视觉证据。这种冗余文本被称为 **textual debt（文本债务）**。
- **关键观察**：
  - 当早期推理已正确捕捉任务相关的视觉证据时，累积文本尚可作为图像的忠实抽象；
  - 但当早期推理未能关注相关视觉区域时，模型会在不完整或弱grounding的文本状态上继续发挥，使多余推理变成"过时假设"，误导后续推理。
- **研究意义**：剪枝推理词元不仅是减小计算量或序列长度，更是一种**grounding机制**——通过减少对过时文本的过度条件化，恢复模型重新关注视觉输入的机会。

## 二、方法论：SPARE框架

### 2.1 核心思想

SPARE（Selective Pruning of Accumulated Reasoning with Visual Evidence Preservation，选择性累积推理剪枝与视觉证据保留）将上下文压缩重新定义为**轻量级、证据保留的选择性遗忘问题**。其核心做法是：**用紧凑的任务状态摘要作为"特权诊断上下文"（privileged diagnostic context），而非替代历史**——不直接用摘要覆盖轨迹，而是检验每个历史片段是否包含超出摘要的信息。

### 2.2 关键技术细节

**（1）自适应摘要触发（Adaptive summary trigger）**
- 仅在智能体自身调用内部 `summarize_the_task` 工具并生成紧凑任务状态摘要 σ 后触发剪枝；
- 短轨迹无剪枝开销，长轨迹仅在显式产生紧凑状态后才被考虑剪枝。

**（2）摘要条件重放（Summary-conditioned replay）**
- 对候选推理片段序列 x，在两种上下文下重放：
  - 学生上下文：ρ_stu = ρ₀（仅共享系统、工具、任务前缀）；
  - 教师上下文：ρ_tea = ρ₀ ∥ σ（额外加入摘要 σ 作为特权信息）。
- 同一模型 πθ 在两种条件下分别产生 token 级续写分布 p_stu 和 p_tea，不引入外部教师模型。

**（3）Top-K 反向 KL 覆盖度评分**
- 对每个重放 token 位置 k，在学生 top-K（K=20）词汇支持集上计算截断反向 KL：
  dₖ = Σ_{u∈Ω_stu} p_stu(u) · [log p_stu(u) − log p_tea(u)]
- 高值表示该 token 对摘要敏感（摘要未覆盖，需保留）；低值表示摘要已充分解释。
- 在每次剪枝事件内做 min-max 归一化：d̃ₖ = (dₖ − d_min)/(d_max − d_min + ε)。

**（4）片段级剪枝（Segment-level pruning）**
- 采用**计数式保留规则**（count-based rule），而非平均值：

  Keep(hᵢ) = 1 当且仅当 |{k ∈ Pᵢ : d̃ₖ > τ}| ≥ κ

  默认 τ = 0.2，κ = 2。
- **选择计数而非平均的理由**：模态关键证据往往是稀疏的（如 OCR 字符串、坐标、边界框、候选标签），平均化会稀释这些信号，计数规则能保守地保留含稀疏高敏感 token 的片段。

**（5）证据保留式重建（Evidence-preserving pruning）**
- 摘要仅用作辅助诊断上下文，**不写入持久轨迹**，避免改写伪影；
- 高 KL 片段（含摘要无法覆盖的信息）被重建为简洁、可核验的结构化视觉证据（如裁剪位置、识别文本、数值、候选间关系）；
- 低 KL 片段整段删除（信息已被摘要覆盖）；
- 工具调用 JSON、工具观测、图像 token 一律保持不变。

**（6）SFT 增强摘要器**
- 收集 376 条 Qwen3-VL-8B 在 VTC-Bench 上的 on-policy 轨迹，用 Qwen3-235B 生成紧凑任务状态摘要，再用标准 next-token 目标微调 8B 摘要器；
- 更强摘要器扩大覆盖范围，使更多片段落入低残差可剪枝区间，实现更激进剪枝。

## 六、主要结论与发现

1. **文本债务是 MLLM 智能体的关键失效模式**：累积自生成推理主导上下文、弱化视觉证据依赖；
2. **剪枝推理词元可以作为 grounding 机制**：减少对过时文本的过度条件化，恢复视觉证据在深层推理中的影响；
3. **SPARE 在性能与压缩间取得最优权衡**：在剪枝方法中平均准确率最高，同时去除 37.89%–64.58% 的推理词元；
4. **摘要能力与剪枝强度正相关**：SFT 增强摘要器可安全地扩大剪枝范围；
5. **注意力证据**：剪枝后各层 text-to-image 注意力普遍上升，直接支持"减少文本主导恢复视觉依赖"的核心主张。

## 七、方法优点

- 🔑 **问题重定义新颖**：将上下文压缩重构为"证据保留的选择性遗忘"，视角独特且贴合多步智能体实际；
- 🔑 **无需外部模型的自蒸馏诊断**：OPSD 思想仅作为诊断原则，同一模型同时充当教师和学生，测试时零额外参数；
- 🔑 **计数式保留规则设计巧妙**：针对"关键证据稀疏分布"这一特性，避免平均值稀释危险信号；
- 🔑 **摘要作为"瞬时探针"而非轨迹替代品**：避免改写伪影，设计克制且可解释；
- 🔑 **自适应触发机制实用**：短轨迹零开销，长轨迹按需剪枝；
- 🔑 **实验验证链条完整**：从端到端性能、机制诊断到注意力可视化，多角度支撑文本债务假说。

## 八、不足与局限

- **适用面受限**：仅针对多步工具使用智能体（含显式推理和工具历史），对单轮或无结构智能体不直接适用；
- **额外推理开销**：摘要生成 + 两次上下文重放带来临时计算成本，论文未提供端到端延迟的量化评估；
- **受控诊断规模偏小**：文本干扰诊断的案例数较少，统计效力有限；
- **超参数固定缺乏跨域验证**：τ = 0.2、κ = 2 在所有实验统一，虽显示了局部稳定性（κ=1 与 κ=2 结果相同），但更广泛场景的敏感性未充分探索；
- **SFT 适用范围有限**：仅对一个 8B 骨干、两个基准验证；Qwen3-235B 蒸馏的摘要质量对最终效果的影响未做深入剖析；
- **较弱骨干上的解释力受限**：Nemotron 上工具轨迹本身可能带来负干扰，文本债务与工具能力不足的交互效应未被充分区分。
