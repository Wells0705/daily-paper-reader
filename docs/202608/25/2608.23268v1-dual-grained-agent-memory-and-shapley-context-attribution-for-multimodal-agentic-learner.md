## 摘要
前沿多模态大语言模型（MLLMs）展现出令人印象深刻的感知能力，但在科学和数学推理方面仍显不足。对于闭权重或设备端骨干模型，参数级自适应不可用，而无状态提示则无法从已解决的问题中获得任何累积收益。我们提出DG-Mem，一种双粒度智能体记忆框架，通过非参数化、外部存储的记忆增强冻结的MLLM，该记忆在训练时的一次性rollout中构建，并在测试时只读访问。受人类记忆的互补学习系统（CLS）解释启发，DG-Mem将其存储分为实例级范例记忆和类别级IF-THEN规则模式记忆，并通过瞬态反思存储介导其构建，使得模式仅从抽象反思中综合，绝不从范例文本中生成。两个设计选择使DG-Mem脱颖而出：一种在线概念分类器，在训练期间逐步增长类别空间，而非预设固定分类法；以及一种Shapley上下文归因程序，将正确性分解到整个检索到的规则集中，并生成每个规则的有用性度量，以在测试时重新加权检索。该流程不引入梯度更新，可部署于闭权重或设备端骨干模型。在MathVista、MMMU和MMMU-Pro上，使用四种开放权重和专有骨干模型（Qwen3.5-27B、Qwen3.5-122B-A10B、GPT-5-Nano、Gemini-3-Flash），DG-Mem在无记忆和竞争性记忆基线上均实现了一致改进。

## Abstract
Frontier multimodal large language models (MLLMs) deliver impressive perception yet still falter on scientific and mathematical reasoning. Parameter-level adaptation is unavailable for closed-weight or on-device backbones, and stateless prompting forfeits any compounding benefit from problems already solved. We propose \textbf{DG-Mem}, a dual-grained agentic memory framework that augments a frozen MLLM with a non-parametric, externally stored memory built once from training-time rollouts and consulted read-only at test time. Motivated by the Complementary Learning Systems (CLS) account of human memory, DG-Mem factors its store into an instance-grounded exemplar memory and a category-level schema memory of IF-THEN rules, with a transient reflection store mediating their construction so that schemas are synthesized only from abstract reflections, never from exemplar text. Two design choices distinguish DG-Mem: an online concept categorizer that grows the category space incrementally during training rather than committing to a predefined taxonomy, and a Shapley context attribution procedure that decomposes correctness across the entire retrieved rule set and yields a per-rule utility that re-weights retrieval at test time. The pipeline introduces no gradient updates and is deployable on closed-weight or on-device backbones. Across MathVista, MMMU, and MMMU-Pro on four open-weight and proprietary backbones (Qwen3.5-27B, Qwen3.5-122B-A10B, GPT-5-Nano, Gemini-3-Flash), DG-Mem improves consistently over no-memory and competitive memory baselines.

- **核心问题**：如何在不更新任何参数的前提下，让冻结的 MLLM 具备**跨问题累积学习**的能力，从而提升科学推理表现？
- **核心思想**：借鉴认知科学中的**互补学习系统（Complementary Learning Systems, CLS）**理论——人类灵活行为源于两个交互系统：快速、实例特异的记忆系统（支持基于范例的泛化）和缓慢、结构化、围绕抽象图式（schema）组织的记忆系统，且图式仅从抽象痕迹中离线整合（schema-mediated consolidation）。同时参考理性记忆分析（rational analysis of memory）——检索可及性 = 线索匹配强度 × 历史有用性（base-level term）。

## 二、方法论（核心思想、技术细节、算法流程）

### 2.1 整体架构（两阶段离线流程）

- **Stage 1（记忆构建）**：对训练语料中每个问题 q，用冻结骨干 MLLM 采样 N 条温度采样解轨迹，经验证级联（原生匹配器 → 符号解析器 → LLM 裁判）标注正确/错误，仅需 gold answer 监督，无需思维链标注。然后并行生成三类产物：
  - **反思规则** ρ(q) = Refl_R(q, a*, {rollouts}) → 写入瞬态反思存储 **MR**；
  - **范例记录** e(q) = Refl_E(q, a*, {rollouts}) → 写入范例记忆 **ME**（内含推理策略 + 验证检查 + 对应的抽象规则）；
  - **类别标签** κ(q) = Cat(q) → 由在线概念分类器生成，并维护类别注册表。
- **Stage 2（Shapley 上下文归因）**：将同一冻结骨干用作“归因设备”，对每个问题抽取 B 个子集（含空集与全集），逐一注入规则集并 rollout，将二元奖励转化为每条规则的 **Shapley 值**，累计为效用 U(ri)，用以在测试时重加权检索。

### 2.2 关键设计细节

- **抽象约束**：所有存储内容（规则、策略、检查）禁止出现具体数值、选项字母、变量绑定、命名实体，防止在跨问题消费时泄漏。
- **在线概念分类器**：增长式类别空间——Cat 提取问题概念 K(q)，与现有注册表（仅限 id-名称对）比较；若匹配度 >70% 则分配，否则创建新类别；类别空间单调增长，无需预定义分类法。
- **图式综合（Schema Synthesis）**：Synth 严格只读 MR（按类别分组的抽象 IF-THEN 规则），**绝不接触范例文本**；输出 2-4 条规范性建议（prescriptive advice），消除冗余、调和冲突、提升为类别级原则。
- **检索机制**：
  - **图式检索**：按类别代表概念与 K(q) 匹配，规则级相似度 + 效用加权的组合得分：
    - **s_i = α·cos(Emb_T(r_i), Emb_T(q)) + (1-α)·norm(U(r_i))**（对相似度和效用分别做 min-max 归一化）
  - **范例检索**：多模态嵌入 Emb_M(I_q, t_q) 余弦相似度 + 阈值过滤 τ_E（无候选则注入空）。
  - **注入模式**：priming（问题前设框架）与 verification（问题后审查）。
- **Shapley 归因**：将共同检索的规则视为合作博弈中的玩家，Shapley 值为：
  - **Δq(r_i) = (1/K!) Σ_π [v(P_i^π ∪ {r_i}) - v(P_i^π)]**
  - 当 B ≥ 2^K 时退化为精确幂集，Shapley 精确；否则近似。累加平均得到 U(r_i)，文件级锁保证可并行可恢复。
- **无梯度保证**：整个流程不向骨干或附加层传播任何梯度，所有节点（rollout、反思器、综合器、分类器）均使用同一骨干，构成“自进化”（self-evolving）同质配置。

## 七、优点（方法或实验设计的亮点）

1. **认知科学理论驱动**：将 CLS 的“双存储 + 图式介导整合”落实为可操作的架构约束（范例文本不进入图式合成），并将理性记忆分析（相似度 × 历史效用）编码进检索公式。
2. **严格的抽象约束**：从 prompt 层面强制禁止数值/选项/实体泄漏，这是可迁移性的关键保障，也是同领域方法常忽略的细节。
3. **在线类别增长**：避免固定分类法过粗/过细的两难，让类别空间跟随语料经验分布动态演化。
4. **Shapley 归因解决信用分配问题**：相比单一记忆效用信号（如 MemRL 的 TD 误差），Shapley 将正确性分解到整个共检索规则集，更准确地反映每个规则的边际贡献。
5. **完全无梯度、同骨干自进化**：显著降低了部署门槛——闭源 API（GPT-5-Nano、Gemini-3-Flash）与本地设备模型均可受益；同质骨干设置排除了“隐性知识蒸馏”的混淆因素。
6. **验证级联设计**：原生匹配器 → 符号解析器 → LLM 裁判的级联，缓解了格式差异导致的假阳性/假阴性。
7. **可审计性**：定性的案例展示让读者能直接看到“检索到了什么”以及“为什么修正了答案”，可解释性强。

## 八、不足与局限

1. **归因的随机性噪声**：Shapley 归因假设骨干是子集价值函数的确定性函数，但 GPU 内核非确定性、动态批处理、浮点非结合性等会导致相同上下文下奖励波动；有限子集预算 B 下，Δq(ri) 会继承背景噪声，U(ri) 的符号可能依赖数据顺序。作者虽用跨问题平均与排序（而非阈值化）缓解，但未从根本上消除。
2. **测试期记忆冻结**：选择冻结 M 是为保证评估纯净并与 ViLoMem (offline) 公平对比，但放弃了持续学习（test-time error 也可成为新记忆）的适用场景；结合离线整合与有界在线更新的设计仍为开放问题。
3. **有限子集预算的近似性**：当 B < 2^K 时并非精确 Shapley，严格的大 O(K!) 精确计算不可行；对规则量大类别的效用估计可能存在偏差。
4. **某骨干上的非一致增益**：Qwen3.5-27B 在 MMMU-Pro 上低于无记忆基线（73.6 vs 75.1），表明小模型对长上下文中记忆注入的敏感度可能不同，论文未深究这一负迁移原因。
5. **算力信息缺失**：未报告 GPU 型号与数量、训练时长、能耗等资源消耗数据，对实际部署成本预估不足。
6. **缺乏广泛的模型/基准扩展**：未在纯文本推理（如 GPQA、AIME）、更多骨干（如 Llama 系列、Claude 系列）、更多模态（音频/视频）上验证泛化性。
