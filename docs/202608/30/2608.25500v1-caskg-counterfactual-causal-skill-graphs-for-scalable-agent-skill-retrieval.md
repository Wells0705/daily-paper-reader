## 摘要
可复用技能库使大型语言模型（LLM）智能体能够在不同任务间重用程序性知识，但也使记忆访问成为一项具有挑战性的检索问题。全库提示以高上下文成本保留覆盖率，向量检索返回紧凑的邻域但将技能视为独立文本，而基于图的检索仅在承载相关性的边可靠时才能恢复工作流上下文。我们提出CaSKG，一种在检索前校准程序性关系的反事实因果技能图框架。CaSKG首先从语义、词汇、输入/输出和结构证据构建高召回率的有向候选图，并通过修复证据和可选的LLM评判器进一步优化候选分数。然后，它应用面向方向的条件化文本反事实探针，对技能对进行移除、替换和重排，通过贝叶斯平滑聚合证据，并发布状态过滤的加权图以支持任务条件扩展。该图离线构建，使用时不改变下游智能体策略或任务接口。在ALFWorld ID-140和ScienceWorld U211上的六个LLM后端中，CaSKG在所有十二种模型和基准组合中取得了最高任务分数。与技能图（GoS）相比，它将六模型宏平均ScienceWorld分数从72.62提升至80.50，ALFWorld成功率从80.01\%提升至86.79\%，同时在两个基准上减少了平均环境步骤。定性和消融分析进一步表明，校准边有助于检索保留前提条件、状态改变动作、验证例程和最终完成步骤。这些结果将边置信度校准定位为大规模紧凑且可执行技能检索的有效途径\footnote{代码可在 https://github.com/ZhiyuanLi218/Caskg 获取}。

## Abstract
Reusable skill libraries allow large language model (LLM) agents to reuse procedural knowledge across tasks, but they also turn memory access into a challenging retrieval problem. Full-library prompting preserves coverage at high context cost, vector retrieval returns compact neighborhoods but treats skills as independent text, and graph-based retrieval can recover workflow context only when the edges that carry relevance are reliable. We propose CaSKG, a counterfactual-causal skill graph framework that calibrates procedural relations before retrieval. CaSKG first builds a high-recall directed candidate graph from semantic, lexical, input/output, and structural evidence, with repair evidence and an optional LLM judge further refining candidate scores. It then applies direction-conditioned textual counterfactual probes that remove, substitute, and reorder skill pairs, aggregates the evidence with Bayesian smoothing, and publishes a state-filtered weighted graph for task-conditioned expansion. The graph is constructed offline and used without changing the downstream agent policy or task interface. Across six LLM backbones on ALFWorld ID-140 and ScienceWorld U211, CaSKG achieves the highest task score in all twelve combinations of model and benchmark. Relative to Graph-of-Skills (GoS), it improves the six-model macro-average ScienceWorld score from 72.62 to 80.50 and ALFWorld success from 80.01\% to 86.79\%, while reducing mean environment steps on both benchmarks. Qualitative and ablation analyses further show that calibrated edges help retrieval preserve prerequisites, state-changing actions, verification routines, and final completion steps. These results position edge-confidence calibration as an effective route to compact and executable skill retrieval at scale\footnote{Code is available at: https://github.com/ZhiyuanLi218/Caskg }.

## 1. 论文的核心问题与整体含义（研究动机与背景）

随着大型语言模型（LLM）智能体在复杂任务中的广泛应用，可复用技能库（reusable skill libraries）成为智能体跨任务重用程序性知识的重要手段。然而，当技能库规模不断扩大时，核心问题不再是"智能体能否使用某个工具"，而是"如何从庞大的程序性记忆中暴露当前任务所需的正确技能子集，同时避免压垮上下文窗口"。

现有方法各有明显缺陷：

- **全库暴露（Full-library exposure）**：虽然保留了最高召回率，但将所有技能全部放入上下文，把筛选负担转移给智能体，引入了大量无关干扰，上下文成本极高。
- **向量检索（Vector retrieval）**：通过语义相似度压缩上下文，但将技能视为独立的文本单元，忽略了技能之间的程序性依赖关系（如前置条件、验证步骤、后续动作），因而不适合程序性记忆场景。
- **图检索（Graph-based retrieval）**：以Graph-of-Skills（GoS）为代表，通过构建离线技能图并传播查询相关性来恢复工作流上下文。但图检索引入了新的失效模式：一旦相关性开始传播，检索质量取决于携带相关性的边是否可靠。仅由主题相似性或共现关系诱导的弱边可能传播噪声，导致检索结果包含操作上不合适的技能。

论文的核心洞察是：技能图构建的瓶颈不在于如何建立更大的图，而在于如何决定哪些候选关系应该影响检索。因此，给定高召回率的候选关系池，系统需要决定哪些边值得评估、每条评估边应获得多少置信度、以及该置信度应如何控制图传播——这就是论文形式化的"预算受限的边置信度校准"问题。

## 2. 论文提出的方法论：CaSKG

CaSKG（Counterfactual-Causal Skill Graph）是一个离线图构建与检索框架，将关系发现与边可靠性评估分离。整体流程分为四个阶段：

### 2.1 候选技能图构建（Candidate Skill Graph Induction）

- 从技能描述、语义表示、输入/输出接口和工作流角色等异构证据通道构建有向候选图 C ⊆ S × S，其中每条边 (sᵢ, sⱼ) 表示"源技能 sᵢ 为目标技能 sⱼ 提供操作支持"的有序假设。
- 语义与词汇信号捕捉文本和概念亲和性；输入/输出信号捕捉接口兼容性；结构信号捕捉工作流位置。修复证据（repair evidence）和可选的LLM评判器可进一步细化候选分数。框架预留了轨迹共现和既有关系记录作为自进化技能库的扩展通道。
- 初始关联分数 Aᵢⱼ 通过加权平均活跃信号得到，并施加结构下限（structural floor）增强强工作流证据。该分数用于排序候选边以分配有限的验证预算。

### 2.2 反事实边探针（Counterfactual Edge Probing）

关联分数只能说明两个技能相关，无法判断有向边是否捕捉了操作依赖关系。CaSKG对选定的预算验证前沿 F ⊆ C 中的每条边应用三种方向条件化的文本反事实探针：

- **移除探针（Removal）**：使源技能不可用，测试目标技能是否受损——衡量必要性（necessity）。
- **替换探针（Substitution）**：用低重叠技能替换源技能，测试目标技能是否退化——衡量源技能的特异性（specificity）。
- **重排探针（Reordering）**：反转提议的关系顺序，测试工作流是否保持连贯——衡量方向性（directionality）。

三种探针共享相同的支持方向（分数越大表示对依赖关系的破坏越强），因此可直接聚合。

### 2.3 贝叶斯边校准与图发布（Bayesian Edge Calibration and Graph Publication）

- 探针分数通过 Beta 分布累积器转化为平滑的关系可靠性估计 cᵢⱼ（式3-5）。以 0.5 为极性分界，距离中点越远贡献的证据质量越大，证据质量下限 εₑ 防止中间判断被完全忽略。
- 根据对称确认阈值 τ_c，每条边被分配到四种状态之一：**已确认（confirmed）**、**已拒绝（rejected）**、**不确定（uncertain）** 或 **未验证（unvalidated）**（式6）。
- 发布时，已确认边保留完全支持，不确定边被降权（系数 ρ_unc），被拒绝边移除，选定的未验证边仅作为低权重支架（系数 ρ_scaf）保持覆盖（式7）。最终生成冻结的发布图 G_pub 供检索使用。

### 2.4 任务条件化技能检索（Task-Conditioned Skill Retrieval）

- 推理时，使用词汇和语义排名获取种子技能，转换为逆排名加权的种子分布 π_q。
- 在发布图上运行 personalized PageRank 迭代（式9），重启系数 γ 控制每次更新回到 π_q 的强度，状态门控的边权重决定程序性关系以何种强度传播相关性。
- 收敛后按相关性分布 p 排序技能，返回最高排名的技能摘要作为任务上下文。下游智能体策略和任务接口完全不变。

## 6. 论文的主要结论与发现

1. **全面最优**：CaSKG 在全部 12 个模型-基准组合中取得最高任务分数。六模型宏平均 ScienceWorld 分数从 GoS 的 72.62 升至 80.50，ALFWorld 成功率从 80.01% 升至 86.79%。

3. **机理验证**：任务类型增益分析表明 CaSKG 在需要多步依赖操作的任务类型上增益最大（如三/二次颜色混合、植物种植、未知导电性和能量分类，增益 9.6-34.6 分），而在直接检索或测量任务上增益有限甚至小幅下降。
4. **图传播的双刃剑**：GPT-5.6-Luna 在 ALFWorld 上的表现揭示，未经校准的图传播可能比全库暴露更差，而 CaSKG 能恢复最佳性能——结构检索只有当结构抑制误导链接时才有效。
5. **消融确认设计原理**：语义单通道候选图（67.14%）和发布全部候选（71.43%）均不及完整 CaSKG（73.57%），证明"候选阶段广阔、发布阶段选择性"这一设计原则的有效性。
6. **代表性案例**：导电测试和冷却放置两个实例展示了 CaSKG 返回的是保持"准备→操作→验证→放置"依赖链的可执行技能束，而非孤立的相关技能。

## 7. 优点

1. **问题定位准确**：将技能图构建形式化为"预算受限的边置信度校准"问题，切中图检索的核心瓶颈——边可靠性，而现有方法大多默认边的可靠性或仅依赖文本/结构信号。
2. **方法设计创新**：首次将方向条件化的文本反事实探针（移除、替换、重排）应用于技能关系的可靠性评估，将因果推理思想带入程序性记忆检索，三条探针分别对应必要性、特异性和方向性三个正交维度。
3. **构建/检索分离**：离线构建 + 运行时检索的架构使 CaSKG 不改变下游智能体策略或任务接口，即插即用，工程落地友好。
4. **校准机制完善**：贝叶斯平滑避免了直接用 LLM 原始分数带来的噪声；四态发布（confirmed/rejected/uncertain/unvalidated）提供了比简单二值化更精细的传播控制；未验证边保留低权重支架保持了覆盖。
5. **实验设计较为严谨**：多模型、多基准、多规模的全面评估，且在相同条件下控制变量；定性分析揭示增益来源；消融实验验证了每个组件的贡献。

## 8. 不足与局限
