## 摘要
大语言模型（LLM）智能体已展现出解决需要规划、工具使用和外部信息访问的多步任务的能力，然而不断增长的执行历史会增加推理成本，并使推理暴露于过时、无关或误导性信息之中，从而可能降低推理质量。现有记忆方法对执行历史进行组织或压缩，但在决定哪些记忆应保持活跃方面提供的机制有限。我们提出了一种分层记忆系统，将执行组织为任务、子任务和动作，并为每条记忆分配动态保留分数。基于事件的更新和基于选择的衰减会修正这些分数，使WMT能够保留有用信息、折叠已完成轨迹、抑制低效用内容，并保持对折叠上下文的访问。我们使用Qwen3-8B、Gemma 4 E4B和Llama-3.1-8B在GAIA-Text上评估了WMT，并进行了消融实验和记忆投毒实验。与线性记忆相比，WMT平均将准确率提高了9.97个百分点，同时将提示令牌使用量减少了32.8%。记忆投毒实验表明，WMT限制了不可靠信息的持续存在和传播。我们的结果表明，有效的长时程智能体记忆，与其说取决于存储更多信息，不如说取决于决定哪些信息应保持活跃。

## Abstract
Large language model (LLM) agents have demonstrated the ability to solve multi-step tasks requiring planning, tool use, and external information access, yet growing execution histories increase inference cost and expose reasoning to outdated, irrelevant, or misleading information, potentially degrading reasoning quality. Existing memory approaches organize or compress execution histories but provide limited mechanisms for deciding which memories remain active. We introduce the, a hierarchical memory system that organizes execution into tasks, subtasks, and actions while assigning each memory a dynamic retention score. Event-based updates and selection-based decay revise these scores, allowing WMT to preserve useful information, fold completed trajectories, suppress low-utility content, and retain access to folded context. We evaluate WMT on GAIA-Text using Qwen3-8B, Gemma 4 E4B, and Llama-3.1-8B, with ablations and memory-poisoning experiments. Relative to linear memory, WMT improves accuracy by an average of 9.97 percentage points while reducing prompt-token usage by 32.8%. Memory-poisoning experiments show that WMT limits the persistence and propagation of unreliable information. Our results suggest that effective long-horizon agent memory depends less on storing more information than on deciding which information should remain active.

## 一、核心问题与整体含义（研究动机与背景）

### 1.1 研究背景
- LLM智能体在多步任务中需要不断进行推理、工具调用和外部信息访问，执行历史（execution history）不断增长。
- 传统ReAct风格设计将推理步骤、工具调用和观察结果**追加到线性交互历史**中，但随着历史变长，出现三方面问题：
  - **推理成本上升**：完整历史被反复输入提示，token消耗不断增长。
  - **信息干扰**：过时观察、失败尝试、无关细节与有效证据混杂，相关信息的可提取性下降——已有研究（如Liu et al., 2024）表明模型在长上下文中利用相关信息的能力显著下降，远低于名义上下文窗口限制。
  - **安全隐患**：持久记忆中的被投毒记录（poisoned records）可能被检索并影响后续行为。

### 1.2 现有方法的不足
- 现有记忆方法（如Task Memory Engine、Context-Folding）能够组织或压缩执行历史，但**缺少对每条记忆持续效用（continuing utility）的动态估计机制**。因此，即使后续证据降低了某条记忆的相关性或可靠性，该记忆仍可能保持活跃。

### 1.3 核心研究问题
> 能否通过显式估计记忆效用，来调节哪些内容进入智能体的工作上下文，从而改善长时程推理？

### 1.4 整体含义
- 论文的核心主张是：**有效的长时程智能体记忆，关键在于"决定哪些信息应保持活跃"而非"存储多少信息"**。这一观点将记忆问题从"容量与组织"转向"动态效用评估与选择性保留"。

## 二、方法论：Weighted Memory Tree（WMT）

### 2.1 总体框架
WMT是一个**记忆管理层**，在不修改基础智能体参数或工具接口的前提下，将执行历史组织为持久层次结构，并为每个推理步骤构建紧凑的工作上下文。其工作流程为：
1. 从用户查询初始化根任务；
2. 构建工作上下文；
3. 基础智能体执行一步交互；
4. WMT记录任务、动作、观察和结果；
5. 事件结果更新节点保留分数→聚合为分支优先级→Memory Controller执行折叠/抑制/重开；
6. 提示选择反馈（missed-selection）更新分数；
7. 循环直至根任务完成。

### 2.2 分层记忆树结构
记忆状态定义为 Mt = (Gt, Vt, Et)，其中：
- **Gt**：全局记忆（跨任务分支或对话共享）；
- **Vt**：查询特定记忆节点；
- **Et**：节点间的父子关系。

节点层级：
- **根节点**：用户查询；
- **任务节点**：目标和子目标；
- **动作节点**：尝试的操作、观察结果和结果记录。

每个节点存储：内容、节点类型、父节点、生命周期状态（ACTIVE/COMPLETED/FOLDED/OBSOLETE）、保留分数、未选中计数（missed-selection count）和执行元数据。

**活跃路径**（Active Path）Pt = Path(vroot, v⋆t) 从根到当前活跃任务，始终保留在上下文构建中。

### 2.3 动态保留分数（Dynamic Retention Scoring）
核心创新在于为每条记忆维护动态保留分数，由两类更新驱动：

**(1) 基于事件的更新（Event-based updates）**：根据动作执行结果更新中间分数：
- 成功（ωi = success）：保留分数设为 usuccess = 0.75；
- 失败（ωi = failure）：保留分数设为 ufailure = 0.30。
- 失败动作不会被自动标记为过时，而是作为警示信息保留，防止重复无效操作。

**(2) 基于选择的衰减（Selection-based decay）**：若某条记忆在候选池中但未被选中（missed selection），其分数乘以衰减因子。连续未选中次数越多，衰减越强：
- 非全局记忆的衰减因子：ρ^min{m, M}（ρ为普通衰减率，M为最大衰减指数上限）；
- 全局记忆使用独立的衰减率 ρG；
- 被选中的记忆重置未选中计数（missed-selection count = 0）。

**(3) 分支优先级**（Branch-level priority）：对于任务分支 b = B(vb)，优先级计算公式为：
> U_b(t) = α·max_i u_i(t) + β·mean_i u_i(t) − γ·F_b(t) − δ·O_b(t)

其中：max项保留含高价值记忆的分支；mean项反映分支整体效用；F_b为失败动作节点比例，O_b为已标记OBSOLETE的节点比例，作为惩罚项。当分支优先级低于阈值τobs（=0.10）时，该分支被标记为OBSOLETE（抑制但未删除）。

### 2.4 生命周期管理（Memory Controller）
三种生命周期操作：
1. **折叠（Folding）**：任务完成时将已完成分支压缩为紧凑摘要（包括任务目标、最终结果、支持证据、未解决问题、失败警示），底层执行轨迹仍持久保存；
2. **抑制（Suppression）**：分支优先级低于τobs时，标记其根任务节点为OBSOLETE，从普通上下文构建中排除，但不删除存储记录；
3. **重开（Reopening）**：当执行返回到已折叠任务时，恢复为ACTIVE状态，摘要立即可用，底层记忆可在需要时重新进入候选池。

### 2.5 效用感知的提示合成器（Utility-Aware Prompt Synthesizer）
- 候选池包含：强制性活跃路径、符合条件的全局记忆、任务和动作记忆、折叠摘要、失败警示；
- OBSOLETE分支的记忆被排除在普通选择之外；
- 使用**基于LLM的语义选择器**（而非确定性top-k规则），将语义相关性与保留分数、分支优先级结合；
- 上下文序列化顺序：当前任务和活跃层次 → 选定记忆 → 折叠摘要 → 相关失败警示；
- 被选中的记忆重置未选中计数；可被选但未选中的记忆经历衰减。

## 六、主要结论与发现

### 6.1 主基准结果（GAIA-Text）
| 指标 | Qwen3-8B | Gemma 4 E4B | Llama-3.1-8B | 平均 |
|------|----------|-------------|--------------|------|
| 准确率提升（相对Linear History） | +13.39pp | +8.66pp | +7.87pp | **+9.97pp** |
| 提示令牌减少 | 25.6% | 42.0% | 30.8% | **32.8%** |

### 6.2 主基准结果（GAIA完整验证集）
- 准确率平均提升：**+10.10pp**（Qwen3-8B +9.70pp，Gemma 4 E4B +4.85pp，Llama-3.1-8B +15.76pp）；
- 提示令牌平均减少：**32.2%**。

### 6.3 消融结论
- **纯层次结构（Unweighted Tree）不足以提供一致改进**：在6个模型–基准组合中，仅1个超过线性历史；WMT在所有6个组合中均优于Unweighted Tree（高5.46–18.11pp且令牌更少）；
- 语义选择单独使用虽可提升某些模型准确率，但增加令牌使用；
- 摘要压缩单独使用可降低令牌但准确率影响不一致；
- **只有完整WMT（层次结构+语义选择+摘要+保留评分+生命周期控制）实现最佳准确率–效率权衡**。

### 6.4 记忆投毒结论
- Linear Memory在所有安全指标上表现最差（ASR 0.995、PRR 0.246、IP 1.000、BR 0.906、AF 6.103）；
- Full WMT取得所有安全指标最优：ASR 0.419、PRR 0.097、IP 0.009、BR 0.315、AF 0.965；
- 同时取得最高任务成功率（TSR 0.575）和最低平均提示令牌（131.963）；
- 生命周期管理不足（A2）导致感染完全持续（IP=1.000）；
- 缺少语义检索（A3）导致爆炸半径和放大因子显著恶化。

### 6.5 核心论断
> 有效长时程记忆不取决于存储信息的多少，而取决于**动态调节哪些信息保持活跃以指导后续推理**。

## 七、优点与亮点

1. **问题定义清晰且实践导向**：直接瞄准长上下文LLM的已知弱点（"lost in the middle"），并提出可操作的解决方案；

3. **动态保留机制设计合理**：事件更新（成功/失败）+ 选择衰减（实际使用反馈）双通道，同时考虑信息效用与使用频率，避免仅依赖时间遗忘的粗糙做法；

7. **对话模式扩展**：支持将已完成任务摘要提升为全局记忆，具备扩展到多轮对话场景的架构空间。

## 八、不足与局限

### 8.1 实验覆盖局限
- **基准单一**：仅GAIA基准族，且GAIA-Text与GAIA题目风格相近；未覆盖Web交互环境、软件工程智能体、具身任务、长期对话等场景；
- **模型规模有限**：仅评估8B级别模型（Qwen3-8B、Llama-3.1-8B）和一个4B级模型（Gemma 4 E4B）。更大模型可能更能忽略无关上下文从而减少WMT的相对准确率增益，但更高的处理成本可能增加效率增益——这种交互效应未被验证；
- **全局记忆模式未验证**：基准实验中每个问题初始化新树，跨对话全局记忆（Section 2.3描述的功能）实际未在实验中测试。

### 8.2 方法局限性
- **大量手工设定参数**：初始分数、事件更新值、分支聚合系数、过时阈值均为固定常量，缺乏对不同任务分布的适应性；
- **保留分数反映操作效用而非事实正确性**：一条看似成功但包含错误信息的动作可获得高分（如附录中的mirror页面案例），仅靠选择衰减和因超过而变的规则不足以完全过滤；
- **LLM选择器/摘要器本身的误差**：语义选择或摘要可能出错，且引入额外

且引入额外的推理开销与延迟；一旦选择器或摘要器输出错误，错误信息会经由工作上下文注入后续推理，产生复合误差。

4. **固定生命周期阈值缺乏上下文感知**：分支过时阈值τobs为全局常量，无法区分"低谷但仍有价值"的分支与"确实过时"的分支；在多任务交错场景中，一个暂时中断但仍有潜力的分支可能被过早抑制，而任务重开机制虽可恢复，但恢复成本（重新检索底层记忆）并未计入评估。

5. **全局记忆机制不完整**：论文仅提出全局记忆概念，但基准实验中每个查询均从头初始化新树，缺少跨会话累积效应的实验验证；全局记忆的衰减率ρG、可提升为全局记忆的条件等设计细节未充分交代。

### 8.3 安全评估局限

- 投毒实验是**受控合成场景**：100个场景、297个子任务的设置虽然允许系统化消融，但投毒记录以固定形式注入，与AgentPoison等真实对抗性攻击相比，缺乏针对语义选择器和生命周期机制协同利用的复杂攻击测试；
- **安全指标的定义依赖手动构造的黄金记忆集合**：投毒检索率（PRR）和放大因子（AF）的计算依赖人工标注哪些记忆应被检索，这种标注方式在开放域任务中难以规模化；
- 安全增益与任务有用性的权衡未被充分讨论：Full WMT虽然大幅降低ASR，但其安全性的提升部分来源于对记忆的积极抑制——如果攻击者将恶意信息隐藏在关键任务证据附近，这种抑制策略可能同时牺牲有用信息。

## 九、未来工作方向

1. **自适应参数学习**：用强化学习或在线贝叶斯推断替代手工设定的保留分数常量（如usuccess、ufailure、ρ、τobs），使记忆管理系统自动适应不同任务分布和用户偏好；
2. **大规模模型验证**：将WMT应用于70B级或更大规模模型，验证记忆机制在高能力模型上的增益是否仍然显著；
3. **事实性与一致性校验层**：将保留分数与事实核验（如对照工具返回的原始证据）相结合，识别"执行成功但信息错误"的记忆节点；
4. **跨对话全局记忆的端到端评估**：构建多任务连续交互基准，验证全局记忆共享与衰减策略的实际效用；
5. **真实世界安全性评测**：在AgentPoison或其他真实对抗性投毒基准上对比WMT与现有防御方法，并测试联合投毒（同时污染多条记忆以绕过生命周期抑制）的场景；
6. **记忆压缩质量评估**：系统研究折叠摘要的信息保真度，建立摘要生成质量与下游任务性能之间的量化关系。

## 十、总体评价

### 10.1 贡献定位

WMT是长时程LLM智能体记忆管理领域中一项**设计系统且验证全面**的工作。它的主要贡献不是提出一种全新的记忆表示（树结构本身是已有概念的延伸），而是将**动态效用评估**作为记忆生命周期管理的核心驱动因素，构建了从事件结果→保留分数→分支优先级→折叠/抑制/重开的完整闭环。这一思路与心理学中人类记忆的选择性保留机制相呼应：重要的不是存储多少，而是什么需要被记住。

### 10.2 值得注意的亮点

- 在GAIA两个子集上，WMT相较Linear History实现了约**+10pp准确率提升**，同时减少约**三分之一提示令牌**——这种准确率与效率的同时改善并非互斥，而是来自对无关记忆的系统性排除；
- **投毒鲁棒性增益**是意外收获：安全消融表明生命周期管理抑制了"永不消散"的恶意记忆，说明动态遗忘机制本身就是一种防御机制——这个发现很容易被忽视，但可能对其他记忆系统设计产生广泛影响；
- 消融实验设计的"阶梯式"拆解（无权重树→加选择→加摘要→加生命周期）为理解各组件贡献提供了清晰证据链。

### 10.3客观局限的再强调

核心方法论的风险点在于**保留分数是启发式的人为设定**，而非从数据中学习的表示。这带来两层问题：其一，分数更新规则无法区分"失败但信息丰富"与"失败但毫无价值"的记忆；其二，分支优先级计算公式中多目标之间的系数（α, β, γ, δ）缺乏明确的调优策略，对跨任务泛化构成潜在威胁。此外，单纯依赖GAIA基准，使"WMT优于Linear History"这一结论的适用边界仍有待更广任务类型的检验。

### 10.4 总结性判断

总体而言，本文在方法构建（动态分层记忆）、实验设计（多模型×多基准×系统消融）与结果呈现（准确率与效率兼顾、安全性分析）三方面均表现出较高完成度。其核心观点——**记忆效用需要被动态估计并在必要时被主动遗忘**——为长时程LLM智能体记忆研究提供了一个值得借鉴的新范式。与该领域现有工作（如MemGPT的层级分页内存、Generative Agents的反射记忆）相比，WMT的独特定位在于将"遗忘"从一种被动的容量管理手段提升为一种主动的效用管理策略。尽管在全局记忆验证、参数自适应、真实攻击场景评估等方面仍有明显不足，但作为一项面向实用智能体的记忆系统研究，其工程质量与实验严谨性使其具有较强的参考价值与后续扩展潜力。
