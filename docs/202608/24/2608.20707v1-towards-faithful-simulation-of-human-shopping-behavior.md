## 摘要
模拟逼真的用户购物行为是电子商务场景中离线评估和强化学习的基础。尽管近期基于LLM和VLM的模拟器取得了令人鼓舞的进展，但重现真实的浏览会话仍然困难，原因有二。(i) 记忆挑战：购物会话跨越数十个页面，然而现有智能体要么丢弃长期观察历史，丢失不断演进的用户状态，要么天真地将它们连接起来，使上下文窗口过载，甚至降低模拟质量。(ii) 优化挑战：当前用户模拟器通常通过模仿或步骤级奖励来监督匹配每个记录的动作；由此产生的会话往往显示不真实的模式，例如过度探索或过度被动，而逐步监督既无法检测也无法纠正这些模式。为了解决上述挑战，我们提出了RecVerse，一个基于GUI的模拟智能体，通过截图感知页面并生成忠实的多轮轨迹。针对记忆挑战，RecVerse采用了一种受认知启发的分层记忆：工作记忆用于短期聚焦，情景记忆用于会话内痕迹，偏好记忆用于高层意图，并将记忆更新视为动作，从而使智能体自适应地学习何时记忆以及记忆什么。针对优化挑战，RecVerse通过轨迹级强化学习目标进行优化，该目标对整个会话进行评分，使宏观层面的动作类型分布和微观层面的购物意图与真实用户对齐。我们进一步发布了USB（用户模拟基准），一个用于多轮用户模拟的交互式电子商务GUI轨迹数据集。实验表明，RecVerse在行为保真度和意图一致性方面显著优于现有基线。

## Abstract
Simulating realistic user shopping behavior underpins offline evaluation and reinforcement learning in e-commerce scenarios. While recent LLM- and VLM-based simulators have made encouraging progress, reproducing a real browsing session remains difficult for two reasons. (i) Memory Challenge: a shopping session spans dozens of pages, yet existing agents either discard long-range observation histories, losing the evolving user state, or naively concatenate them, overwhelming the context window and even degrading simulation quality. (ii) Optimization Challenge: current user simulators are typically supervised to match each logged action via imitation or step-level rewards; the resulting sessions often display unrealistic patterns, such as over-exploration or excessive passivity, which per-step supervision can neither detect nor correct.   To address the above challenges, we present RecVerse, a GUI-grounded simulation agent that perceives pages through screenshots and produces faithful multi-turn trajectories. For the memory challenge, RecVerse adopts a cognitive-inspired hierarchical memory: Working Memory for short-term focus, Episodic Memory for in-session traces, and Preference Memory for high-level intent, with memory updates treated as actions so that the agent adaptively learns when and what to memorize. For the optimization challenge, RecVerse is optimized with a trajectory-level RL objective that scores entire sessions, aligning both macro-level action-type distributions and micro-level shopping intent with real users. We further release USB (User Simulation Benchmark), an interactive e-commerce GUI trajectory dataset for multi-turn user simulation. Experiments show that RecVerse significantly outperforms existing baselines in both behavioral fidelity and intent consistency.

## 1. 核心问题与研究动机

- **背景**：用户行为模拟旨在生成逼真的浏览轨迹，反映真实用户如何探索、比较和购买商品。它在电商推荐系统中承担关键角色，包括离线评估、反事实策略评估、RL推荐算法训练环境等。
- **核心问题**：现有 LLM/VLM 驱动的用户模拟器虽然取得了进展，但要忠实重现真实浏览会话仍面临两大挑战：
  1. **记忆挑战**：购物会话通常跨越数十个页面，点击或购买行为往往可以追溯到许多页面之前的浏览与比较。现有方法要么丢弃长期历史（丢失演化的用户状态），要么将全部历史简单拼接（导致上下文窗口过载、token 成本上升，且模拟质量随上下文增长而退化）。
  2. **优化挑战**：现有用户模拟器普遍采用"逐动作模仿"或"步骤级奖励"进行监督。然而真实浏览包含大量行为噪声（如意外过度滚动后立即回退），拟合这些噪声会干扰模型对用户意图的推断；同时逐步监督无法检测或纠正整体行为模式的失真，如过度探索或过度被动；且无法保证宏观层面的行为统计分布真实或微观层面的交互意图对齐。
- **深层差距**：无论是基于文本还是基于 GUI 的模拟器，均未针对"长期模拟"这一核心需求进行专门设计。

## 2. 方法论：RecVerse

### 2.1 核心思想
RecVerse 是一个基于 GUI 的模拟智能体（GUI-grounded agent），通过像素级截图感知推荐页面，由两大核心设计构成：

- **认知启发的分层记忆系统**：解决长期上下文建模问题；
- **轨迹级强化学习框架**：解决逐步模仿目标与行为保真度错位的问题。

### 2.2 分层记忆系统（Memory-as-Action）

| 记忆层级 | 认知对应 | 功能与内容 | 更新方式 |
|---------|---------|-----------|---------|
| **工作记忆（Working Memory）** | 视觉空间画板 | 容量受限的 FIFO 滑动窗口，保留最近 K 步的视知觉信息（截图视觉印象 + 心态 + 动作） | 固定滑动窗口，自动驱逐最早条目 |
| **情景记忆（Episodic Memory）** | 会话级行为追踪 | 以文本形式记录会话内的交互事件，保持跨页面连贯性 | **作为动作空间的一部分**，由策略模型学习"何时记录、记录什么" |
| **偏好记忆（Preference Memory）** | 稳定个人偏好 | 提炼高层用户意图，如偏好属性、比价标准、不喜欢项、购买意图等（例："用户偏好低价红裙"） | 同情景记忆，由策略模型自适应决定何时更新 |

**关键设计——Memory-as-Action**：将记忆写入动作空间的一部分，使记忆更新与浏览行为通过同一奖励信号联合优化，智能体自主学会何时及如何记忆，而非依赖手工规则。

### 2.3 轨迹级强化学习（Trajectory-Level RL）

- **两阶段训练**：
  1. **模仿学习（IL）预热**：最大化真实用户动作的对数似然 $\mathcal{L}_{IL} = -\sum_{t=1}^{T} \log \pi_\theta(a_t | o_t, h_{<t})$，提供稳定的策略初始化。
  2. **GRPO 轨迹级 RL 优化**：每组采样 G 条完整轨迹，通过组内相对优势估计（$A_i = \frac{R(y_i) - \text{mean}(\cdot)}{\text{std}(\cdot)}$）更新策略。
- **综合奖励**：$R_i = R_{\text{macro}} + \lambda \cdot R_{\text{micro}} + R_{\text{format}}$
  - **宏观奖励 $R_{\text{macro}}$**：惩罚智能体与真实用户在物品相关动作（点击、加购、购买）的数量分布差异，抑制过度探索或过度被动：$R_{\text{macro}}(\tau) = -\sum_{a \in \mathcal{A}} \frac{|N_a(\tau) - N_a(\tau^*)|}{N_a(\tau^*) + \epsilon}$
  - **微观奖励 $R_{\text{micro}}$**：基于三级分层商品类目评估物品决策与真实用户购物意图的对齐程度，通过加权意图强度（点击权重1、详情页权重5、加购权重5、购买权重10）和层次化类目匹配（$r(a) = \max_{y \in I^*} \frac{1}{L}\sum_{l=1}^{L} \mathbb{I}(c_l[x_a] = c_l[y])$）提供更密集的奖励信号。
  - **格式奖励 $R_{\text{format}}$**：确保输出可解析且动作在当前界面可执行。

## 3. 实验设计

### 3.1 基准数据集：USB（User Simulation Benchmark）
- 来自东亚主要电商平台的 5,274 条真实用户浏览轨迹，包含页面级截图、8 种动作类型、69,842 个动作。
- 平均轨迹长度 13.24 步；涵盖 90,095 件商品、41 个L1 / 517个L2 / 2256个L3 类目；5,222 个用户，每个用户含 5 种画像属性。
- 与现有基准的关键区别：USB 是**首个同时提供 GUI 视觉轨迹、多样化动作类型、用户画像和交互式多轮 RL 环境**的基准（对比 Amazon、MovieLens、RecBench+、Qilin、OmniBehavior、OPeRA 等均缺乏至少一项能力）。

### 3.2 对比方法

- RecVerse 自身变体：RecVerse-Text（IL/RL）、RecVerse-GUI（IL/RL）

### 3.3 评估指标

## 6. 主要结论与发现

1. **RecVerse-GUI + RL 显著优于最强 GUI 基线 STA**：物品级 F1 从 4.27 提升至 7.19，HR 从 5.92 提升至 10.45，HCO 从 23.11 提升至 32.64。
2. **从文本到 GUI 的模态升级显著提升类目级对齐**：HCO 在 IL 下从 19.03 提升至 30.00，在 RL 下从 24.38 提升至 32.64，验证了像素级观察的价值。
3. **轨迹级 RL 优于逐步监督**：能够同时改善行为保真度（接近真实用户的高保真区间）和意图对齐度。
4. **分层记忆协同有效**：仅靠短期工作记忆无法维持连贯的购物意图；情景记忆与偏好记忆在不同抽象层面互补。
5. **微观奖励对意图一致性最关键**：移除微观奖励导致最大退化；但仅依赖宏观看不够，需要两者协同。
6. **人类仍可区分 RecVerse 与真实用户**（74% 偏好真实用户），表明完全拟人化模拟仍需更深的个性化建模。

## 7. 优点

- **认知科学启发的记忆设计**：三层次记忆（工作/情景/偏好）对应人类认知结构，避免了扁平化长上下文导致的性能退化，且记忆更新通过"记忆即动作"机制纳入 RL 优化，摆脱了手工启发式。
- **兼顾宏微观的轨迹级奖励设计**：宏观奖励约束整体行为分布，微观奖励通过层级类目匹配提供稠密、语义灵活的意图对齐信号，较好地解决了稀疏奖励问题。
- **将"过程导向"模拟与"目标导向" GUI 智能体明确区分**的视角具有理论贡献，重新定义了监督与评估范式。
- **USB 基准的贡献**：首个支持交互式多轮智能体 RL 的 GUI 电商基准，弥补了现有数据集只能静态回放、偏差后无法返回真实状态的关键缺陷。
- **评估体系设计审慎**：关注"最小化偏差"而非"最大化某个指标"，避免了过度交互策略带来的分数虚高；人类评估的标注者一致性高（κ = 0.834）。

## 8. 不足与局限

- **与真实人类仍存在差距**：人类评估中真实用户轨迹在 74% 的对比中被优先选择，意味着模拟行为仍存在可被察觉的不自然之处。
- **数据单一性与类目偏差**：仅来源于一个东亚电商平台，且"服装"类目占比极高（L1 中 51.0%），可能限制了模型对其他类目或文化背景用户的泛化能力。
- **算力信息披露不足**：未说明 GPU 型号、数量及总训练耗时，影响实验可复现性和资源成本评估。
- **轨迹级 RL 的行为保真度仍有待校准**：虽然大部分指标接近真实用户，但某些维度（如扩展实验中的 IPVR 偏低、ACR 偏高）仍存在系统偏差。
- **部分消融缺失**：未单独评估情景记忆的独立贡献（仅有完整 vs 无偏好记忆 vs 仅工作记忆三档），未完全剥离 IL 预热与 RL 的各自贡献。
- **IL 数据合成依赖大型教师模型**（Qwen3.5-397B），存在潜在的知识蒸馏偏差和偏见放大风险；合成数据质量未单独评估。
- **未讨论失败模式**：缺少对模拟失败场景（如罕见购买路径、异常长尾行为）的系统分析。
