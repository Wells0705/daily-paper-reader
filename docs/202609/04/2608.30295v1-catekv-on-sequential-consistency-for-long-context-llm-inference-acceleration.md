## 摘要
大型语言模型（LLM）在处理长上下文任务方面展现出强大的能力，但处理如此长的上下文仍然具有挑战性，因为需要大量的内存和推理延迟。在这项工作中，我们发现某些注意力头在其注意力模式中表现出顺序一致性，可以使用基于变异系数的算法持续识别。受这一观察的启发，我们提出了CateKV，一种混合KV缓存方法，它仅保留一致性头的关键标记信息，从而减少KV缓存大小和计算开销，同时保留自适应头中的大部分KV对以确保高精度。我们展示了我们算法的独特特性及其与现有加速方法的扩展。对长上下文基准的综合评估表明，在保持与全注意力相当的准确性的同时，CateKV在单样本输入中将内存使用量减少了高达2.72倍，解码速度提升了2.18倍，并在批量场景中使吞吐量提升了3.96倍。

## Abstract
Large language models (LLMs) have demonstrated strong capabilities in handling long-context tasks, but processing such long contexts remains challenging due to the substantial memory requirements and inference latency. In this work, we discover that certain attention heads exhibit sequential consistency in their attention patterns, which can be persistently identified using a coefficient-of-variation-based algorithm. Inspired by this observation, we propose CateKV, a hybrid KV cache method that retains only critical token information for consistent heads, thereby reducing KV cache size and computational overhead, while preserving the majority of KV pairs in adaptive heads to ensure high accuracy. We show the unique characteristics of our algorithm and its extension with existing acceleration methods. Comprehensive evaluations on long-context benchmarks show that, while maintaining accuracy comparable to full attention, CateKV reduces memory usage by up to $2.72\times$ and accelerates decoding by $2.18\times$ in single-sample inputs, and boosts throughput by $3.96\times$ in batch scenarios.

## CateKV：面向长上下文LLM推理加速的顺序一致性研究

### 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：长上下文LLM推理面临两大挑战——KV缓存带来的巨大内存占用和注意力计算的推理延迟。例如，使用 Llama-3-8B-Instruct-262k 模型时，将上下文从 1K 扩展到 1M tokens，推理延迟增长超过 3000 倍。
- **现有方法的不足**：
  - **KV驱逐（Eviction）方法**（如 StreamingLLM、H2O、SnapKV、PyramidKV）：直接丢弃 KV 对，容易误删关键信息，导致显著精度损失。
  - **KV检索（Retrieval）方法**（如 Quest、InfLLM、ShadowKV）：保留完整 KV cache，只稀疏检索，虽保精度，但无法缓解高内存压力，限制了批处理吞吐量。
  - **逐头分类方法**（如 DuoAttention、RazorAttention）：虽然识别了注意力头的异质性，但未能充分利用 prefilling 与 decoding 两个阶段之间的关联性。
- **本文的观察与洞见**：部分注意力头在 prefilling 和 decoding 阶段展现出 **顺序一致性（Sequential Consistency）**——注意力始终集中在少数固定 token 上；另一部分头则表现出动态激活、注意力分布随解码步变化。若能提前在 prefilling 阶段识别这两类头，即可在保精度的前提下大幅压缩 KV cache。
- **整体含义**：该工作利用注意力头跨阶段的稳定性模式，构建更精细的混合 KV 缓存管理策略，为长上下文推理提供了一条“无损压缩”路径，可与现有多种加速手段正交结合。

### 2. 论文提出的方法论

**核心思想**：CateKV 将注意力头分为两类并实施差异化缓存策略：
- **一致性头（Consistent Heads）**：注意力在解码各步稳定聚焦于少量关键 token，只保留这些关键 KV 对即可。
- **自适应头（Adaptive Heads）**：注意力分布随解码步变化剧烈，需要保留绝大多数 KV 对以保证精度。

**关键技术细节**：

**（1）识别头类型——基于变异系数（Coefficient of Variation, CV）的评分算法**：

- 设置观察矩阵 \( A \)：利用 prefilling 阶段的最后 \( L_{obs} \) 个 query token（观察窗口），对中间部分 token 计算注意力权重：
  \[
  A = \text{softmax}\left(\frac{Q[-L_{obs}:,:] \cdot K[L_{init}:-L_{rec},:]^T}{\sqrt{d}}\right)
  \]
- 通过分位数阈值 \( \Phi(k, \alpha) \)（第 k 百分位数乘以缩放因子 α）对 A 二值化，得到指示矩阵 \( B \)。
- 按列求和得到频率向量 \( C \)，表示每个 token 被识别为关键 token 的频次，可反映相似度与集中度。
- 基于变异系数计算每个 head 的分数：
  \[
  \text{score} = \frac{\sqrt{\frac{1}{N}\sum_i(C_i - \mu(C))^2}}{\mu(C)}
  \]
  一致性头在观察矩阵中行间高度相似、少量列集中大量注意力，CV 分数较高；自适应头则分布分散、行间差异大，CV 分数较低。通过阈值（按自适应头比例 r 的分位数）判断头类型。

**（2）参考集静态识别（Reference-Based Static Identification）**：
- 动态逐样本识别代价高且不利于内存管理。论文发现同一头在不同样本间的分类结果高度一致（重叠率 > 80%），因此使用参考数据集离线确定模型级固定头类型，推理时直接复用。

**（3）缓存策略**：
- 对一致性头：仅保留 top-k 关键 KV 对（采用 chunk + block max 策略，便于与检索方法集成）。
- 对自适应头：按保留比例 η 保留大部分 KV 对。
- GQA 模型中，以组内各头 attention 矩阵均值作为观察矩阵。
- 算法流程分为 Pre-filling（观测、识别关键 chunk、按头类型选择性缓存）和 Decoding（按头类型直接调用缓存或进行检索式注意力）。

**（4）理论分析**：
- 给出了基于 Rademacher 复杂度的泛化上界（Lemma 1），并将 token 保留精度的下界分解为三个关键因素（Theorem 1）：注意力分数排序的有效性 λ、预算控制策略、以及头分类准确率 P_head。

- **核心结论**：LLM 的部分注意力头具有跨 prefilling 与 decoding 的稳定注意力模式（顺序一致性），可用变异系数算法精确分类。
