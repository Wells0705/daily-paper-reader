## 摘要
基于大语言模型（LLM）的智能体正越来越多地应用于漏洞发现和自动化渗透测试等网络安全任务。然而，在长时程安全任务中，此类智能体仍受限于上下文遗忘与意图漂移：早期关键事实与因果推理链在长时间交互中丢失，智能体陷入漫无目的、重复性的探索。本文提出 Intentest，一种由意图图引导的自动化渗透测试智能体，它将长时程状态从 LLM 的上下文窗口外化到一个持久化的事实—意图有向无环图（DAG）上，从而大幅减少无效状态转移。我们在 Web 应用自动化渗透测试这一网络安全领域具有代表性的长尾任务上评估了 Intentest。在该 DAG 中，经验证的网络状态被存储为不可变的事实节点，探索方向被约束为以前驱事实为边界的意图边。系统采用三层架构：事实—意图映射层维护全局状态；任务调度与分配层通过两阶段降级恢复和多维自适应负载均衡保障执行稳定性；意图检索与预测层通过自顶向下的五阶段过滤算法提供战术先验。在覆盖三大难度级别、十余种漏洞类型的真实 CTF 挑战基准上，Intentest 取得了 88.2% 的总体成功率和 75.0% 的困难任务成功率，相较基线分别提升约 44 和 50 个百分点。消融实验进一步表明，意图检索与预测在不改变可解任务集合的前提下，使成功完成的中等和困难任务的平均轮数分别减少约 33% 和 48%。

## Abstract
Large language model (LLM) based agents are increasingly applied to cybersecurity tasks such as vulnerability discovery and automated penetration testing. On long-horizon security tasks, however, such agents remain limited by context forgetting and intent drift: early critical facts and causal reasoning chains are lost over extended interactions, and the agent falls into aimless, repetitive exploration. This paper proposes Intentest, an intent-graph-guided automated penetration testing agent that externalizes long-horizon state from the LLM's context window onto a persistent fact-intent directed acyclic graph (DAG), thereby substantially reducing invalid transitions. We evaluate Intentest on automated penetration testing of web applications, a representative long-tail task in cybersecurity. In the DAG, verified network states are stored as immutable fact nodes, and exploration directions are constrained as intent edges bounded by predecessor facts. The system adopts a three-layer architecture, in which the fact-intent mapping layer maintains the global state, the task scheduling and allocation layer ensures execution stability through two-phase degradation recovery and multi-dimensional adaptive load balancing, and the intent retrieval and prediction layer provides tactical priors through a top-down five-stage filtering algorithm. On a benchmark of real CTF challenges covering more than ten vulnerability types across three difficulty levels, Intentest achieves an overall success rate of 88.2% and a success rate of 75.0% on hard tasks, improving over the baseline by approximately 44 and 50 percentage points. Ablation experiments further show that the intent retrieval and prediction reduce the average number of rounds on successful medium and hard tasks by about 33% and 48%, respectively, without changing the set of solvable tasks.

## 1. 核心问题与整体含义

- **研究背景**：基于 LLM 的智能体正被广泛用于漏洞发现与自动化渗透测试。渗透测试可建模为部分可观测马尔可夫决策过程（POMDP），其网络拓扑、开放端口、服务版本、防火墙规则等状态对智能体部分隐藏，需要长序列侦察与探测才能获得观测。
- **核心痛点**：
  - **上下文遗忘（context forgetting）**：LLM 的线性上下文窗口无法承载非线性、网状的因果关系，长交互中早期关键事实（如内网段发现、数据库凭证）被截断丢失。
  - **意图漂移（intent drift）**：智能体偏离最初设定的渗透目标，陷入漫无目的、重复性的局部探索。
  - **其他瓶颈**：经典规划依赖预定义谓词与确定性动作空间，面对 0-day 或私有协议易陷入逻辑死锁；RAG 是"无状态的局部文本相似度检索"，易因词面重叠引入噪声与因果关联幻觉；纯 SFT 存在幸存者偏差。
- **整体含义**：论文主张将长时程状态从 LLM 上下文窗口**外化**到一个持久化、图论化的状态机（事实—意图 DAG）上，让 DAG 决定智能体"能否维持长时程推理"，让意图图决定"探索效率有多高"。

## 2. 方法论（Intentest）

### 2.1 核心思想
- 采用 **BDI（Belief-Desire-Intention）框架**映射到网络安全场景：
  - **Goal**：宏观静态终态（如获得域控权限）；
  - **Action**：底层引擎直接执行的具体命令；
  - **Intent**：连接宏观目标与细粒度动作的战术承诺，受当前已知状态约束。
- 把 POMDP 中的信念状态 $b_t$ 外化到持久图结构：**写入新事实的后向边等价于更新 $b_t$**，**前向边把可行动作限制在已被验证事实支撑的子集内**。

### 2.2 关键技术细节

**（1）事实—意图 DAG 映射**
- 定义 1：DAG 为四元组 $G=(F,I,E_{f\to i},E_{i\to f})$，其中 $F$ 为已验证的不可变事实节点，$I$ 为意图节点；$E_{f\to i}$ 是由事实触发意图的前向边，$E_{i\to f}$ 是意图成功后产生新事实的后向边。任意有向路径交替经过事实与意图节点且无环。
- 六个核心持久表：`project`（项目生命周期 + 独占租约锁）、`fact`（不可变已验证事实）、`intent`（单步因果有向路径 + 心跳时间戳动态回收）、`intent-source`（桥表，支持多前驱事实共同触发一个意图的超图语义推理）、`prompt`（专家异步战术指导）、`scope`（项目级隔离命名空间）。
- 多智能体采用**基于全局共享状态的异步间接协作**：以 DAG 作为唯一通信媒介，避免点对点通信的广播风暴与状态冲突。

**（2）意图节点四状态有限状态机**
- 状态 $S=\{s_1,s_2,s_3,s_4\}$ = CREATED / CLAIMED / CONCLUDED / COMPLETED。
- 事件集 $\Sigma=\{\text{claim},\text{conclude},\text{goal},\text{timeout}\}$，转移函数：
  - claim：$s_1 \to s_2$
  - conclude：$s_2 \to s_3$
  - goal：$s_3 \to s_4$
  - timeout：$s_2 \to s_1$（超时回收，重新可认领）
- 命中目标后所有未完成意图迁移至 COMPLETED，后续调度关闭，保证终态不可逆。

**（3）任务调度与自适应负载均衡**
- 三类标准化任务与优先级：**Bootstrap**（初始广谱扫描）、**Explore**（单步验证，常规最高优先级）、**Reason**（全局事实增量规划，单项目互斥锁，仅当全局无未认领 Explore 任务且有新事实/专家提示时唤醒，避免空转）。
- 负载均衡六级筛选：①协议一致性仲裁 → ②容量安全检查 → ③健康探针检查 → ④优先级权重选择 → ⑤活动负载均衡 → ⑥随机抖动。算法以 $D_\tau$（任务工具依赖）、$D_n$（节点可用依赖）、$L(n)$（活动任务数）、$C_n$（最大并行度）、$w(n)$（优先级权重）为参数。
- **两阶段降级恢复**：主执行阶段超时（Explore/Bootstrap 均为 180 秒）后不销毁容器，而是在同一会话触发 90 秒降级阶段，注入高优先级紧急截断提示，强制停止网络层探测、收集残余 stdout/stderr 并上报部分事实。Reason 任务超时不降级，直接失败并释放锁以保持全局逻辑一致性。
- **两层防御**：①结构前置条件验证（意图只能由已验证事实节点触发，外部载荷诱导的指令因无事实依据被构造性拒绝）；②容器级隔离（Docker 独立容器 + 生命周期管理器监控终止信号，项目停滞或验证失败时触发系统级 abort）。

**（4）意图图构建与检索预测**
- 三类有向图：离线**意图图**（批量爬取威胁情报与演练文档，LLM 抽取器做语义因果抽取并映射到 MITRE ATT&CK，错误路径单独存储）、在线**攻击图**（实时记录实际探测到的物理拓扑）、运行内存中的**融合图**（跨图链接，用历史经验补偿目标网络的局部视野缺失）。
- **自顶向下五阶段检索预测算法**：
  1. 高维语义嵌入空间探测：用 Qwen3-Embedding-4B 向量化，按余弦相似度 $\text{sim}_{\cos}(v,\phi(i))=\frac{v\cdot\phi(i)}{\|v\|\|\phi(i)\|}$ 保留 Top-k 战术簇；
  2. 子图同构验证：对候选意图的前驱子图做同构校验，抑制词面重叠导致的因果幻觉（成本受限于 $O(k)$ 次局部同构检查）；
  3. 降级模糊统计推断：同构失败时回退到基于 Jaccard 系数 $J(A,B)=|A\cap B|/|A\cup B|$ 的模糊图相似度匹配；
  4. 战略意图对齐：将候选序列映射回宏观意图层，与授权目标 $g$ 及主漏洞链比对，剪除偏离主目标的冗余分支；
  5. LLM 启发式推理：前四阶段均无匹配时（闭源协议、无历史特征），注入降维环境日志与残余拓扑，由 LLM 做启发式判断。
- **关键约束**：五阶段算法只是"战术推荐器"，不授权执行；任何新意图（包括 Stage 5 的输出）必须通过 DAG 前置条件验证才能写入意图表，幻觉或被注入的指令因无已验证事实依据而被构造性拒绝。
- **异步意图桥注入**：仅在一次成功 Explore 任务写入新事实后触发；余弦相似度阈值 $\theta=0.3$ 过滤噪声；注入提示分三块——推荐下一步战术动作、支撑证据链、当前项目上下文；构建提示时剥离所有冗余元数据（相似度分数、来源报告名、底层匹配细节）。

## 6. 主要结论与发现

- **RQ1（有效性）**：Intentest 在三个难度档均取得最高成功率——easy 100.0%、medium 90.9%、hard 75.0%、总体 **88.2%**。相较总体最高的基线 VulnBot（44.1%）提升约 **44 个百分点**，困难任务提升约 **50 个百分点**（25.0% → 75.0%）。所有总体差异均统计显著（p < 0.001）。优势随难度增加而扩大，印证了长尾事实推理瓶颈的动机分析。
- **RQ2（效率）**：成功任务平均轮数约 **7 轮**，显著低于 Pentest-R1（约 20 轮）、Claude Code（约 12 轮）、VulnBot（约 23.6 轮，约为 Intentest 的 3.4 倍）；失败任务平均轮数约 34 轮，与 VulnBot（约 32.8 轮）相当，低于 Pentest-R1（40 轮，即预算耗尽）。
- **RQ3（消融）**：禁用意图模块**不改变可解任务集合**（两种配置成功率完全相同），但成功任务平均轮数从 11 降至 7；medium 降低约 **33%**（10.8 → 7.2），hard 降低约 **48%**（18.3 → 9.4）。失败任务轮数略有增加（40 vs. 37；31.7 vs. 29.3），解释为有引导时智能体会做更有针对性的验证。
- **失败模式对比**：VulnBot 的失败集中于推理与状态缺陷——F1 过早宣告成功、F2 长时程角色/状态混淆（在错误主机上找 flag）、F3 长输出中信号遗漏（注意力稀释）、F4 僵化剧本与冗余重执行；且均非预算耗尽。Intentest 的失败集中在"专家级、多漏洞组合成单条利用链、需要框架内部知识"的任务上，属难度天花板而非推理或状态层缺陷。
- **结论**：图结构化状态是**可解性**的决定性因素，意图模块主要决定**探索效率**；二者分工明确，共同构成 Intentest 的核心。

## 7. 优点

- **架构层面外化状态**：用持久化 DAG 替代 LLM 隐式记忆，把"记忆"变成可验证、可回溯、可约束的图结构，思路清晰且有理论形式化（DAG 定义、四态 FSM、POMDP 映射）。
- **安全边界设计扎实**：结构前置条件验证 + 容器级隔离构成两层防御，使间接提示注入（IPIA）诱导的意图在构造上就无法获得执行授权；明确区分"推荐器"与"执行授权层"。
- **工程鲁棒性细节完备**：两阶段降级恢复机制（超时不销毁容器、从残余日志抢救部分事实）、六维负载均衡、心跳租约与超时回收，针对真实环境的网络延迟与畸形 JSON 输出。
- **检索机制设计有层次**：五阶段流水线从语义嵌入 → 子图同构 → Jaccard 模糊回退 → 战略对齐 → LLM 启发式，既用结构约束抑制幻觉，又在无历史特征时保留 LLM 的泛化探索能力；匹配成本受 Top-k 限制。
- **实验设计客观性较好**：统一 LLM、统一轮数预算、引入 Fisher 精确检验、黑名单防数据泄漏、明确指出 DAG 无法受控消融并诚实给出三条佐证性证据。
- **失败分析深入**：将基线失败归为四类可辨识模式，并与动机部分的三个问题一一对应，形成闭环论证。
- **适用边界阐述清晰**：明确指出意图图是"结构化战术先验"而非新攻击知识来源，在无历史特征的攻击面上仅靠 DAG 约束 + Stage 5 保底。

## 8. 不足与局限

- **Benchmark 规模与真实性**：
  - 仅约 34 道 CTF 题目，远小于生产网络资产规模；三档难度分档较粗。
  - CTF 通常只涉及单一应用或小网段，而生产内网含大规模拓扑与异构服务，内网横向移动与跨段穿越是核心，本工作未覆盖。
  - CTF 中的 WAF、蜜罐与生产环境的 EDR、IDS、微隔离、动态网络策略差异显著。
  - 生产测试受业务连续性与合规约束（如反复爆破、提权尝试受限），操作边界与 benchmark 不同。
- **DAG 无法受控消融**：VulnBot 对比属跨系统对照，二者在编排结构与工具链上均有差异，证据为佐证性而非结论性。
- **意图图的时效性与覆盖缺口**：离线图源自历史报告，新漏洞类别、0-day 变体与未出现过的攻击模式缺失，前四阶段无法提供先验，先验质量依赖图的
