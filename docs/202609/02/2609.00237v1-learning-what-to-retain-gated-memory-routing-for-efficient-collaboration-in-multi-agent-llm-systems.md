## 摘要
基于大语言模型的多智能体系统通过编排多个智能体的配置与协作方式来处理复杂推理。核心挑战在于使编排适应不断演化的协作状态。仅依据查询进行路由无法适应中间进展或错误，这会损害准确性。依据完整执行历史进行路由能提供缺失的上下文，但会迫使后续决策处理每一个先前步骤，包括冗余或低效用的步骤，造成执行历史过载，增加成本。有效的编排反而需要一种紧凑的状态，既能捕捉有用的进展，又不积累冗余上下文。我们提出门控记忆路由，它将每个决策建立在查询和学习到的执行记忆之上。学习到的记忆写入门仅提交非冗余的推理步骤，学习到的检索门为每个智能体提供紧凑且相关的子集，从而使每个决策都基于干净、信息丰富的状态。在每一步，系统从该记忆中选择下一个角色和骨干，自适应终止控制器在记忆包含足够答案证据时停止执行。在五个推理和代码生成基准测试上，我们的框架既有效又高效：它达到了最佳平均准确率，比最强基线高出2.44个百分点，同时相对于该基线将HumanEval推理成本降低了31.9%。代码可在https://github.com/rajibrhasan/gated-memory-routing获取。

## Abstract
Large language model (LLM)-based multi-agent systems tackle complex reasoning by orchestrating how multiple agents are configured and how they collaborate. A central challenge is to adapt orchestration to the evolving collaboration state. Routing from the query alone cannot adapt to intermediate progress or errors, which hurts accuracy. Routing from the complete execution history supplies this missing context, but forces later decisions to process every prior step, including redundant or low-utility ones. This creates an execution-history overload that inflates cost. Effective orchestration instead requires a compact state that captures useful progress without accumulating redundant context. We propose Gated-Memory Routing, which conditions each decision on the query and a learned execution memory. A learned Memory Write Gate commits only non-redundant reasoning steps, and a learned Retrieval Gate supplies each agent a compact, relevant subset, so every decision conditions on a clean, informative state. At each step, the system selects the next role and backbone from this memory, while an Adaptive Halting Controller stops execution once the memory contains sufficient evidence for answering. Across five reasoning and code-generation benchmarks, our framework is both effective and efficient: it attains the best average accuracy, exceeding the strongest baseline by 2.44 points, while reducing HumanEval inference cost by 31.9% relative to that baseline. Code is available at https://github.com/rajibrhasan/gated-memory-routing

# 论文总结：Learning What to Retain: Gated-Memory Routing for Efficient Collaboration in Multi-Agent LLM Systems

## 1. 论文的核心问题与整体含义

**研究动机与背景：**
- 基于 LLM 的多智能体系统通过多智能体分工、批判与协作来解决复杂推理任务，其核心挑战在于**编排（Orchestration）问题**——如何决定智能体数量、角色分配、模型选型和上下文内容。
- 已有方法的局限主要体现在两条路线：
  - **查询级路由（Query-only Routing）**：如 MASRouter，仅在任务开始前根据输入查询一次性完成决策，无法感知执行过程中出现的中间进展、错误或遗漏，导致准确率受限。
  - **全历史路由（Full-History Routing）**：如 Puppeteer，将完整执行历史逐步累积并暴露给后续决策，虽然提供了演化上下文，但未加过滤地保留全部中间步骤，导致“执行历史过载”——上下文不断膨胀、冗余噪声累积、推理成本大幅上升。
- 论文的核心观点是：**有效的多智能体编排应基于一个紧凑、选择性的记忆状态来路由**，而非仅依赖原始查询或未加筛选的完整历史。系统需要学会“该保留什么”与“该暴露什么”。

## 2. 方法论：核心技术思想与流程

**核心思路框架：**
提出 **Gated-Memory Routing（门控记忆路由）**，将路由决策统一建立在“门控执行记忆”（Gated Execution Memory）之上。该方法将多智能体多步协作形式化为一个序贯决策过程，状态表示为 `st = (q, S_{t-1})`，其中 `S` 为记忆中的保留记录；每一步动态选择角色与 LLM 骨干，并控制记忆的写入、检索与终止。

**五个核心模块：**
- **History-Aware Role Allocator（历史感知角色分配器）**：基于当前状态（查询 + 记忆），通过 VAE 将角色描述编码为连续潜在向量，使用 softmax 策略按上下文匹配程度选择下一智能体角色，而非从查询或完整历史中固化角色。
- **LLM Router（LLM 路由器）**：在选定角色后，基于“角色条件化状态”在异构骨干模型池（Llama-3.2-3B 至 Qwen-2.5-32B）中采样选择最匹配当前需求的骨干模型，每个模型同样以能力描述嵌入表示。
- **Retrieval Gate（检索门）**：针对记忆中每条记录独立做伯努利采样（是否取出），使每个智能体获得的任务上下文大小可自适应变化，避免了固定 top-k 检索的刚性。
- **Memory Write Gate（记忆写入门）**：以**学习型最大边际相关（MMR）** 为判据，衡量新增推理步骤与当前任务的相关性以及相对已有记录的新颖性（冗余度），加权后经 sigmoid 采样决定是否将该步骤写入记忆，从而保证记忆紧凑、非冗余。
- **Adaptive Halting Controller（自适应终止控制器）**：用 GRU 汇总后写记忆状态，输出伯努利决策判断是否已具备充足证据，可停止继续执行；配合最大深度上限，使每个查询的推理深度和成本自适应。

**训练与优化：**
- 各模块均为随机离散决策（角色、骨干、检索、写、停），通过 **策略梯度** 以组相对优势（类似 GRPO）联合训练。
- 同一查询采样 G 个轨迹，以组内轨迹效用差异作为 Advantage（不做标准差归一化，避免近零方差导致数值不稳定）。
- 目标函数结合任务成功率与推理成本惩罚（λ_c）进行权衡，加入 VAE 正则项和熵正则项；LLM 骨干和句子编码器均冻结。

## 6. 主要结论与发现

- **准确率最高**：五个基准平均准确率 **77.73%**，超过最强基线（Puppeteer-32B 的 75.29%）**2.44 个百分点**；在 MATH、GSM-Hard、HumanEval、MMLU-Pro 四项上均登顶（MBPP 略低于固定拓扑 MacNet-Chain-14B，但优于 MASRouter）。
- **显著降本**：在 HumanEval 上，相比 MASRouter 成本降低 43.86%、相比 Puppeteer-32B 降 31.9%，并且准确率同时更高，处于 Pareto 前沿高准确率端。
- **路由是准确率的关键**：消融显示去掉 LLM Router 损失最大（GSM-Hard 下降达 14 分），角色分配影响次之。
- **记忆门控保障状态质量**：写入门或检索门单独去除都会降低准确率；两者同时去除平均下降约 2.56~6.25 分。
- **自适应终止是控本杠杆**：去除终止策略使测试成本在 GSM-Hard 上升超 40%、在 HumanEval 上翻倍以上，训练时 rollout 步数也增至约 1.8 倍，且准确率不升反降。
- **深度预算存在饱和**：φ = 6 已接近准确率-成本曲线的拐点，φ 从 6 增至 10 仅有不到 1 个百分点的提升但成本继续显著增加。
- **门控记忆 ≈ 全历史准确率但成本更优**：Gated-Memory 相对 Full-History 在 GSM-Hard 上成本降低约 40%、HumanEval 上超 50%，准确率基本持平或略高，验证了选择性记忆相对全历史的核心优势。
