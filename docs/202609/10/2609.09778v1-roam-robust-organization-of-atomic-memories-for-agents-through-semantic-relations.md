## 摘要
长期语言模型智能体在多次交互中依赖外部记忆。原子记忆尤其有用：其细粒度语义边界能够实现精确检索以及观察之间的直接比较。然而，不断累积的原子不可避免地会变得冗余、重叠或冲突。现有方法通常让 LLM 管理器直接添加、更新、删除或重写记忆，将语义解释、存储决策和内容生成耦合在一个易出错的操作中。我们提出 ROAM，一个关系引导的框架，它在管理时利用原子性，同时允许在回答时使用更丰富的表示。ROAM 将新到的原子与已存储的原子对分类为独立、等价、方向性包含或冲突，然后将观察组织为活跃的 Primary 和支持性的 Evidence 角色。融合随后将互补细节和时间变化组合成紧凑的、可能非原子的视图。回答时只检索 Primary 视图，防止冗余或过时的原子独立参与竞争。在不同模型和评估设置中，ROAM 将回答准确率最多提升 29.8 个百分点。消融实验表明，不同关系带来互补收益，而融合在角色组织之外带来一致增益。机制分析进一步发现，答案关键来源召回率提高 15.6 个百分点，混杂 token 占比降低 11.5 个百分点。ROAM 在不同管理器规模下保持鲁棒。

## Abstract
Long-term language-model agents rely on external memory across interactions. Atomic memories are particularly useful: their fine-grained semantic boundaries enable precise retrieval and direct comparison between observations. Yet accumulating atoms inevitably become redundant, overlapping, or conflicting. Existing methods often ask an LLM manager to add, update, delete, or rewrite memories directly, coupling semantic interpretation, storage decisions, and content generation in one error-prone operation. We introduce ROAM, a relation-guided framework that uses atomicity for management while allowing richer answer-time representations. ROAM classifies incoming--stored atom pairs as independent, equivalent, directionally subsuming, or conflicting, then organizes observations into active Primary and supporting Evidence roles. Fusion subsequently combines complementary details and temporal changes into compact, potentially non-atomic views. Only Primary views are retrieved for answering, preventing redundant or outdated atoms from competing independently. Across models and evaluation settings, ROAM improves answer accuracy by up to 29.8 percentage points. Ablations show complementary benefits from different relations and consistent gains from fusion beyond role organization. Mechanism analysis further finds 15.6-point higher answer-critical source recall and an 11.5-point lower confounder-token share. ROAM remains robust across manager scales.

## 1. 核心问题与整体含义

- **背景**：长期语言模型智能体需要跨交互维护外部记忆。原子记忆（细粒度事实）便于精确检索、比较与更新，已成为长期记忆系统的常见表示基础。
- **核心问题**：原子记忆持续流入后会产生冗余、重叠、冲突或过时记录。现有方法（如 Mem0）通常让 LLM 管理器直接执行 `ADD / UPDATE / DELETE / NONE`，把语义理解、存储决策与内容生成耦合在一次黑箱操作中，导致结果不稳定、历史可追溯性差。
- **整体含义**：论文主张将“语义关系推断”与“确定性存储控制”解耦，用显式关系引导记忆组织，而不是让模型直接改写记忆。这样既能消除冗余，又能保留历史溯源，并让回答时只检索活跃的 Primary 视图。

## 2. 方法论

- **核心思想**：ROAM 是一个关系引导的记忆管理框架。它先判断新观察与已有原子记忆之间的五类语义关系，再通过固定策略更新记忆角色，最后融合生成紧凑的检索视图。
- **五类语义关系**：
  - `IND`：独立，两者可同时为真且无蕴含关系。
  - `EQV`：等价，真值条件相同、互相蕴含。
  - `OSN`：旧被新包含，新观察严格蕴含旧观察并增加特异性。
  - `NSO`：新被旧包含，旧观察严格蕴含新观察，新观察不增加特异性。
  - `CON`：冲突，同一实体同一单值属性出现不兼容状态；时间可解释的变化也视为冲突。
- **记忆记录结构**：每条记忆保存为不可变记录 \(M_i=(a_i,v_i,\tau_i,c_i,z_i)\)，其中 \(a_i\) 是原子文本，\(v_i\) 是当前读取视图，\(\tau_i\) 是时间戳，\(c_i\) 是来源上下文，\(z_i\) 是角色。
- **角色划分**：
  - `Primary`：活跃记忆，可参与后续管理检索与回答检索。
  - `Evidence`：支持性/历史性记录，保留溯源，但不在回答时独立竞争上下文。
- **算法流程**：
  1. 对新观察 \(O_t\)，用其原子文本从已有 Primary 集合中检索 \(k\) 个候选记忆 \(C_t=\rho_k(a_t,P_{t-1})\)。
  2. 关系模型 \(\Phi(a_t,a_i)\) 对每个候选对预测关系 \(r_t(i)\in\{IND,EQV,OSN,NSO,CON\}\)。
  3. 若多个候选关系不同，按优先级选择：`CON ≻ OSN ≻ EQV ≻ NSO ≻ IND`。
  4. 根据选中关系执行确定性角色更新：
     - `IND`：新观察插入为新 Primary。
     - `EQV`：最早匹配的 Primary 存活，其余变 Evidence，去除冗余。
     - `OSN`：新观察成为 Primary，旧匹配变 Evidence，保留新增特异性。
     - `NSO`：最早匹配的 Primary 存活，新观察变 Evidence。
     - `CON`：新观察成为当前 Primary，旧匹配变 Evidence，构建时间历史。
  5. 对非独立更新，将存活 Primary 与 Evidence 按时间排序，调用融合模块生成新的读取视图：\(v_{M^*}\leftarrow Fuse(View(S_1),...,View(S_n);r_t^*)\)。
  6. 回答时只检索 Primary 的读取视图，Evidence 不独立参与检索竞争。
- **关键设计**：原子文本保持不变，仅更新角色和读取视图；管理时用原子文本做关系判断与溯源，回答时用融合视图做紧凑表示。
