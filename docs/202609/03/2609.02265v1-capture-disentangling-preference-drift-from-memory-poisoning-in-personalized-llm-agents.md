## 摘要
个性化语言代理使用持久记忆来随时间适应用户，但同一机制也创造了攻击面。当新信息与存储的偏好冲突时，代理必须区分真正的偏好漂移与暂时的上下文转变、模糊性或对抗性记忆中毒。我们将此问题形式化为一个关于潜在用户状态的连续时间部分可观测决策过程，并展示了为何仅基于新近性和来源的规则是不够的。CAPTURE通过神经微分方程信念追踪器、多时间尺度记忆账本、不确定性触发的澄清以及引用记忆的反事实审计来解决这一模糊性。在来自96名用户的480个保留情节中，CAPTURE达到了71.5%的胜率，而同样受监督的基线为69.3%，最强的启发式基线为66.1%。它将固定策略的中毒成功率限制在11.5%，同时接受83.5%的真正偏好更新。在面对可访问已发布权重的自适应攻击者时，攻击成功率上升至24.7%，暴露了真实的适应性-安全性权衡。我们还对一个独立构建的基准进行了冻结系统的零样本评估，并重放了从40名用户收集的跨越两到三周的纵向交互历史。这些结果表明，显式建模偏好真实性可以提高记忆增强型LLM代理的个性化和鲁棒性。

## Abstract
Personalized language agents use persistent memory to adapt to users over time, but the same mechanism creates an attack surface. When new information conflicts with stored preferences, an agent must distinguish genuine preference drift from temporary context shifts, ambiguity, or adversarial memory poisoning. We formulate this problem as a continuous-time partially observable decision process over a latent user state and show why rules based only on recency and provenance are insufficient. CAPTURE addresses this ambiguity with a neural differential-equation belief tracker, a multi-timescale memory ledger, uncertainty-triggered clarification, and counterfactual auditing of cited memories. On 480 held-out episodes from 96 users, CAPTURE achieves a 71.5% win rate, compared with 69.3% for an identically supervised baseline and 66.1% for the strongest heuristic baseline. It limits fixed-policy poisoning success to 11.5% while accepting 83.5% of genuine preference updates. Under an adaptive attacker with access to the released weights, attack success rises to 24.7%, exposing a real adaptation-security tradeoff. We further evaluate the frozen system zero-shot on an independently constructed benchmark and replay longitudinal interaction histories from 40 users collected over two to three weeks. These results suggest that modeling preference authenticity explicitly can improve both personalization and robustness in memory-augmented LLM agents.

## 1. 核心问题与整体含义

**研究动机**

- 个性化语言代理（Personalized LLM Agents）依赖持久记忆（persistent memory）来长期适应用户偏好，但记忆机制本身也是攻击面：检索到的网页、共享文档、工具输出都可能被攻击者利用，向代理记忆中注入恶意内容。
- 当一个代理发现某条新信息与已有记忆冲突时，它面临**偏好-真实性歧义（preference-authenticity ambiguity）**：同样的证据在单轮内可能来自——①用户的真实偏好转变（如换了管理岗位）；②用户在不同情境下的临时切换（如 Standup 要简短）；③反讽或歧义表达；④检索文档中夹带的对抗性投毒载荷。
- 现有方法的两种极端立场各有缺陷：
  - **个性化管线**：将历史视为真实，追求快速适应，容易被投毒者操纵；
  - **注入防御（provenance filtering）**：拒绝来源不可信的内容，但会阻断用户通过合法渠道（如总结文档）完成真实偏好调整，使代理随时间退化。

**核心洞察**

- 真实性（authenticity）应当被视为需要推断的**潜在变量**，而非需要断言的属性。
- 仅依赖**recency（新近性）**和**provenance（来源）**的固定规则无法解决该问题——定理证明其错误率存在一个下界（与对抗者模仿合法修订统计特性的能力相关）。利用完整历史信息或使用澄清问题，可严格扩展可实现误差区域。

## 2. 方法论

### 核心思想
将记忆更新形式化为**连续时间部分可观测决策过程**（continuous-time POMDP），其中潜在用户状态 $s_t = (v, c_t, g_t)$ 分别包含：稳定价值观（月级变化）、情境偏好（按域/项目）、瞬时目标（会话级）。代理对状态维持信念，通过估计事件真实性来决定是否写入记忆。

### 系统架构（一条事件经过的完整路径）

1. **偏好假设提取**（Preference-hypothesis extraction）
   - 使用 Qwen2.5-3B + LoRA，schema 约束解码，输出六元组：`H_t = (claim, direction, scope, timescale, confidence, provenance)`；
   - 训练目标包含交叉熵 + 弃权（abstention）奖励项（约七成事件无偏好信号，提取器必须学会“拒绝”）。

2. **真实性门控**（Authenticity gate）
   - 核心是一个**神经微分方程（Neural ODE）**：
     $$\frac{dh(t)}{dt} = f_\theta(h(t))$$
   - 事件之间的信念演化是自治的（autonomous），时间仅通过积分区间 $\Delta t$ 进入——这使系统能区分“一个下午40条消息”和“九天空白”的差异；瞬态信号在九天中大幅衰减，而稳定信号基本不动；
   - 事件到达时由离散 GRU 更新消费；
   - 面对候选假说，门控输出六类动作的分布：**保留、新增、收窄范围、全面修订、隔离待验证（quarantine）、向用户提问**；
   - 当动作分布Shannon熵超过阈值 $\eta$ 时触发澄清（去问用户）；验证集中最多一轮澄清/12轮交互。
3. **多时间尺度记忆账本**（Multi-timescale ledger）
   - 三层结构：**stable / contextual / transient**，各自设置基础衰减率（通过验证集网格搜索固定：$\gamma_s=0.01$、$\gamma_c=0.1$、$\gamma_g=0.5$，单位为天−1）；学习率部分为门控潜在状态 $σ(h_t)$，端到端训练；
   - 节点置信度：$c_0 \sigma(h_t) \exp(-\gamma(t-t_0))$；
   - **隔离（quarantine）是一种状态而非第四层**：被隔离的节点不可检索，以速率 $\gamma_q = 0.135$ 衰减，约14天后触底（floor 0.15）被逐出；若在此前获确证则被提升（promote）；
   - 扁平记忆无法表达“在Standup中要简短（scope）”与“全面修订（revise）”的语义差别，分层账本解决这一问题。
4. **安全约束的选择与因果审计**（Safety-bounded selection & causal audit）
   - 安全选择器独立于个性化循环，从账本和候选响应中按 $y^\star = \arg\max_{y\in Y} [\alpha r_p(y) - \beta r_s(y)] \quad\text{s.t.}\quad r_s(y) \le \tau_{safe}$ 选取输出；账本内容无法改动 $\tau_{safe}$；
   - 可解释性：不使用注意力或检索排名（文献证明其不可靠），而是**反事实移除重解码**：
     $$\text{Inf}(n_i) = U(y_{factual}) - U(y_{L\setminus n_i})$$
   - 同一轮内：移除后不影响输出的引用被丢弃（提升 Evidence F1）；
   - 跨轮：累积影响分数低的节点在检索时被降权。

### 理论结果（简要）
- **定理2（不可能性）**：任何只读 $φ=(recenty, provenance)$ 的规则，$\text{FUR}(d) + \text{RRL}(d) \ge 1 - δ_φ$（固定对抗者下可达，以似然比检验达到）。
- **定理3（数据处理不等式）**：条件于完整历史不劣于 $φ$；且在给定条件下严格更优。
- **定理4（澄清扩大可实现区域）**：若澄清成本 $κ$ 和通道误差 $\varepsilon$ 之和低于无查询 Bayes 误差，则“问”胜过所有“不问”规则。

## 3. 实验设计

### D-PREFGUARD 基准（作者构建）
- **规模**：2400 条纵向 episode（12–20 轮/条），来自 96 个用户的 480 条测试保留；
- **覆盖5个轨道**：
  - T0：静止（任何更新都算误报）；
  - T1：4 种真实漂移形态（突变、渐变、复发、情境切换）；
  - T2：良性歧义（反讽、错字、弱证据）；
  - T3：3 类污染（间接注入、投毒摘要、同源写入 each 160 episodes）；

## 6. 主要结论与发现

- **关于自适应-安全前沿（Q1–Q2）**：
  - 无免费的 tradeoff 曲线：Recency RAG 接受率最高但投毒最严重（51.6%）；Provenance-only 投毒最低（20%）但接受率低（74.1%）；CAPTURE 以 11.5% 投毒率 + 83.5% 真实更新接受率 + 8.9% 假更新率，同时超越两者；
  - 胜率 71.5% vs StateMem 66.1%；Recency RAG 恢复更快且拒绝更少——保隔离的代价；
  - 与 StateMem 相比，在 context-switch 上 CAPTURE 71% 选择 scope（降容量）而 StateMem 仅 4%；
  - 同源（same-origin）污染是 CAPTURE 的主要残余失败（成功投毒中占50.7%，攻击成功率为17.5% vs Provenance-only 的43.6%）。
- **组件贡献（Q3）**：真实性门控承担安全结果（去掉后投毒 +22.0pp）、来源特征另有 +14.0pp（互补）；时间尺度分离带来 +5.4pp 的接受率，探问 +3.6pp；移除安全边界使投毒攻击成功翻三倍。
- **监督 vs 架构（Q4）**：监督 Transformer 达到 15.9% 投毒和 69.3% 胜率（StateMem 到 CAPTURE 大半路径）；CAPTURE 残余优势：胜率 +2.2pp（p=0.011）、投毒 −4.4pp（p=0.003）；标签层面 macro-F1 无显著差异（0.71 vs 0.68，p=0.13）→ **架构优势在账本和时间更新，不在逐事件分类**。架构优势迁移到外部基准但幅度温和（HorizonBench contradiction resolution +0.04，p=0.008）。
- **自适应攻击（Q5）**：自适应攻击者（32候选释义搜索，使用发布权重对 shadow-state 粒子打分以最大化 add+revise−quarantine−clarify）将 CAPTURE 的投毒从11.5%提高到24.7%（同源达38.1%）；此时与 Provenance-only（22.1%）无显著区分（p=0.29）；CAPTURE 的残余优势是同安全下更高的接受率（83.5% vs 74.1%）。独立红队攻击成功率为18.3%（仍最低）。
- **跨骨干（Q6）**：连续时间门控在 Qwen3 上前述离散门控 2.4 个百分点；给离散门控显式 Δt 输入可恢复约 55% 差距。

**综合结论**：显式建模偏好真实性可同时在个性化和鲁棒性两端取得进步，其中大部分来自监督式时间追踪（Transformer 也能达到）；账本与连续时间更新提供更小但可在独立数据上迁移的增益。自适应攻击仍是开放问题，对 provenance 过滤器的优势未被可靠区分。

   - 共同池后悔设计使所有方法面对同一定义；matched split 体现 Theorem 2 的实证检验（FUR+RRL 精确等于 1−d̂TVφ，C1）；
   - 预先声明5个可证伪标准（C1–F5）并如实逐条汇报（F4“勉强通过”，F5 依赖判别器有强假设）。
4. **主动应对外部效度**：冻结系统 → 独立构建的基准 → 真实用户重放 → 外部红队独立攻击 → 生成器交叉（未参与训练的90/10分），多层防泄漏措施。
5. **计算透明**：公布每轮延迟和 token 数，明确说明额外推理成本。

## 8. 不足与局限

1. **与真实部署仍有差距**：D-PREFGUARD 是合成数据；即使经外部验证与真实用户重放缓解，也不能视作部署级数值。40个真人用户只支持效果估计，不支持亚组结论。
2. **自适应攻击下安全优势消失**：自适应攻击者将投毒成功率提高一倍以上（→24.7%），与 provenance-only 无显著安全差异——作者诚实报告但暴露出核心弱点；约21%成功攻击是“慢投毒”（多轮小幅度漂移），这本质上是难分的问题。
3. **理论结果的局限性**：定理的 worst-case 形式是 maximin 值而非 minimax；固定攻击者下可达；定理证明依赖解释成本、澄清通道假设（error ε 的对称通道是正面设定，实际澄清精度未知）；matched evaluation 的配对期望距离小于部署距离，不能直接用于 Equation 11 的部署解释。
4. **残余泄漏风险**：虽采用多重泄漏控制，但 D-PREFGUARD 的训练/开发仍使用同一个生成器统一生成；真人重放中的污染是作者构造的（非独立攻击）；HorizonBench 和真人研究均不能同时验证“自然历史+独立攻击”的组合。
5. **效果量衰减**：CAPTURE 相较监督 Transformer 的赢率优势只有 2.2 个百分点（[0.6, 3.9]）；在 HorizonBench belief-revision 精度上 Recency RAG 反而领先（0.79 vs 0.78）；跨生成器优势幅度不大。
6. **量化限制**：实验在多组 metric 上依赖 GPT-4.1 作为 judge（与真人一致率 87.4% 低于人-人 91.2%）；模型超参数很大一部分在验证集上网格或阈值搜索后冻结，难以严格排除过拟合特定数据。
