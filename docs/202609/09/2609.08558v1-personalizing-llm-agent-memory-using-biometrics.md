## 摘要
个性化记忆通过跨交互存储和重用特定用户数据，帮助LLM智能体提供稳定、定制化的辅助。然而，在多用户场景中，检索不仅要考虑语义相似性，还要考虑当前请求者是否与存储记忆关联的身份匹配。我们提出Bio-Memory，一种生物特征感知的记忆架构，它同时基于语义相似性和生物特征匹配来调节记忆检索。Bio-Memory构建在A-Mem之上，为每条原子记忆笔记附加生物特征嵌入，并在语义排序前利用生物特征匹配形成检索候选池。我们在10用户共享智能体设置下，基于7个人脸基准和10个掌纹协议在LoCoMo上评估Bio-Memory。跨数据集上，Bio-Memory始终区分拥有者与非拥有者查询。在人脸个性化设置下，CALFW上F1/BLEU-1的最大平均差距达到27.29%/21.15%；在掌纹个性化设置下，MS_Blue上的相应差距为25.75%/19.22%。这些结果支持生物特征作为共享环境中个性化记忆检索的实用控制信号。

## Abstract
Personalized memory helps LLM agents deliver stable, tailored assistance by storing and reusing user-specific data across interactions. In multi-user scenarios, however, retrieval must consider not only semantic similarity but also whether the current requester matches the identity associated with the stored memory. We propose Bio-Memory, a biometric-aware memory architecture that conditions memory retrieval on both semantic similarity and biometric matching. Built on top of A-Mem, Bio-Memory augments each atomic memory note with a biometric embedding and uses biometric matching to form the retrieval candidate pool before semantic ranking. We evaluate Bio-Memory on LoCoMo in a 10-user shared-agent setting over 7 face benchmarks and 10 palmprint protocols. Across datasets, Bio-Memory consistently separates owner and non-owner queries. Under face-based personalization, the largest average gap reaches 27.29% / 21.15% in F1 / BLEU-1 on CALFW; under palmprint-based personalization, the corresponding gap is 25.75% / 19.22% on MS_Blue. These results support biometrics as a practical control signal for personalized memory retrieval in shared environments.

## 论文详细总结：利用生物特征个性化 LLM 智能体记忆（Bio-Memory）

### 一、核心问题与研究动机

- **问题核心**：在多用户共享的 LLM 智能体环境中（如智能家居助手、公共终端、企业助手），记忆检索不仅需要匹配语义相关性，还必须甄别“当前是谁在提问”，即回答“谁的记忆应被检索”的问题。
- **背景**：现有记忆系统（如 A-Mem、MemoryBank、Mem0 等）几乎都默认检索只需考虑任务相关性，而身份信息多依赖外部输入（账户、用户 ID、会话边界）。这假设在共享设备/共享会话中极为脆弱——同一物理设备可能被多人轮流使用，且一个用户的对话往往流经原先的开放式记忆空间。
- **安全与个性化风险**：当多个用户的记忆存在于共享记忆池中时，仅凭语义相似度进行检索，会让来自不同用户的语义相似内容相互干扰，无法有效执行基于内容的个性化，还会导致个人数据在“错误用户”的查询下被错误检索出来。现有工作中，这一存储级、检索时的物理身份约束并未被系统化解决。
- **研究目标**：将生物特征嵌入作为记忆的组成部分，用户查询时先依据生物特征匹配限制候选记忆范围，再执行语义排序，从而实现面向物理请求者的检索级记忆访问控制。

### 二、方法：Bio-Memory 体系结构

核心方法包括以下几个方面：

1. **记忆笔记结构扩展**：在 A-Mem 的原子记忆笔记上，额外新增生物特征嵌入（biometric embedding），使每个记忆块同时携带语义属性和物理所有者信息。  
   形式化表示为一个记忆块 \(m_i\) 包含内容、时间戳、关键词、标签、语境描述、语义嵌入、语义链接和生物特征嵌入等多字段数据结构。

2. **双模态驱动的候选池构建**：  
   Bio-Memory 在推理时将语义检索置于生物匹配之后：
   - 输入当前请求者的实时生物特征探针；
   - 与记忆库中各笔记的生物特征嵌入计算相似度（如余弦相似度），利用与安全界限对应的、经相应生物识别评估集校准的固定验证阈值进行筛选；
   - 返回匹配的候选记忆池；若匹配池为空，则模型将直接在无可用的记忆上下文情况下回答问题。
   
3. **检索排序顺序**：  
   将生物特征匹配得到的候选记忆按时间先后排序，再使用文本编码器计算查询与记忆的语义相似度，执行 Top-K（K 固定为 10）语义检索，并将最终答案交回 LLM 生成。这一顺序的目的是：先约束“谁的记忆可以参与排序”，避免跨用户语义相近的笔记在早期阶段就混入竞争性候选集，使检索在共享场景下仍然安全。

4. **模型与生物识别器选择**：  
   - 语义检索使用基于 MiniLM 的句向量模型（all-MiniLM-L6-v2）；
   - 生成模型与回答后端遵循 A-Mem 评估配置；
   - 人脸实验采用 ArcFace 生物特征模型，掌纹实验采用 CCNet；
   - 生物嵌入在匹配前进行了 L2 归一化与正余弦相似度度量。

5. **低侵入式设计**：  
   该架构仅以“检索层”形式扩展 A-Mem 记忆系统，不重构 A-Mem 的核心笔记构建、图连接或语义排序模块；对既有记忆系统改造相对轻量。

### 三、实验设计

- **测试基准**：  
  - 问答记忆数据集选用 LoCoMo（长期会话记忆基准）作为基础评估集，并对测试拆分取 10% 的子集以控制推理成本；
  - 生物特征侧分为人脸（LFW、CALFW、CPLFW、CFP-FF、CFP-FP、AgeDB-30、VGG2-FP 等 7 个基准）和掌纹（CASIA 多光谱 3 个子集、IITD、MS 多光谱 4 种波段、PolyU、Tongji 等共 10 个协议）。

- **实现 10 用户共享智能体场景**：  
  将 10 个 LoCoMo 对话空间合并为一个只有生物特征分区的单一共享记忆库。每个 LoCoMo 对话样本与生物基准库中的某个身份关联，所有该样本对话记忆共享该身份的生物模板。为准确模拟查询时角色切换，对目标分区而言：
  - “所有者（Owner）”查询使用与储藏模板同一生物身份的样本；
  - “非所有者（Non-owner）”查询则采用同一共享环境中另一生物身份的样本；
  - 除“探针生物嵌入”身份不同外，其余记忆库、问题进行子集、检索配置和生成模型均一致。

- **评测指标和问题类型**：  
  采用 token 级 F1 和 BLEU-1，报告 Multi-Hop、Temporal 和 Single-Hop 这3类问题的平均分数；无外部基线对比，而是侧重 Owner 对比 Non-owner 的成绩差异。

- **实验数量**：  
  7 个人脸基准 + 10 个掌纹协议（含有 2 类模态、3 类问题类型、2 个评估指标和全部数据的 Owner / Non-owner 条件），共覆盖 17 种不同生物数据集；未包含对生物阈值 λ 的敏感性消融、或与 Mem0、MemoryBank 等替代记忆架构的对比实验。

### 五、实验数量与充分性

- **强项**：  
  - 覆盖的模态和数据集组合较广（人脸和掌纹共有 17 种协议设定）；
  - Owner / Non-owner 实验条件一致，控制了变量为探针生物特征身份；
  - 报告了三种不同类型的问题（单跳、多跳、时序），便于推断不同推理机制下的差异。

- **可提升之处**：  
  - 缺少与现有代表性记忆系统（如 Mem0、MemoryBank、PersonaMem-v2 等）的直接定量基线对比；
  - 缺少消融实验（例如去掉生物过滤后仅靠语义的对照、阈值敏感性分析），无法量化每一步骤对最终准确性的相对贡献；
  - 没有在真实多轮共享设备场景下用真实采集的多模态查询进行验证；LoCoMo 样本与生物身份的含绑定属于人为模拟，不能完全模拟实际环境中身份变化、会话切换、噪声传感器等复杂情况；
  - 非所有者（Non-owner）场景本质上只是“无记忆可用”，并没有模拟伪装身份进行恶意攻击（攻击者往往试图让自己的生物特征匹配某一目标身份）等更具对抗性的情形。

总体而言，这个实验方案可以支撑“可区分所有者/非所有者”的直接结论，但在系统性的对照组与对抗安全性验证上仍略显不足。

### 六、主要结论与发现

- **所有者优势稳定**：在所有测试的人脸与掌纹协议中，Owner 的 F1/BLEU-1 成绩远高于 Non-owner，且优势普遍跨越 Single-Hop、Multi-Hop 和 Temporal 三类问题。  
  示例数据：人脸基准 CALFW 的平均差距为F1 27.29% / BLEU-1 21.15%；掌纹 MS_Blue 上的平均差距达 25.75% / 19.22%。

- **非所有者成绩受损显著**：Non-owner 大多数 F1 结果都在 4.49% 到 6.60% 之间，而其所有者的成绩仍维持在约 26.27%~31.32% 的健康区间——说明方法没有简单抑制所有人的记忆，反映出对不匹配用户记忆的“选择性阻断”效果。

- **时序类问题最具区分度**：Temporal 任务中，非所有者的分数极低（部分低于 1%），说明一旦有效过滤掉个人信息流，模型凭借通用性知识无法重建出对应用户的时间线。

- **跨模态可推广**：效果并不绑定于单一生物模态；人脸和掌纹在多个不同协议上都保持方向一致的分离趋势，差异只体现在“边界明显性”上。

- **核心机制定位**：实验认为，方法改善效果主要来自“候选池形成的阶段”，即检索前置身份门控本身，而非后置生成策略的调节。

### 七、优点

- 问题关切务实：紧扣了多用户共享设备中“逻辑身份与物理请求者不一致”的真实痛点。
- 实现轻量：沿用 A-Mem 的结构化笔记和索引流水线，不改变底层 LLM 即可获得身份感知，为实用落地提供了基础。
- 多模态充分性较强：联合了面部与掌纹覆盖面较广的公开标准生物数据集，能验证多形态生物特征与语义记忆相结合的可行性。
- 严格控制变量：Owner 与 Non-owner 只是生物探针不同，记忆库、问题和生成器完全一致，尤其有利于因果归因。
- “检索层加入身份信息”的先后次序表述清晰——先身份过滤再语义选择，理论上能直接规避跨用户噪声进入候选池，优于简单的会话认证/访问控制思路。

### 八、不足与局限

- 缺少更丰富多样的基线系统对比和基准解释，不足以说明 Bio-Memory 必然优于 Mem0、MemoryBank 或纯粹依靠会话隔离的方案。
- 缺少消融与参数敏感性章节（例如：阈值变化、Top-K 大小、嵌入长度、身份共享数对性能的影响），对架构设计的内在驱动因素发掘不够具体。
- 部分测试采用人工绑定对话与样本的生物身份，会导致天然的数据偏差；将生物样本与 LoCoMo 对话身份的映射属于人为模拟，并未引入真实采集的同一设备多用户交互记录。
- 未针对生物识别模型错误率较高或极端伪造身份、多模态共谋注入等对抗安全场景进行压力测试；
- 没有分析生物识别失败（拒绝合法所有者/接受冒充者）所导致的记忆安全边界，也缺少对错误接受率、错误拒绝率与最终 QA 质量之间关系的定量分析。
- 技术上没有讨论生物嵌入的隐私保护机制（模板撤销、可撤销生物特征、安全加密等），也未讨论在设备端进行生物匹配的功耗和延迟约束。
- 文中没有说明各 Owner 组内部是否隐藏有水平差异，如果生物任务难度本身差异很大，则表格中的“平均值和差距”在跨数据集解读时要格外谨慎。
