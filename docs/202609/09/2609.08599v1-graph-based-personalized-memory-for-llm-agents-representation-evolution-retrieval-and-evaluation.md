## 摘要
大型语言模型（LLM）智能体正从单会话工具演变为长期个人助理，必须在任务、情境和交互中适应个体用户。这一转变使记忆成为个性化的核心需求，因为用户偏好、目标、约束、关系及过往经验是逐渐积累的，且往往随时间变化。基于图的个性化记忆通过显式关系、时间上下文和证据链接，为建模此类用户信息提供了一种结构化方式。这种表示不仅能建模智能体对用户的记忆内容，还能刻画记忆之间如何连接、修订和检索，以支持个性化决策。然而，现有工作仍分散于个性化智能体和通用图记忆框架中，难以从整体上理解其设计空间。本综述对LLM智能体的基于图个性化记忆提出了一个生命周期导向的视角。我们围绕记忆表示、记忆演化、记忆检索和记忆评估来组织现有研究，并进一步比较关键设计选择，讨论当前评估实践，以及构建可靠长期个性化智能体所面临的开放挑战。本综述旨在阐明基于图的记忆如何支持自适应、可控且以用户为中心的LLM智能体。

## Abstract
Large Language Model (LLM) agents are evolving from single-session tools toward long-term personal assistants that must adapt to individual users across tasks, contexts, and interactions. This shift makes memory a core requirement for personalization, since user preferences, goals, constraints, relationships, and past experiences are accumulated gradually and often change over time. Graph-based personalized memory provides a structured way to model such user information through explicit relations, temporal context, and evidence links. Such representations can model not only what an agent remembers about a user but also how memories are connected, revised, and retrieved to support personalized decisions. However, existing work remains fragmented across personalized agents and generic graph memory frameworks, making it difficult to understand the design space as a whole. This survey develops a lifecycle-oriented view of graph-based personalized memory for LLM agents. We organize existing studies around memory representation, memory evolution, memory retrieval, and memory evaluation. We further compare key design choices, discuss current evaluation practices, and open challenges in building reliable long-term personalized agents. This survey aims to clarify how graph-based memory can support adaptive, controllable, and user-centric LLM agents.

- **研究背景**：LLM 智能体正从单次会话工具向长期个人助理演变，需在跨任务、跨情境和长期交互中适应个体用户。由于用户偏好、目标、约束、关系和过往经验都会随时间不断积累与变化，记忆成为支持个性化的核心能力。然而 LLM 上下文窗口有限，无法持续容纳全部用户交互历史，因此需要一种持久化的、能跨会话积累与更新的外部记忆机制。

- **整体含义**：该综述为构建可靠、长期、以用户为中心的个性化 LLM 智能体提供了一张"路线图"，将记忆从被动存储提升为可查询、可演化、可追溯的用户操作模型，并指出现有评测体系对记忆图本身的结构质量关注不足，为后续研究指明了关键缺口。

### 二、论文提出的方法论

本文无具体方法公式，而是提出一个**生命周期导向的分类框架（Taxonomy）**，从四个核心环节组织现有研究，并给出关键设计维度：

1. **记忆表示（Representation）**
   - **元素级设计**：
     - 区分四类节点角色：证据节点、事实节点、抽象节点（persona、场景、反思）与领域专属节点。
     - 关系类型包括：时间关系、溯源关系（provenance）、关联关系、领域专属关系。
     - 引入生命周期元数据（时间戳、有效期、失效标记）以区分"当前活跃状态"与"历史证据"。
   - **结构级设计（五种模式）**：
     - *扁平图（Flat）*：无抽象层，如 UMGR、KGT、Mem0ᵍ。
     - *分层图（Hierarchical）*：跨粒度组织证据、事实与高层抽象，如 GAAMA、Bi-Mem、GAM、SGMem，支持溯源但需维护跨层一致性。
     - *超图（Hypergraph）*：用超边保留多元素联合上下文，如 HingeMem、HyperMem。
     - *混合图（Hybrid）*：图与非图基底（如摘要存储、文本检索库）结合，如 H-Mem、LiCoMemory、MemWeaver。
     - *多图（Multiple Disjoint Graphs）*：按用途划分多个图实例，如 DEMENTIA-PLAN 将日常作息图与人生记忆图分离。

2. **记忆演化（Evolution）**——归纳为五个操作：
   - **记忆接纳（Admission）**：判断证据是否进入持久记忆及以何种粒度/类型写入，代表系统：KGT、MemORAI、MemGuard。
   - **记忆整合（Integration）**：将新证据接入已有拓扑，常见方式为追加并链接（append-and-link）或冗余合并，代表系统：LiCoMemory、Mem0ᵍ、HingeMem、GAM（缓冲式接入）。
   - **冲突消解（Conflict Resolution）**：区分三种冲突——时间更替、用户纠正、情境共存（contextual coexistence），避免一味"最新覆盖"，代表系统：AriadneMem、GRAVITY、ZEP。
   - **记忆融合（Consolidation）**：对积累的记忆进行抽象、去重、重构、归档，代表系统：GAM、All-Mem（SPLIT/MERGE/UPDATE 操作）。
   - **记忆移除（Removal）**：分为*遗忘*（降低曝光/分辨率，如 ScrapMem 的光学遗忘）与*删除*（改变可恢复/检索状态，如 Kumiho 的版本化信念修订）。

3. **记忆检索（Retrieval）**——三类机制可组合：
   - **基于相似度的检索**：lexical / keyword / dense vector 产生初始候选或锚点（如 EMG-RAG），但可能返回相关或近重复片段。
   - **基于结构的检索**：通过图拓扑在关系、层级、时间视图间扩展证据，代表：GAM（先主题后事件）、MAGMA（多图多视图）、AsSoMem、xMemory（扩展源段落）。
   - **自适应与 Agentic 检索**：依据查询意图和中间证据控制路径探索、路由与压缩，代表：MRAgent（Cue-Tag-Content 图迭代检索）、PRISM（意图敏感路径选择+证据压缩）、HingeMem（元素路由+深度控制）、APEX-MEM（检索时化解冲突）。

4. **记忆评估（Evaluation）**
   - 总结五类指标：答案质量、证据检索、用户状态建模、演化与结构、效率。
   - 整理 14 个代表性 benchmark（详见下节）并标注其考察维度。

### 六、论文的主要结论与发现

- 图不是银弹：图拓扑本身不必然带来个性化增益，只有表示、演化与检索三者协同有效时，图记忆才真正发挥作用。**"将记忆存入图 ≠ 完成个性化建模"**是全文的核心判断。
- 个性化记忆的维度是多重的：语义、时间、关系、经历、情感五大维度相互交织，单一扁平记录难以捕获其结构。
- 演化操作需区分精细类型：冲突消解应区分时间更替、用户纠正与情境共存；移除操作应区分遗忘与删除；高阶抽象若缺少溯源与依赖传播机制，容易导致用户模型内部不一致。
- 检索并非单一策略：相似性检索、结构扩展与自适应/agentic 控制应组合为流水线，结构信息只有在能表达有意义关系、且演化维持其有效性时才有价值。
- 评测严重偏向"下游答案正确性"，**对记忆图本身的结构质量（如跨层一致性、溯源完整性、状态有效性）缺乏直接度量**，这是当前最大的评估缺口。
- 未来方向包括：规模化终生记忆、多模态记忆图、以及支持因果/反事实推理的用户建模。
