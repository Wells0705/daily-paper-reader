## 摘要
长程大语言模型（LLM）智能体依赖外部记忆系统在扩展交互中保留用户偏好和任务知识。传统的检索机制优化语义兼容性而非下游效用，经常将过时、误导或冲突的证据引入活动上下文。我们提出MeClear，一种任务条件化的记忆清除框架，通过合作归因识别具有负下游效用的记忆，并选择性地将其从智能体执行中抑制。MeClear将留一法筛选与采样合作Shapley归因相结合，在交互证据间分配效用，有效解决了单一移除评估无法处理的冗余冲突掩盖问题。利用归因排名，MeClear在嵌套过滤上执行查询范围的最小清除策略，验证清除上下文上的任务恢复，而不会永久改变持久记忆库。跨十个长对话记忆池的综合实验评估表明，MeClear实现了85.9%的目标召回率和82.3%的总体任务恢复率，比留一法（LOO）基线提高了25.5个百分点。

## Abstract
Long horizon Large Language Model (LLM) agents rely on external memory systems to preserve user preferences and task knowledge across extended interactions. Conventional retrieval mechanisms optimize semantic compatibility rather than downstream utility, frequently introducing outdated, misleading, or conflicting evidence into the active context. We present MeClear, a task conditioned memory clearance framework that identifies memories featuring negative downstream utility through cooperative attribution and selectively suppresses them from agent execution. MeClear combines Leave One Out screening with sampled cooperative Shapley attribution to distribute utility across interacting evidence, effectively resolving redundant conflict masking where single removal evaluations fail. Utilizing attribution rankings, MeClear executes a query scoped minimal clearance strategy over a nested filtration, verifying task recovery on the cleared context without permanently altering the persistent memory bank. Comprehensive experimental evaluations across ten long dialogue memory pools demonstrate that MeClear achieves a target recall of 85.9% and an overall task recovery rate of 82.3%, representing a 25.5 percentage point improvement over Leave One Out (LOO) baselines.

## 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：长程 LLM 智能体依赖外部记忆系统在长时间交互中保存用户偏好、观察和任务状态。传统记忆管理系统主要靠语义相关性检索记忆，但“语义相似”并不等于“下游任务有用”。过时、冗余、误导或相互冲突的记忆即使被检索出来，也可能显著降低智能体的执行正确性。
- **核心问题**：如何识别并处理那些“在语义上相关但在当前任务下具有负面效用”的记忆？更关键的是，多条记忆之间可能存在复杂交互（冗余、互相掩盖、联合有害），单条记忆的移除评估（Leave-One-Out，LOO）无法发现这些由多记忆协同引发的危害。
- **关键挑战**：
  - **冗余有害盲区**：两条可替代的有害记忆共享同一惩罚项时，删除任何一条都不会改变输出，导致LOO效应为零，但每条对失败都有贡献。
  - **联合有害**：两条记忆单独无害，组合时才引发错误。
  - **记忆效用是查询条件化的**：一条记忆对当前查询有害，但可能对未来查询有用，因此不能直接永久删除数据库记录。
- **整体含义**：需要一种“任务条件化、可逆、最小化”的记忆上下文清除机制，在推理时动态抑制有害记忆，而不是修改持久记忆库。

## 2. 方法论：核心思想、关键技术细节、公式与算法流程

### 2.1 核心思想

MeClear 将“记忆集合 + 当前查询 + 任务正确性函数”建模为一个**合作博弈**：
- 每条记忆是玩家；
- 任务价值函数 \(v_t(S)\) 衡量使用记忆子集 \(S\) 时回答查询的正确性期望；
- 用 **Shapley值** 来分配每条记忆对任务效用的平均边际贡献；
- 贡献为负且低于容差阈值的记忆被标记为“有害”，随后按有害程度排序并构造**嵌套清除候选**，最终选择一个已验证能恢复任务且删除记忆最少的最小候选集，仅对当前查询生效。

### 2.2 四个阶段

1. **自适应任务条件上下文检索**：沿用现有检索器得到固定上下文 \(M_t\)（大小为K），此后冻结该上下文，所有反事实评估均在 \(M_t\) 的子集上进行，不重跑检索。
2. **局部反事实筛选**：对每条记忆计算LOO效应 \(\hat d_{t,i} = \hat v_t(M_t) - \hat v_t(M_t\setminus\{m_i\})\)。LOO只作为局部诊断信号，不作为最终有害性判据。
3. **反事实合作归因**：采用排列形式的Shapley值估计。随机采样L个排列，计算每条记忆的平均边际贡献：
   \[
   \hat\psi_{t,i}^{(L)} = \frac{1}{L}\sum_{\ell=1}^{L}[\hat v_t(P_i(\pi^{(\ell)})\cup\{m_i\}) - \hat v_t(P_i(\pi^{(\ell)}))]
   \]
   - 估计是无偏的，且满足 Hoeffding 集中界和联合界。
   - 构造操作有害集合：\(\hat H_t = \{m_i \mid \hat\psi_{t,i}^{(L)} < -\tau\}\)。
   - 另外还计算两两非加性交互得分用于结构诊断，但不参与清除决策。
4. **验证的查询范围清除**：
   - 将 \(\hat H_t\) 中的记忆按贡献从小到大排序，形成嵌套清除候选 \(C_{t,j} = \{\) 前j个最有害记忆\(\}\)。
   - 对每个候选计算经验增益 \(\hat g_t(j)=\hat v_t(M_t\setminus C_{t,j})-\hat v_t(M_t)\)。
   - 用任务恢复谓词 \(\nu_t\) 判断清除后的上下文是否能正确回答查询。
   - 可接受指标 \(J_t = \{0\} \cup \{j \mid \hat g_t(j)>0,\ \nu_t(M_t\setminus C_{t,j})=1\}\)。
   - 选择最大增益中清除数量最小的指标 \( \hat j_t = \min \arg\max_{j\in J_t} \hat g_t(j)\)。
   - 最终上下文为 \( \hat M_t = M_t \setminus C_{t,\hat j_t}\)，持久记忆库保持不变。

### 2.3 关键定理与保证

- **定理1（冗余有害盲区）**：在两条可替代有害记忆模型下，LOO效应为零，但Shapley贡献各为 \(-\Delta_t/2\)；推广到r条冗余记忆时，LOO均零，Shapley各为 \(-\Delta_t/r\)。
- **命题1（有限样本估计）**：采样排列估计无偏，且满足 \( \Pr(\max_i |\hat\psi_i^{(L)} - e\psi_i| \ge \epsilon) \le 2K\exp(-L\epsilon^2/2)\)；给出充分采样条件。
- **定理2（查询范围消除保证）**：在嵌套候选族内，选择结果保证经验值不下降；若选择正索引，则满足恢复谓词；且在达到最大增益的可接受候选中具有最小删除数量。

## 7. 优点

- **问题建模清晰**：将记忆评估正式化为合作博弈，用Shapley值构建理论上可解释的记忆效用分配，并证明LOO的冗余盲区。
- **方法层面**：
  - 将LOO与采样Shapley结合，兼顾局部可诊断性与全局交互性；
  - 采用查询范围的可逆清除，不修改持久记忆库，避免永久编辑带来的跨任务风险；
  - 引入验证机制，明确任务恢复谓词，保证清除结果不劣于原上下文；
  - 使用嵌套清除候选和极小化干预原则，避免人为权重超参数，控制计算开销（L=16即可）。
- **实验设计**：结构化构造三类故障并严格因果验证（单条/联合行为验证），分析各方法在不同故障机制下的差异，配对统计检验提供了较可信的结论。
- **理论分析完整**：提供了冗余盲区定理、有限样本估计集中界、清除保证定理，使方法更有理论依据。
