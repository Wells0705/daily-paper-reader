## 摘要
具有强大能力的开放权重小型语言模型（SLM）的激增，使先进网络安全能力的获取更加普及，同时也在本地部署时能够绕过专有API护栏，从而带来不断升级的风险。然而，作为自主智能体部署的SLM，往往难以处理网络安全夺旗赛（CTF）挑战等长时程、探索性任务，原因在于上下文膨胀以及累积工具调用输出所导致的认知退化。为了理解并缓解这一网络安全威胁，我们提出上下文分段，这是一种两级智能体框架，可将复杂的漏洞利用任务分解为可管理且上下文隔离的子问题。我们在picoCTF数据集上使用内存受限的gemma-4模型进行评估，结果表明，对于E4B模型，我们的策略可作为一种智能搜索，相比暴力重试以更优的token效率取得有竞争力的奖励，并成功解决了标准智能体执行无法完成的18.52%的任务。代码见 https://github.com/9xeb/context-segmentation。

## Abstract
The proliferation of highly capable open-weight Small Language Models (SLMs) democratizes access to advanced cybersecurity capabilities, posing a escalating risk as these models can bypass proprietary API guardrails when deployed locally. However, SLMs deployed as autonomous agents often struggle with long-horizon, exploratory tasks like cybersecurity Capture The Flag (CTF) challenges due to context bloat and cognitive degradation from accumulated tool-call outputs. To understand and mitigate this cybersecurity threat, we introduce context segmentation, a two-level agentic framework that divides complex exploitation tasks into manageable, contextually isolated sub-problems. Evaluating on the picoCTF dataset using memory-constrained gemma-4 models, we demonstrate that for the E4B model, our strategy acts as an intelligent search, achieving competitive rewards with superior token efficiency compared to brute-force retries, and successfully solving 18.52% of tasks that standard agentic execution fails to complete. Code is available at https://github.com/9xeb/context-segmentation.

## 1. 核心问题与整体含义

- **研究动机**：开放权重的小型语言模型（SLM）能力持续增强，本地部署可绕过专有 API 的安全护栏，使资源有限的攻击者也可能自动化执行复杂网络攻击，形成扩散中的安全威胁。

- **整体含义**：论文试图在严格硬件受限的威胁模型下，评估本地可部署 SLM 的真实攻击潜力，并提出一种提示层面的“分而治之”框架，以提升其在网络安全任务中的长程执行能力，同时揭示这种能力提升带来的安全风险。

## 2. 方法论

- **核心思想**：提出 **上下文分割（context segmentation）**，将复杂漏洞利用任务拆分为多个上下文隔离的子问题，分离高层战略推理与低层战术执行，避免冗长工具输出污染长期规划。
- **两级智能体架构**：
  - **Explorer（探索者）**：主智能体，负责维护高层摘要，基于历史尝试报告生成新策略，并决定继续尝试还是停止。
  - **Worker（执行者）**：由 Explorer 通过工具调用启动的次级智能体，在空白上下文中执行单个策略，直接与 bash CLI 等环境交互。
- **关键工具与流程**：
  - `run_strategy(strategy)`：Explorer 以自然语言提出策略，该工具启动一个全新的 Worker 智能体循环；Worker 执行后生成行动摘要和停止原因，作为工具输出返回 Explorer。
  - `give_up()`：Explorer 和 Worker 均可调用，用于在穷尽可行方案后终止并说明失败原因。
  - **Plain 基线**：单一 Worker 智能体循环，直接以问题描述为提示，与环境顺序交互。
  - **Plain+Explorer**：先运行 Plain；若 Worker 放弃，则回退到 Explorer 框架继续尝试。任务成功标准为提交正确 flag，失败为 Explorer 放弃。
- **伪代码逻辑**：
  - Worker 工具集包含环境工具和 `give_up`。
  - Explorer 工具集包含 `run_strategy` 和 `give_up`。
  - Explorer 主循环调用 `run_strategy` 时，动态生成新的 Worker 实例，Worker 在干净上下文中执行策略，最后返回摘要。

- **边角案例恢复能力**：

- **核心发现**：
  - 上下文分割能有效恢复复杂边角任务，但需要底层模型具备足够基础能力。
  - 该方法降低了硬件受限攻击者自动化网络攻击的门槛，凸显本地开放权重 SLM 的安全威胁。
  - SLM 的智能体潜力仍受传统手工提示工程制约，上下文分割可视为一种初步的自动提示扩展。
