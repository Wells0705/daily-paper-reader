## 摘要
设计有效的记忆机制对于推进LLM驱动的多智能体系统（MAS）至关重要，有助于智能体共同学习并随时间推移表现更好。尽管近期工作已经带来了强大的合作能力，但大多数方法仍使用扁平、无结构的记忆，这类记忆容易被噪声填充，并抹去智能体之间的差异。为解决这一问题，我们引入集体-个体记忆协同的概念，并提出CoMem，一种统一私有经验与共享知识以支持多智能体学习的架构。CoMem具有以下特点：（i）私有经验沉淀，让每个智能体随时间保留并更新自身有用的记忆；（ii）集体智慧策展，仅精心选择被广泛验证的想法在智能体之间共享；（iii）并行双流检索，使智能体既能从自身记忆中提取信息，也能利用群体智慧，并通过聚类来确保多样性。在ALFWorld和PDDL基准上的实验表明，CoMem取得了强大的整体性能，并能稳健地避免记忆污染。

## Abstract
Designing effective memory mechanisms is crucial for advancing LLM-driven Multi-Agent Systems (MAS), helping agents learn together and perform better over time. While recent work has led to strong cooperation skills, most methods still use flat, unstructured memories, which easily get filled with noise and erase differences between agents. To address this, we introduce the concept of collective-individual memory synergy and propose CoMem, an architecture that unifies both private experience and shared knowledge for multi-agent learning. CoMem features:(i) Private Experience Sedimentation, which lets each agent keep and update its own useful memories over time;(ii) Collective Wisdom Curation, which carefully selects only widely proven ideas to be shared among agents;(iii)Parallel Dual-Stream Retrieval, which allows agents to draw both from their own memory and the group's wisdom, using clustering to ensure diversity.Experiments on ALFWorld and PDDL benchmarks show that CoMem achieves strong overall performance and robustly avoids memory pollution.

## 1. 核心问题与研究动机

- **背景**：LLM 驱动的多智能体系统（MAS）已具备较强的协作能力，但要在动态环境中实现持续适应与长期群体智能，记忆机制至关重要。
- **核心痛点**：现有 MAS 记忆方法大多采用**扁平、非结构化**的共享记忆，导致"记忆污染"（Memory Pollution），具体表现为两种相互强化的退化过程：
  - **噪声累积（Noise Accumulation）**：未经证实的试错行为和低质量决策不断写入共享库，降低整体可靠性。
  - **行为同质化（Behavioral Homogenization）**：跨智能体的盲目交叉写入使角色专属性认知轨迹被"平均化"，个体差异逐渐消失（论文形式化为 $\lim_{t\to\infty} H(\pi_{a_i} \| \pi_{a_j}) = 0$）。
- **整体含义**：论文主张可持续的集体智能需要**个体学习纯度**与**群体知识筛选**之间的平衡，仿照人类社会"个体提案 → 集体筛选 → 共识结晶"的知识演化过程，构建结构化的群体记忆生态。

## 2. 方法论：CoMem 架构

### 2.1 核心思想

- 将记忆空间解耦为两个逻辑与物理隔离的层级：
  - **私有层（Private Layer）**：每个智能体独占的私有记忆 $\mathcal{M}^{(i)}_{\text{priv}}$，防止跨智能体污染。
  - **集体池（Collective Pool）**：共享仓库 $\mathcal{M}_{\text{coll}}$，仅接纳通过严格经验验证的洞见。
- 每条记忆条目以结构化元组存储：$m = \langle \text{doc\_content}, \text{metadata} \rangle$，其中 metadata = {agent_name, S, $n_{use}$, $n_{succ}$, $\iota_{prom}$}，分别表示归属智能体、效用分、调用次数、成功次数与晋升状态。

### 2.2 三大关键机制

**(i) 私有经验沉淀（Private Experience Sedimentation）**

- 每个 episode 结束后，智能体 $a_i$ 用 LLM 蒸馏器将完整执行轨迹 $\tau^k_i$ 转化为少量简洁可操作的文本洞见，存入私有记忆。
- 采用**滚动剪枝**：每个条目维护连续未命中计数器 $K_{miss}(m)$。若被检索使用则归零，否则加一；超过阈值 $K_{max}$ 即永久移除，保持私有记忆紧凑且聚焦。

**(ii) 集体智慧策展（Collective Wisdom Curation）**

- **经验晋升门控**：私有条目 $m$ 晋升需同时满足：
  $$\iota_{prom} = \mathbb{I}\left[ \left( N_{use}(m) \geq N_{min} \right) \wedge \left( \bar{R}_m \geq \bar{R} \right) \right]$$
  即足够的使用曝光次数，且其使用期间的平均任务得分不低于环境全局移动基线。
- 晋升后条目被复制到集体池并从私有库移除，避免冗余。
- **混合效用持续质控**：集体条目每 episode 计算综合效用
  $$U_t(m) = w \cdot R_{norm} + (1-w) \cdot \frac{1}{|A_m|} \sum_{a \in A_m} \frac{\text{LLM}_a(m)}{L_{max}}$$
  融合客观奖励与离线 LLM 主观评分；长期效用按指数移动平均更新：
  $$S_{t+1}(m) = (1-\alpha) S_t(m) + \alpha \cdot (S_{max} \cdot U_t(m))$$
  持续低于自适应阈值的条目被清除。

**(iii) 并行双流检索（Parallel Dual-Stream Retrieval）**

- 任务查询到来时，每个智能体**并行**从私有与集体两个隔离仓库检索：
  - **私有流**：基于语义嵌入相似度取 top-ranked 私有条目，注入提示词提供个性化战术指导。
  - **集体流 + 多样性过滤**：对集体候选条目使用**在线层次聚类**，按语义距离分组，每组选最具代表性的条目，构建简洁且多样的共识上下文，减少冗余 token 消耗。
