## 摘要
大型语言模型（LLM）代理需要对用户或组织所说和存储的一切拥有持久、忠实的记忆，然而大多数记忆系统固守于单一的组织结构（事实存储、向量索引或知识图谱），并继承了其盲点。我们提出了 Agent Zero Memory，一个溯源性感知的长期记忆系统，该系统将用户的对话、文件和连接来源提炼为三个并行的记忆系统，每个系统捕捉同一历史的不同方面：一个情景记忆事件时间线，使时间和变化成为一等公民；一个关联实体-事件知识图谱，连接跨会话的人物和项目；以及一个语义化、精选、引用锁定的分层文档记忆（HDM），用于持久事实。一次检索轮运行一个意图门控（因此自包含的轮次不会增加延迟）、一个源路由器，以及三个并发的代理搜索，每个系统一个，每个都是工具使用循环，在代理控制的过滤器下进行混合（嵌入+词汇）搜索；它们基于证据的、带引用的答案被整合为一个具有单一置信度的答案。我们形式化了阅读纪律：每个学习到的条目都是一个带有来源、时间戳和证据指针的溯源性条目，每个答案都在引用锁定下被读取，因此它只能引用读者实际打开过的证据；捏造在结构上被排除，系统宁可弃权也不猜测。在两个公开基准测试中，该系统达到了新的最先进水平：在 LongMemEval 上为 95.60%，在 LoCoMo 上为 93.60%，比之前最强的系统分别提高了 +0.73 和 +1.10 个百分点。一项涉及八种主干 LLM 的受控研究刻画了准确性-成本-延迟的边界：准确性仅变化 3.4 个百分点，而每次查询成本变化约 30 倍，在每次查询成本降低高达 20 倍的情况下实现接近最先进的质量，这是记忆驱动而非模型驱动的质量特征。

## Abstract
Large language model (LLM) agents need durable, faithful memory of everything a user or organization has said and stored, yet most memory systems commit to a single organizing structure (a fact store, a vector index, or a knowledge graph) and inherit its blind spots. We present Agent Zero Memory, a provenance-aware long-term memory system that distils a user's conversations, files, and connected sources into three parallel memory systems, each capturing a different facet of the same history: an episodic Memory Events timeline that makes when and what changed first-class, an associative entity-event knowledge graph that links people and projects across sessions, and a semantic, curated, citation-locked Hierarchical Documentary Memory (HDM) of durable facts. A retrieval turn runs an intent gate (so self-contained turns add no latency), a source router, and three concurrent agentic searches, one per system, each a tool-using loop over hybrid (embedding + lexical) search under agent-controlled filters; their grounded, cited answers are integrated into one answer with a single confidence. We formalize the reading discipline: every learned item is a provenanced item carrying its origin, timestamp, and evidence pointer, and every answer is read under a citation lock, so it may cite only evidence its reader actually opened; fabrication is structurally excluded and the system abstains rather than guesses. On two public benchmarks the system sets a new state of the art: 95.60% on LongMemEval and 93.60% on LoCoMo, improving over the strongest prior systems by +0.73 and +1.10 points. A controlled study across eight backbone LLMs characterizes the accuracy-cost-latency frontier: accuracy varies by only 3.4 points while per-query cost varies by ~30x, with near-state-of-the-art quality at up to 20x lower cost per query, the signature of memory-driven, rather than model-driven, quality.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：现有 LLM 代理记忆系统大多采用单一组织结构——事实存储（fact store）、向量索引（vector index）或知识图谱（knowledge graph）——每种结构都只擅长特定类型的问题，而对其他类型存在结构性盲点。更重要的是，大多数系统只记录"说了什么"，却很少建模"为什么相信"以及"随着证据积累，置信度应如何变化"。当一个事实被用户更正时，多数系统要么静默覆写，要么堆积矛盾，导致无法区分一条事实与其被修正前的旧版本。
- **现实挑战**：个人或组织所掌握的知识往往散落在数月对话、文件、邮件、维基、代码托管等异构来源中。例如回答"我们关于发布日期的决定是什么？这个决定什么时候变过？"需要同时做到：回忆数月前只说一次的事实、知道后续会话中该事实被取代、并引用每一版本被说出的具体对话轮次。没有任何单一检索机制能同时完成这三件事。
- **论文立场**：长期记忆应被视作维护一个持久、可查询、诚实的"已知知识模型"——不仅记录断言本身，还记录其来源、支撑证据和经过校准的置信度；并且没有单一表示能服务所有问题类型。Agent Zero Memory 因此采用**三套并行记忆系统 + 溯源感知阅读纪律**的设计。

## 2. 论文提出的方法论

### 2.1 总体架构
系统维护三个并行存储 \( M = (T, G_E, D) \)：
- **Memory Events（情景事件时间线）**：将对话和文件提炼为带时间戳的事件，构成跨来源合并的时间线，使"何时发生、什么改变了"成为一等公民，专门支撑时间推理和知识更新类问题。
- **Entity–Event Knowledge Graph（实体-事件知识图谱）**：通过 agentic"连接"阶段，将人物、团队、项目与相关事件链接为可导航的图，用于跨会话的多跳推理。
- **Hierarchical Documentary Memory（HDM，分层文档记忆）**：精选的、带引用锁的持久事实知识库，分六类（profile、preferences、entities、milestones、cases、patterns），每条目有 L0/L1/L2 三个详细级别，且由用户笔记经确定性映射构建（而非 LLM 抽取），避免漂移和捏造。

### 2.2 构建流程（Memory Build）
四阶段后台流水线：
1. **预处理与分类**：归一化文本并标记为聊天/文件/代理会话；
2. **索引**：同时构建 embedding 索引（pgvector，3072 维，余弦相似度）和词法索引（BM25 + 模糊匹配）；
3. **抽取**：LLM 分析生成事件时间线和 HDM；
4. **连接**：agentic 过程构建本体图谱。

整个构建在后台一次性完成，不占用对话热路径。

### 2.3 检索流程（Memory Injection）
核心算法（Algorithm 1）：
1. **意图门控**（Intent Gate）：小型快速分类器判断当前轮是否需要记忆，自包含轮次直接通过，零延迟；
2. **源路由器**（Source Router）：限制检索到最可能包含相关证据的来源桶；
3. **三路并发 agentic 搜索**：每个记忆系统各一个搜索，循环执行——混合（dense + lexical）检索、代理控制过滤器（时间窗口、标签、来源、说话者）、按需打开原始证据；
4. **整合**：合并三个部分答案的引用集，输出带单一置信度的答案。

### 2.4 形式化定义（阅读纪律）
- **Definition 1（溯源性条目）**：条目 \( x \) 携带 \( \pi(x) = \langle o(x), t(x), ev(x) \rangle \)，其中 \( o(x) \) 是来源类型，\( t(x) \) 是不可变创建时间戳，\( ev(x) \) 是指向原始证据的指针。
- **Definition 2（引用锁定答案）**：答案 \( (a, C, \kappa) \) 中，引用集 \( C \) 必须是读者实际打开过的条目子集，且每个原子声明都由 C 中条目支持；无法构建这样的 C 时必须弃权（\( a = \bot \)）。这一纪律通过构造强制——读者接口不提供引用未打开材料的通道，因此从结构上排除捏造。

### 2.5 三条设计公理
- **(P1) 分层**：原始内容与蒸馏记忆隔离，精选事实与可修正的推断经验隔离，防止错误推断污染事实；
- **(P2) 溯源与校准置信度**：每个条目都带溯源和置信度，只在引用锁下读取，宁可弃权也不捏造；
- **(P3) 基于证据的结构化检索**：通过检索感知数据，利用结构导航而非无约束生成。

## 6. 论文的主要结论与发现

- **SOTA 结果**：LongMemEval 达 **95.60%**（超 Mastra 0.73 点），LoCoMo 达 **93.60%**（超 Mem0 1.10 点）；
- **记忆驱动而非模型驱动**：8 个主干模型准确率波动仅 3.4 点（92.20%–95.60%），而每查询成本波动约 30 倍，表明质量主要由记忆结构和溯源决定，而非模型参数知识；
- **成本效率**：deepseek-v4-pro 以每查询 $0.001768 达到 92.20%，约为最佳配置（gpt-5.5，$0.034788）1/20 成本，仅损失 3.4 点；glm5.2fast 是最快的（中位 6.16 秒，93.00%）；
- **混合检索互补性**：完整混合通道（95.20%）优于单通道——纯 embedding 损失 1.2 点，纯词法损失 1.8 点，grep 损失 1.6 点；但所有受限变体仍超最强外部基线，说明结构化和溯源是主要质量来源，混合检索贡献最后一段边际；
- **可审计性**：每个答案都带可追溯的源引用，支持企业部署的审计需求。

## 7. 优点

1. **多结构并行设计**：时间线、图谱、文档记忆三类结构互补，针对不同问题类型各司其职，突破单一结构的盲点；
2. **溯源与引用锁是形式化保证而非软性约束**：从构造上排除捏造，无法给出证据时强制弃权，这在 LLM 记忆系统中是罕见且严格的设计；
3. **检索成本受意图门控和源路由控制**：自包含轮次零延迟，每次只触及相关记忆子系统，读成本随查询而非随历史增长；
4. **非破坏性更新**：事件追加而非覆写，修正与旧版本可区分，满足知识更新问题的核心需求；
5. **构建与推理分离**：Memory Build 离线后台运行，原始资料始终被索引，提取误判不会造成不可恢复的信息丢失；
6. **骨架无关性好**：质量不绑定特定模型，部署者可按成本/延迟/准确率策略混用不同主干，甚至在同一部署内不经重建切换；
7. **共享组织记忆**：设计支持多代理共享，单个代理学到的经验可服务所有代理。

## 8. 不足与局限

1. **对比公平性受限**：竞争系统数字是各自公开的最佳值，评价协议不统一（judge 模型、prompt、检索预算都可能不同），跨系统对比应视为"定位"而非严格对照；唯一严格受控的是主干研究内部比较；
2. **成本数据时效性**：成本基于评估时的公开列表价格，会随供应商调价而漂移；论文只报告 token 数以便重新计价，但原始结论仍受价格波动影响；
3. **缺少组件级消融**：未量化三个记忆系统各自和意图门控的独立贡献，仅做了检索通道消融，机制的因果归因不够严谨；
4. **置信度未校准**：论文声称每条答案附有置信度 \( \kappa \)，但承认这些置信度尚未经频率学校准——声明 0.9 的置信度并不保证事实上 90% 正确；
5. **冲突仲裁缺失**：当多个有效版本的事实并存于不同来源时，系统尚未有原则性的选择机制（包括何时应询问用户）；
6. **遗忘机制未实现**：过时经验记忆的优雅衰减（降权而非删除、墓碑保持可审计性）只是未来方向，当前系统可能随历史积累出现信息过载；
7. **未来工作的开放性**：Beyond 单一检索通道消融，三记忆和意图门控各自边际贡献、置信度校准、冲突仲裁、遗忘都是规划中的未完成工作。
