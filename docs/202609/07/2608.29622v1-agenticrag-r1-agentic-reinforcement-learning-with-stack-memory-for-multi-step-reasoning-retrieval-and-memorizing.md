## 摘要
检索增强生成（RAG）提升了大语言模型（LLM）的事实性，然而现有的RAG系统往往难以应对需要自适应检索和持续修正中间上下文的复杂多步推理。近期基于强化学习（RL）的智能体RAG方法在一定程度上缓解了该问题，但通常依赖粗粒度的动作空间和轨迹级奖励，导致奖励分配薄弱，并偏向短期、刻板的推理模式。为此，我们提出AgenticRag-R1，一种通过记忆栈和细粒度动作空间深度融合推理、检索与记忆的强化学习框架，并辅以层次化的动作感知奖励和信息感知的轨迹拒绝策略，以实现有效的长程学习。在涵盖多种骨干模型规模的多跳、开放域和智能体推理基准上的实验表明，AgenticRag-R1始终优于强基线。此外，AgenticRag-R1学习了更稳健、可解释且具有记忆感知的推理行为，凸显了细粒度动作建模和信息感知优化对长程推理的作用。我们的代码匿名公开于 https://github.com/jiangxinke/Harness-RL/tree/AgenticRAG-R1-Whitebox。

## Abstract
Retrieval-Augmented Generation (RAG) improves the factuality of large language models (LLMs), yet existing RAG systems often struggle with complex, multi-step reasoning that requires adaptive retrieval and continuous revision of intermediate contexts. Recent reinforcement learning (RL)-based agentic RAG methods partially alleviate this issue, but typically rely on coarse-grained action spaces and trajectory-level rewards, resulting in weak reward assignment and a bias toward short-horizon, stereotyped reasoning template. To address, we propose AgenticRag-R1, a RL framework that deeply integrates reasoning, retrieval, and memory via a memory stack and fine-grained action space, supported by hierarchical action-aware rewards and an information-aware trajectory rejection strategy to enable effective long-horizon learning. Experiments across a diverse set of multi-hop, open-domain, and agentic reasoning benchmarks, spanning multiple backbone model sizes, demonstrate that AgenticRag-R1 consistently outperforms strong baselines. Moreover, AgenticRag-R1 learns more robust, interpretable, and memory-aware reasoning behaviors, highlighting the effect of fine-grained action modeling and information-aware optimization for long-horizon reasoning. Our code is anonymous available at https://github.com/jiangxinke/Harness-RL/tree/AgenticRAG-R1-Whitebox.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **背景**：大规模语言模型（LLM）在自然语言处理任务中表现优异，但存在事实错误、知识过时和领域专长不足的问题。检索增强生成（RAG）通过引入外部知识来提升准确性和适应性，但面对真实世界复杂的多步决策任务时，模型需要将问题分解为多个相互依赖的步骤，动态决定何时检索、检索什么，并将检索信息持续融入不断演进的内部状态中。
- **现有方法的两大缺陷**：
  - **动作空间粗糙**：多数基于RL的智能体RAG方法将整个推理和搜索过程压缩为单一的`<think>`和`<search>`动作模板，缺少细粒度的记忆操作（如修正、回溯、压缩），中间噪声会被写入记忆后不可逆地传播放大，导致错误累积。
  - **奖励信号薄弱**：仅根据最终答案正确性分配奖励（轨迹级奖励），忽略了轨迹各中间动作的贡献，难以对长程多步推理提供有效监督。
- **后果**：模型偏向短视的、模板化的、可轻易复现的推理模式，而非探索复杂的长程推理策略。
- **核心研究问题**：如何实现推理、检索与记忆的深度集成，设计细粒度记忆感知的动作空间和层级化奖励机制，并通过信息感知的轨迹筛选策略优化RL训练数据分布，从而在长程推理场景中实现稳定、泛化良好的学习。

## 2. 论文提出的方法论（核心思想与技术细节）

### 2.1 总体框架
AgenticRag-R1由两大核心组件构成：
- **动作中心训练范式**：支持多轮、多动作的推演（rollout），涵盖推理、检索和记忆操作；引入层级化、动作感知的奖励建模，实现细粒度token级奖励分配。
- **信息增益感知的动态推演选择策略**：在训练中过滤低信息轨迹，优先选择高奖励和具有行为多样性的困难长程样本，增强探索和数据效率。

### 2.2 记忆栈与细粒度动作空间
采用**后进先出（LIFO）栈结构**作为模型内部状态表示，每个栈元素对应一个离散的、语义完整的推理单元。支持的操作/动作为：

| 动作 | 栈操作 | 功能 |
|------|--------|------|
| `<Plan>` | push | 生成子目标、任务分解或高级策略 |
| `<Think>` | push | 记录内部逻辑推理和决策 |
| `<Search>` | push | 构造查询参数并触发外部检索 |
| `<Backtrack>` | pop + push | 检测到不一致/错误时，移除栈顶元素，恢复先前有效推理状态，进行替代探索 |
| `<Summary>` | pop + push | 将近期记忆条目压缩为简洁表示并压回栈，实现上下文管理和信息保存 |
| `<Conclusion>` | push | 标记当前状态为候选最终答案，结束推理 |

### 2.3 层级化奖励建模
- **结果奖励（r_out）**：基于最终答案与标准答案的精确匹配（EM）或F1分数计算，并均匀分配到全部有效生成token。
- **过程奖励（r_proc）**：仅在动作token上施加，细粒度监督中间决策，分为三类分量：
  1. **动作格式奖励（r_fmt）**：检查动作的语法正确性（如是否具有有效的`<ACTION>`标签），CONCLUSION动作权重1.0，其他有效动作0.5。
  2. **搜索奖励（r_rag）**：用通用奖励模型（GRM）评估检索到的内容与查询及当前任务上下文的相关性。
  3. **记忆奖励（r_mem）**：用GRM评估记忆操作（Backtrack/Summary）在给定当前推理上下文和记忆栈状态下是否合理、有益。
- **奖励预算与比例归一化**：为避免奖励黑客（通过过度调用动作来获益），设定每条轨迹的过程奖励预算。当累计过程奖励超过预算时，按比例缩放，防止冗余或过量动作调用。

### 2.4 token级奖励公式
- 对第k条轨迹的第i个token，其奖励为：

  `r_i = (1 − I_mask,i) · r_out + I_act,i · r_proc,i`

  其中 `I_mask` 表示该token是否从策略优化中被屏蔽（如检索到的观测文本）， `I_act` 表示该token是否属于动作调用token。

### 2.5 信息感知轨迹拒绝（Information-Aware Trajectory Rejection）
- **批级rollout集成**：对每个mini-batch中的每个输入生成K条随机rollout，构成统一的候选集。
- **输入级信息量度量**：对同一输入的K条rollout，计算奖励均值μ和方差σ²，以方差衡量该输入下不同推理/检索路径的多样性。
- **信息感知打分**：为每条rollout定义UCB风格分数：

  `r̃ = σ² · r + μ`

  该分数将输入级方差（信息多样性）与rollout级奖励（轨迹质量）相乘耦合：当存在有意义的多样性时，选择性放大高奖励轨迹；同时通过加性均值项μ稳定基线，防止过度拒绝。
- **全局选择**：在批级空间上对所有rollout按分数排序，仅保留前p比例；未选中的轨迹被丢弃，不参与策略优化，从而优先训练既局部高质量又全局信息量大的轨迹。

## 6. 论文的主要结论与发现

- **性能领先**：AgenticRag-R1在7个基准、3种骨干规模上普遍优于最强基线。示例：3B骨干下2Wiki提升+3.02%，HotpotQA提升+6.76%；7B下Bamboogle提升+7.17%；在TriviaQA上1.5B提升+3.24%。
- **记忆动作与轨迹拒绝均有实质性贡献**：去除记忆动作导致2Wiki从32.92%下降至27.54%、HotpotQA从44.00%降至28.77%；同时去掉记忆动作和拒绝机制后平均F1从33.55%降至24.24%。
- **过程奖励对训练至关重要**：同时去掉搜索和记忆奖励后，平均F1降至19.94%，表明两类信号互补且不可或缺。
- **长程能力显著扩展**：随最大步数预算从10向30增加，模型取得一致性提升，如TriviaQA 37.53→55.28（3B），而TC-RAG和Search-R1在长程配置下表现不稳定或退化。
- **训练行为可视化显示**：`<think>`、`<conclusion>`逐步增加，`<search>`相对稳定，`<summary>`与`<backtrack>`波动上升；模型在训练过程中学会使用更紧凑的推理策略（长度先升后降），实现更高效的长程推理。
- **记忆栈+细粒度动作的学得行为更加鲁棒、可解释、记忆感知**，并在更广泛场景（医疗QA、长报告生成、交互决策）中展现出良好泛化能力。

## 7. 优点

- **动作空间设计细致**：提出的六种结构化动作与栈式记忆结合，具备可逆（reversible）与可解释（interpretable）特性，解决了现有方法的"不可修复的追加式记忆"问题。
- **奖励机制层次分明**：结合结果奖励与动作感知的过程奖励，对搜索、记忆操作进行语义层面的质量评估，有效缓解稀疏奖励与弱信用分配。
- **信息感知轨迹选择策略创新性较突出**：利用跨输入批级别的方差信息构建UCB风格分数，在训练中全局地优先高信息轨迹，避免模型陷入低信息、短视推理套路的局部最优——这一思路具有理论支撑和实践有效性。
- **结合pop-based注意力掩码**：对已弹出的记忆token进行屏蔽，防止模型在后续步骤直接访问被撤销的上下文，结构上隔离了方向错误的动作对最终结果的影响。
- **理论分析补充**（附录K）：证明在仅有结果奖励条件下，错误步骤会随训练轮次单调放大；而基于栈的回溯和上下文掩码使错误步骤能系统性地从梯度贡献中消失。
- **实验设计较为全面**：覆盖多类backbone规模、多样任务类型与多个消融角度，验证框架的通用性、鲁棒性与可迁移性。

## 8. 不足与局限

- **算力开销较高**：记忆栈系统和动态检索机制带来了额外的计算成本；训练过程中的记忆操作评估（GRM judge）消耗约3.5~4百万输入token的额外开销（仅训练阶段）。虽然提出投机采样等缓解方案，但对实时/大规模部署仍可能构成瓶颈。
- **超参数调优较敏感**：信息感知轨迹拒绝策略涉及多个需手工调整的超参数，配置差异会显著影响性能，增加了跨任务、跨数据集迁移的调试成本。
- **理论层面存在潜在简化**：主要结果奖励以EM/F1为基准，对需要更复杂评分（如多面评估）的任务覆盖有限；GRM评分模型的选择本身可能引入偏差。
- **动作类型与参数协同优化未解决**：论文指出联合优化高层动作与其内部参数，以及解决不同动作间的冲突（如计划与执行的协调），仍是未来工作。
- **评测数据集种类广度仍有限**：虽已扩展至医疗、报告生成、交互决策等多场景，但相对实际复杂的开放世界应用仍有相当大的距离，领域规模的多样性有待进一步验证。
- **缺乏统计显著性评估与开销透明度**：报告仅给出均值F1，未提供多次运行的标准差、显著性检验或训练/推理token消耗的完整预算明细，削弱结果的可信度对比深度。
- **对中等规模模型之外的适用性**：探索仅限于1.5B、3B、7B的Qwen系列，未涉及更大参数规模的效果与开销权衡。

## 结论
AgenticRag-R1提出了一种将栈式记忆、细粒度动作空间与层级化奖励和智能轨迹拒绝相结合的强化学习框架，在大量多跳QA、开放域QA及扩展智能体任务上相较于现有RL增强的RAG方法取得了显著性提升。方法设计兼顾了"修复可能性"与"探索多样性"，但其计算开销、超参数调优需求以及对更大模型和更广应用场景的适配性仍需进一步研究。
