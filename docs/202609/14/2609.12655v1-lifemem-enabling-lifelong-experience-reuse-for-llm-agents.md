## 摘要
大语言模型智能体有望在其生命周期内通过复用过往经验，持续适应新任务和新环境。然而，现有的基于记忆的智能体难以跨环境迁移可复用的经验，并会随着经验积累而遭遇灾难性遗忘。为应对这些挑战，我们提出LifeMem，一个使智能体能够在多个环境间迁移知识的终身学习框架。在学习过程中，LifeMem根据底层工作流对积累的交互轨迹进行聚类，以提取可复用的技能。在推理时解决新任务时，智能体回忆相关技能和轨迹来指导动作。为验证我们的方法，我们在10个环境和超过13k个任务上开展实验，并使用了2k条新标注的交互轨迹。结果表明，LifeMem能在终身学习中实现有效的经验复用，既减少已学任务上的遗忘，又获得更优的跨任务迁移。进一步分析揭示，任务流会影响学习，而在记忆中整合结构相似的轨迹能提升性能。

## Abstract
Large language model agents are expected to continuously adapt to new tasks and environments over their lifetime by reusing past experience. However, existing memory-based agents struggle to transfer reusable experience across environments and suffer from catastrophic forgetting as experience accumulated. To address these challenges, we propose LifeMem, a lifelong learning framework that enables agents to transfer knowledge across multiple environments. During learning, LifeMem clusters accumulated interaction trajectories based on underlying workflows to extract reusable skills. When solving a new task at inference time, the agent recalls relevant skills and trajectories to guide actions. To validate our method, we conduct experiments across 10 environments and over 13k tasks with 2k newly annotated interaction trajectories. Results show that LifeMem enables effective experience reuse in lifelong learning, achieving both reduced forgetting on learned tasks and superior cross-task transfer. Further analysis reveals that task streaming impacts learning, while consolidating structurally similar trajectories within memory boosts performance.

## 1. 核心问题与整体含义

- **研究背景**：面向通用人工智能（AGI）的 LLM 智能体需要在生命周期内持续适应具身控制、网页导航、工具调用等异构环境，而无需为每个环境重新设计。这一能力被称为**终身学习（lifelong learning）**。
- **核心痛点**：在**跨环境（inter-environment）**设置下，任务来自动作空间、观察空间完全不同的异质环境，现有基于记忆的智能体面临两大困境：
  - **仅轨迹检索（trajectory-only retrieval）**：如 Synapse，仅靠原始轨迹无法桥接不匹配的动作空间，泛化能力弱；且数据库增长后检索精度下降，导致对早期环境的**灾难性遗忘**。
  - **通用轨迹抽象（generic trajectory abstraction）**：如 ExpeL、AutoSkill，在**未组织的记忆池**上全局蒸馏技能，无关轨迹会引入严重的跨环境噪声，产出的技能过于粗糙，反而导致性能退化。
- **论文含义**：作者提出 LifeMem，通过"先按底层工作流聚类、再局部蒸馏技能"的结构化记忆机制，实现跨异构环境的可复用经验迁移，同时抑制遗忘，为智能体部署后的持续进化提供设计范式。

## 2. 方法论

### 核心思想
将智能体记忆建模为**动态组件**：初始化一次、随经验增量更新、推理时被查询。记忆的基本单元不是单条轨迹，而是**工作流级别的簇（workflow cluster）**，并在此之上叠加**环境无关的技能层**，形成层次化记忆 $H = \{(c_i, s_i) \mid c_i \in C\}$。

### 关键技术细节

- **记忆初始化**：给定初始轨迹集，由 LLM 识别共同工作流模式，将其划分为簇 $C=\{c_1,\dots,c_M\}$，并为每个簇生成简洁描述 $d_i$。

- **记忆演化——工作流聚类**：
  - 新轨迹 $\xi$ 到达时，检索其 top-k 相关轨迹并收集对应簇 $C_\xi$；
  - LLM 基于 $\xi$ 与 $C_\xi$ 判断：**对齐**则加入已有簇并更新描述；**不对齐**则新建簇；
  - **几何多样性约束**：引入方向统计中的**平均合成向量长度（Mean Resultant Length, MRL）**。将簇内 $n$ 条轨迹嵌入归一化为单位向量 $x_i$，定义方向集中度：
    $$R = \frac{1}{n}\left\|\sum_{i=1}^{n} x_i\right\|$$
    $R\in[0,1]$，$R\to1$ 表示高度同质（如重复模板），$R$ 低表示行为多样。当且仅当**同时满足** $n > L$ 且 $R < \tau_{mrl}$ 时，才将簇拆分为更细粒度的子簇，从而自适应调整工作流粒度。

- **技能蒸馏**：对每个工作流簇 $c_i$，用 LLM 提示过程 $f(\cdot)$ 映射为环境无关的高层文本技能 $s_i = f(c_i)$，捕获共享约束、逻辑依赖与通用执行原则，剥离低层环境细节。

- **推理时的双层级机制**：
  - 检索 top-k 最相似且**同环境**的历史轨迹作为环境对齐的操作范例；
  - 并行激活这些轨迹所属簇对应的技能集 $S_\xi = \{s_i \mid c_i \in C_\xi\}$；
  - 最终动作 $a = P_\theta(g, M_{act}, o)$，其中 $M_{act}=(\{\xi_j\}_{j=0}^{k-1}, S_\xi)$，兼顾精确行为落地与可迁移技能抽象。

- **整体性能领先**：LifeMem 在所有指标上优于所有基线。GPT-4o-mini 从 ReAct 的 28.84 提升至 **44.13**；Deepseek-v3.2-exp 从 41.14 提升至 **48.02**；Qwen3-32b 从 33.98 提升至 **46.52**。
- **弱模型受益更大**：经验学习对较弱骨干的提升幅度更大（GPT-4o-mini +15.29 vs Deepseek +6.88），部分缩小了模型间差距。
- **有效抑制遗忘**：LifeMem 平均 BwT 为正（+5.66 / +3.11 / +6.68），而 Synapse、ExpeL、AutoSkill 普遍为负，说明结构化记忆显著减少负迁移。
- **零样本迁移能力强**：在 FEVER 与 τ-bench airline 上相对 ReAct 提升 17.9%–22.5%，即使去掉轨迹仅用技能也能保持增益。

- **检索优化不足以替代架构设计**：升级嵌入仅带来微弱增益，加入重排序反而严重退化。

## 7. 优点

- **方法层面**：
