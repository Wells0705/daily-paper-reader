## 摘要
传统大语言模型（LLM）的作用范围局限于单个用户会话，其知识被限制在单次对话中，无法学习随时间演变的用户偏好。现有的智能体记忆系统缓解了这一局限，但通常仅在单用户层面运行，限制了可跨用户共享以改善下游响应的公共知识。我们提出AIM（Agentic Interoperable Memory，智能体可互操作记忆），一个统一的、隐私感知的记忆框架，使多智能体、多用户LLM系统能够持久地管理私有记忆与共享记忆。AIM动态地将信息分类为私有（仅限某一用户访问且其他用户不可访问）或公共（所有用户均可访问）。它实施索引级访问控制，使得私有记忆只能由其所有者检索，从而在保护敏感数据的同时，允许有益的共享知识提升协调性与一致性。我们还提出了MUMBench（Multi-User Memory Benchmark，多用户记忆基准），这是一个包含四个领域中私有与可共享信息的多用户交互数据集。据我们所知，MUMBench是首个旨在评估多用户环境中多种记忆操作（包括检索、创建、更新和删除）的公开数据集。在MUMBench上的三次独立运行中，AIM实现了96.0%的可见性分类准确率、58.8%的严格操作准确率和70.5%的状态感知操作准确率。

## Abstract
Traditional large language models (LLMs) are scoped to individual user sessions, limiting their knowledge to a single conversation and preventing them from learning user preferences that evolve over time. Existing agentic memory systems address this limitation but generally operate at the individual-user level, restricting the public knowledge that could be shared across users to improve downstream responses. We introduce AIM (Agentic Interoperable Memory), a unified, privacy-aware memory framework that enables multi-agent, multi-user LLM systems to persistently manage private and shared memory. AIM dynamically classifies information as private, scoped to one user and inaccessible to others, or public, accessible to all users. It enforces index-level access controls so that private memories are retrievable only by their owner, protecting sensitive data while allowing beneficial shared knowledge to improve coordination and consistency. We also introduce MUMBench (Multi-User Memory Benchmark), a dataset of multi-user interactions containing private and shareable information across four domains. To our knowledge, MUMBench is the first public dataset designed to evaluate multiple memory operations, including retrieval, creation, update, and deletion, in a multi-user environment. Across three independent runs on MUMBench, AIM achieves 96.0% visibility classification accuracy, 58.8% strict operation accuracy, and 70.5% state-aware operation accuracy.

## 2. 方法论

### 2.1 核心思想

AIM将多智能体记忆管理分解为**两条级联推理路径**，共享一个持续演化的记忆存储：

- **写入路径**：判断是否需要记忆操作 → 提取结构化事实 → 分类可见性 → 去重 → 持久化。
- **读取路径**：可见性约束的稠密检索 → 标签级重打分 → LLM重排序 + 时间融合。

一个形式化的**可见性谓词 V** 同时治理两条路径，确保私有记忆对未授权用户**结构性不可访问**。

### 2.2 问题形式化

- 定义用户集 U、智能体集 A、持久记忆存储 M = {m₁, m₂, …}。
- 每条记忆 mᵢ 包含：文本内容 cᵢ、稠密嵌入 eᵢ ∈ ℝᵈ、所属用户 uᵢ、所属智能体 aᵢ、可见性 vᵢ ∈ {PUBLIC, PRIVATE}、关键词标签集 τᵢ、时间戳 tᵢ、辅助元数据 μᵢ。
- **可见性谓词**：V(u, mᵢ) = (vᵢ = PUBLIC) ∨ (vᵢ = PRIVATE ∧ uᵢ = u)。
- **写入附加所有权要求**：更新和删除操作只能由创建用户（或无用户上下文时的创建智能体）执行，防止一个用户的智能体覆盖他人的记忆（即使是公共记忆）。

### 2.3 关键技术细节

**（1）多标签意图检测（§3.2）**

- 将消息 x 映射到 {C, R, U, D} 的子集或 NONE。
- 关键设计：**允许单条输入返回多个标签**。例如“我刚搬到旧金山。能推荐晚餐地点吗？”产生 {C, R}。
- 通过上下文学习实现：提示词包含操作分类法、每个标签的少样本示例（含多标签案例）、隐私守卫（试图获取他人私有信息的查询映射为 ∅），并使用约束解码。

**（2）结构化记忆提取（§3.3）**

- 提取器 f_ext 将消息映射为变长记忆元组列表 {(cⱼ, τⱼ, μⱼ)}，含文本内容、显著关键词标签集、可选溯源元数据（时间上下文、领域类别）。
- 使用带约束 JSON 模式解码的提示式 LLM 强制执行输出模式。

**（3）隐私感知可见性分类（§3.4）**

- 分类器 f_cls 返回 PUBLIC 或 PRIVATE，决定后续去重范围、检索过滤和更新/删除权限。
- 提示词中编码归纳偏置：
  - **公共信号**：集体事件（团队会议、截止日期）、组织公告、共享资源。
  - **私有信号**：个人偏好、个人日程、直接消息、敏感数据（健康、财务）。

**（4）上下文语义去重（§3.5）**

- 三路分类，条件于动态知识库：
  - **CREATE**：比较集 Mᵥ 中无语义等价记忆。
  - **UPDATE**：存在覆盖同一主题但信息过时的记忆 m̂ ∈ Mᵥ，返回指针。
  - **NO-OP**：已有记忆已涵盖该内容。
- **范围受限设计**：公共记忆与所有公共记忆比较；私有记忆仅与同一用户拥有的私有记忆比较，防止跨用户信息通过去重信号泄露。

**（5）记忆表示与索引（§3.6）**

- 向量索引存储支持 ANN 检索与元数据谓词过滤。
- 嵌入维度 d = 3072，由嵌入模型 φ 生成。
- **标签增强嵌入**：eᵢ = φ(concat(cᵢ, τᵢ,₁, τᵢ,₂, …))，将内容与显著标签联合编码，改善关键词聚焦查询的检索效果，无需独立稀疏索引。
- 使用 HNSW 算法进行高效 ANN 搜索；用户、智能体、可见性、标签等元数据字段独立索引以支持谓词下推。

**（6）级联记忆检索（§3.7）**

- **Stage 1：可见性约束的稠密检索**。将 V(u, ·) 作为服务端过滤器推入向量索引，按余弦相似度返回 top-k 候选，复杂度 O(log|M|)，其他用户的私有记忆永不成为候选。
- **Stage 2：标签级语义重打分**。计算标签相似度 s_tag，候选需同时超过内容阈值 τ_vec 和标签阈值 τ_tag，作为精度门控。
- **Stage 3：LLM 重排序与时间融合**。逐点 LLM 打分器计算相关性 s_rel ∈ [0,1]（保守评分：>0.7 需直接具体相关，不确定默认 ≤0.4，反映“展示无关记忆比遗漏边缘记忆更有害”的成本不对称）；再与归一化新近度 s_rec 融合，最终得分 s_final = (s_rel + s_rec) / 2，按此排序截断至 k。
- **LLM 调用预算**：Stage 1 和 2 仅用嵌入查找，仅 Stage 3 调用 LLM，且 Stage 2 双阈值过滤会激进剪枝，重排序器通常只需评分远少于 k 条记忆。

**（7）模块化与消融（§3.8）**

- 每个推理组件（f_op、f_ext、f_cls、f_dedup、φ、g_θ）和向量索引均通过抽象接口定义，由配置驱动的工厂实例化，可独立替换或禁用，支持隔离各组件贡献的消融研究。
