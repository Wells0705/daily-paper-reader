## 摘要
前瞻记忆是指在继续其他工作的同时，在正确的未来线索下执行一项延迟意图。现有基准已将其独立为一种智能体技能，但前沿大语言模型仍难以胜任：已发表的 PM-Bench 脚手架最高仅达到 65.1% 的 Set-F1。我们认为这一任务本质上是基于模式约束的状态跟踪，而非开放式推理，并且当动作空间被类型化时，小模型也能执行该任务。我们提出了前瞻意图存储（Prospective Intention Store, PIS），将生命周期逻辑置于代码中，并将限定范围的语言处理工作留给模型。该脚手架是智能体式的且无需训练：既无需选择器微调，也无需轨迹蒸馏。在 PM-Bench 上，DeepSeek-Chat 配合 PIS 达到了 82.9% 的 Set-F1。在 Gemma-E2B 上，不使用存储时 Set-F1 仅为 4.2%，在七条回顾记忆下最高为 6.6%，而 PIS 达到了 66.2%。PIS 进一步达到 70.1% 的 Set-F1，而回顾记忆方法最高仅为 54.4%。PIS 在该基准上取得了新的最优结果，并使小模型能够超越已发表的大模型脚手架。

## Abstract
Prospective memory means carrying out a deferred intention at the right future cue while other work continues. Benchmarks now isolate it as an agent skill, yet frontier LLMs still struggle: the best published PM-Bench scaffold reaches only 65.1% Set-F1. We argue that this loop is schema-constrained state tracking rather than open-ended reasoning, and that small models can execute it when the action space is typed. We propose the Prospective Intention Store (PIS) that puts lifecycle logic in code and scoped language work on the model. The scaffold is agentic and training-free: no selector fine-tuning and no trajectory distillation. On PM-Bench, DeepSeek-Chat with PIS reaches 82.9% Set-F1. On Gemma-E2B, Set-F1 is only 4.2% without a store and at most 6.6% under seven retrospective memories, while PIS reaches 66.2%. PIS further reaches 70.1% Set-F1, where retrospective memory methods stay at most 54.4%. PIS sets a new state of the art on this benchmark and enables small models to surpass the published large-model scaffold.

## 一、核心问题与研究背景

- **研究动机**：前瞻记忆（Prospective Memory, PM）指在继续其他工作的同时于正确时间节点执行已延迟的意图，是长时程智能体辅助的关键技能。现有基准（PM-Bench）已将此技能独立评估，但即便前沿大语言模型（LLMs）仍表现欠佳——已发表最佳脚手架仅达 65.1% Set-F1。
- **核心洞见**：作者认为前瞻记忆本质上不是开放式推理任务，而是"受模式约束的状态跟踪"问题——类似于智能体记忆操作中频繁出现的结构化抽取、摘要、相似度检索等限定范围调用，这类任务小语言模型（SLMs）本就擅长。
- **研究空白**：现有 "Memory × SLM" 系统几乎全部面向回顾记忆（retrospective memory，检索/缓存过去经验），而非前瞻记忆（维护延迟意图到未来线索出现）；此前也无人系统研究 SLM 在前瞻记忆任务上的表现。
- **整体意义**：通过类型化意图存储，小模型可以在无需训练、无需蒸馏的前提下超出已发表的大模型脚手架，为前瞻记忆这一智能体技能提供了低成本高效解决方案。

## 二、方法论：PIS（Prospective Intention Store）

### 核心思想

- 将延迟承诺**类型化**为结构化记录，生命周期逻辑固化在代码中；模型只负责有界语义接地（scoped semantic grounding），其中生命周期多为确定性、结构性操作。
- 完全**免训练**（training-free）：无需 selector 微调（LoRA）、无需教师轨迹蒸馏、无需 PEFT。

### 意图表示

- 每个意图为三元组：**I = (φ, α, σ)**，其中：
  - φ = 触发条件（trigger condition）
  - α = 预期动作（intended action）
  - σ = 状态 ∈ {pending, done, canceled}
- 理想到期集 D⋆ₜ = {α | I ∈ Pₜ, σ = pending, Vₜ ⊨ φ}，按轨迹 Set-F1 评估。

### 四阶段操作流程

1. **Form（形成）**：将叙述文本拆解为承诺片段，经槽填充转为类型化记录（φ, α, pending）。这是唯一开放文本进入存储模式的阶段。
2. **Revise（修订）**：对现有存储进行信念更新，而非检索；每一条待定意图可应用类型化补丁：改期（重新写 φ）、覆盖（替换 α）、取消（σ ← canceled）。
3. **Filter（筛选）**：通过结构规则（时程、精确时钟匹配、离散事件/通道标签）生成资格板 Bₜ（eligibility board）；通道条件意图若尚未查询对应通道仍保留在板上作检查目标。
4. **Decide（决策）**：先由通道裁判判断是否需要查询隐藏通道（Observation），获得回复后并入证据 Vₜ；随后由 Decide 将 (Bₜ, Vₜ, Xₜ) 映射至到期集与更新后的存储；履行完毕的待定行被标记为 done。

### 算法步骤（单步）

1. Pₜ ← Pₜ ∪ Form(Vₜ)
2. Pₜ ← Revise(Pₜ, Vₜ)
3. Bₜ ← Filter(Pₜ, Vₜ)
4. 当通道裁判请求查询 c 时，Vₜ ← Vₜ ∪ {c}（循环）
5. (D̂ₜ, Pₜ₊₁) ← Decide(Bₜ, Vₜ, Xₜ)

## 六、主要结论与发现

1. **大模型**：DeepSeek-Chat + PIS 达 **82.9% Set-F1**，显著超过回顾记忆方法（46.5%–58.3%）和无存储 single（67.7%），创 PM-Bench 新 SOTA；跨日漏检达到 0.0%，更新漏检降至 22.2%。
2. **极端小模型**：Gemma-E2B 在不使用存储时 Set-F1 仅 4.2%，七种回顾记忆下最高 6.6%；同一冻结 PIS 将其推至 **66.2%**，约 10 倍于最佳回顾记忆；跨日漏检从 ≥85.7% 降至 28.6%。
3. **其他 SLM**：Qwen3.5-4B + PIS 达 **70.1%**，而回顾记忆方法最高仅 54.4%（且大多数低于 single）；Qwen3-8B + PIS 达 57.2%。
4. **效率结论**：回顾记忆方法看似省时但实为"低效的省"——缺少主动查询（Observation）与通道监测，精度崩溃；PIS 的精度增益来自脚手架的合理设计而非单纯堆长提示。
5. **主要理论结论**：前瞻记忆可以被类型化为意图存储上的 Form–Decide 操作；将生命周期逻辑交给代码、将语义接地留给模型的分工，使小模型在无需训练的情况下超越大模型脚手架成为可能。

## 七、方法亮点

1. **首个系统性前瞻记忆形式化**：将延迟承诺定义为 I=(φ, α, σ) 类型化记录，将到期集决策定义为外部存储上的算子（π, F），概念清晰。
2. **无需训练的设计**：既不需要 selector LoRA，也不需要教师蒸馏，实验增益完全归功于存储架构与算子分解；降低了实际部署门槛。
3. **面向 SLM 的适配**：将任务分解为大量"窄而重复"的小型调用，契合 SLM 擅长场景（TinyAgent 风格的类型化接口）。
4. **主动观察（Observation）机制**：设计上允许模型主动查询隐藏通道（如门户网站、传感器、收件箱）后再做决策，贴近真实智能体使用场景，解决现有回顾记忆无法支持的通道条件承诺。
5. **效率与精度并重**：同时报告 token 与墙钟开销，论证了 PIS 在更高精度下的成本可控性。

## 八、不足与局限

1. **基准覆盖有限**：公共前瞻记忆基准稀缺，实验集中在 PM-Bench 单基准上，缺少跨数据集验证（论文承认并计划补充新基准）。
2. **缺少消融实验**：虽声明 Form–Revise–Filter–Decide 各阶段贡献可归因，但文中未提供逐阶段移除的实证数据。
3. **SLM 残余瓶颈**：Gemma-E2B 与 PIS 组合下更新漏检率仍较高（77.8%），说明修订（reschedule/cancel/override）相关语义对端侧小模型仍是难点。
4. **无训练路径探索**：作者明确未探索微调空间，PEFT/微调能否进一步提升效果未知。
5. **大模型参考系单一**：除 DeepSeek-Chat 外未与其他前沿大模型（如 GPT、Claude、Gemini）在 PIS 上作对比，部分结论的普适性待验证。
6. **"回顾记忆低位运行"可能存在测量偏差**：回顾记忆系统在 PM-Bench 上的低分与其设计目标（服务对话问答而非线索触发）部分相关，不能简单等同为"不如 PIS"；不过论文已通过 single 等 baseline 加以部分控制。
