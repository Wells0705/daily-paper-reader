## 摘要
大语言模型（LLM）智能体越来越频繁地处理长时间交互历史，其中有效的推理需要识别并利用分布在过往观察和行动中的任务相关证据。然而，在后续生成过程中，先前计算得到的表示中所编码的有用信息往往未被充分利用。我们提出**TransMem**，一种轻量级的推理时参数化记忆模块，将来自冻结的LLM骨干网络的稀疏历史隐藏状态转化为可复用的记忆表示。TransMem使用轻量级门控网络，动态地将潜在干预应用于当前隐藏状态，而无需重复编码先前的上下文。为了学习可迁移的记忆利用方式而非任务特定的知识，我们引入证据条件自蒸馏。一个增强记忆的学生模型处理完整上下文，并匹配共享同一冻结骨干网络、仅基于证据的教师模型的预测分布。在LoCoMo、HotpotQA和MemoryAgentBench上的实验表明，TransMem在不同模型架构和规模上都能带来一致的提升。TransMem在LoCoMo上取得11.58–29.25的F1提升，在HotpotQA上取得10.20–13.03的提升，同时将MemoryAgentBench的平均准确率从29.54%提高到40.00%。这些结果确立了稀疏历史隐藏状态作为长上下文LLM智能体有效且高效的记忆基板。我们的代码可在https://github.com/Haodong-Lei-Ray/TransMem获取。

## Abstract
Large language model (LLM) agents increasingly operate over long interaction histories, where effective reasoning requires identifying and exploiting task-relevant evidence distributed across past observations and actions. However, useful information encoded in previously computed representations is often underutilized during subsequent generation. We propose \textbf{TransMem}, a lightweight inference-time parametric memory module that transforms sparse historical hidden states from a frozen LLM backbone into reusable memory representations. TransMem uses a lightweight gating network to dynamically apply the latent intervention to the current hidden states, without repeatedly encoding the preceding context. To learn transferable memory utilization rather than task-specific knowledge, we introduce evidence-conditioned self-distillation. A memory-augmented student processes the full context and matches the predictive distribution of an evidence-only teacher that shares the same frozen backbone. Experiments on LoCoMo, HotpotQA, and MemoryAgentBench demonstrate consistent improvements across different model architectures and scales. TransMem yields gains of 11.58--29.25 $F_1$ on LoCoMo and 10.20--13.03 $F_1$ on HotpotQA, while improving the average MemoryAgentBench accuracy from 29.54\% to 40.00\%. These results establish sparse historical hidden states as an effective and efficient memory substrate for long-context LLM agents. Our code is available at https://github.com/Haodong-Lei-Ray/TransMem.

## 1. 核心问题与整体含义

- **研究动机**：LLM 智能体在长交互历史中需要定位并利用分散的 task-relevant 证据，但因果 Transformer 的隐藏状态虽然天然聚合了前缀信息，却存在位置敏感性（recency bias），导致早期关键证据在后续生成时被低估。
- **核心问题**：如何在不重新编码整个长上下文、不扩缩骨干模型的前提下，让模型更好地利用“已经计算过”的历史隐藏状态中的潜在信息？
- **整体含义**：提出了一种“记忆能力”与“推理能力”解耦的路径——不学习特定知识，而是学习“如何从既有隐藏状态中提取并注入有用信息”，从而提升长上下文推理。

## 2. 方法论

### 核心思想
- 将**冻结 LLM 骨干**在某层（K 层）计算出的**稀疏历史隐藏状态**（按段采样得到）作为“记忆特征”；
- 通过一个轻量级的 **TransMem 模块**（含一个 Transformer 块、线性投影、门控网络）将记忆特征转换成“记忆偏移量”，并动态地加到当前生成 token 的隐藏状态上；
- 通过**证据条件自蒸馏（Evidence-Conditioned Self-Distillation, ECSD）**训练：学生模型（带 TransMem 的完整上下文输入）匹配教师模型（只接收证据+问题，同一冻结骨干）的预测分布。

### 关键技术细节
- **记忆特征提取**：将上下文 $C$ 切分为 $B$ 段，取每段最后 token 的隐藏状态 $h_{n}, h_{2n}, \dots, h_L$ 作为记忆集合 $H_M$（默认 $B=4$，保证稀疏性；超长上下文采用分块聚合）。
- **记忆变换**：
  - $h_m = f_m^K(H_M, h_{A_{1:t} })$：标准化自回归注意力；
  - $\Delta h = W_\Delta^K h_m$：线性投影得到记忆偏移；
  - $g_m = \alpha \sigma(W_g h_m / \tau)$：门控缩放（默认 $\alpha=2$，$\tau$ 为温度）；
  - $\hat{h}_t^K = h_t^K + g_m \odot \Delta h$：仅对生成阶段的 token（$t \ge L+1$）施加校正。
- **训练目标**：最小化前向 KL 散度：
  $$ \mathcal{L}_{SD} = \frac{1}{|A|}\sum_{i=1}^{|A|} \mathrm{KL}\big(p_T(\cdot|A_{<i}, E, Q) \,\|\, p_S(\cdot|A_{<i}, C)\big) $$
- **插入位置**：仅插入骨干最后 4 个 Transformer 层（实验证实较优），而非全部层，保证轻量。

## 6. 主要结论与发现

- TransMem 在**所有测试骨干与数据集**上均带来一致提升：
  - LoCoMo F1 提升 11.58–29.25；
  - HotpotQA F1 提升 10.20–13.03；
  - MemoryAgentBench 平均准确率从 29.54% 提升至 40.00%。
- 记忆能力具有**跨任务迁移性**：仅在 HotpotQA 上训练即可泛化到 LoCoMo、MemoryAgentBench。

- 插入位置：最后 4 层最优，更深插入未必更好；门控网络在多跳推理上贡献更明显。
- ECSD 训练目标优于 SFT、GRPO、OPD，说明 token 级证据分布监督对记忆模块学习至关重要。

## 7. 优点

- **新颖性**：直接复用已计算的隐藏状态作为记忆基板，避免重复编码长上下文，将“记忆利用”显式参数化。
- **轻量高效**：只插入最后 4 层、仅生成阶段调用、记忆槽数可低至 5，计算和延迟几乎不随上下文增长。
- **训练范式**：证据条件自蒸馏使用共享冻结骨干的自蒸馏，无需额外教师模型，且能学习可迁移的记忆能力而非任务记忆。
- **充分验证**：跨架构（Qwen、Llama）、跨规模（4B-14B）、跨任务（多跳 QA、超长对话记忆）、多类基线比较，并在附录进行大量补充实验。
- **鲁棒性**：对记忆段数不敏感，对特征来源选择不敏感，门控行为在域内外保持稳定。
