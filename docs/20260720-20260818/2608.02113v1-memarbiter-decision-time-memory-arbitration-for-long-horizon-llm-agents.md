## 摘要
大语言模型（LLM）智能体必须保留并利用跨步骤信息，才能在长视野任务中连贯行动。现有方法提高了记忆的可访问性，但行动相关信息仍可能因其形成、组织、优先级排序或呈现方式不佳而无法指导当前决策。我们将这种访问后失败称为“记忆-行动差距”。我们提出了MemArbiter，一种功能感知的记忆仲裁框架，用于解决该差距中由记忆管理引发的部分。MemArbiter将交互历史分解为原子条目，将其组织到五个功能性记忆库中，并结合库级需求、条目级相关性、焦点-环境表征以及时间呈现门控，动态控制记忆显著性。我们在ALFWorld上，在统一的每步记忆预算下，将MemArbiter与扁平检索和扁平近期性进行了评估。在500和750个token的预算下，MemArbiter使用开放权重动作生成模型分别实现了82.8%和92.5%的成功率，分别比最强基线高出20.9和25.4个百分点。它还改善了失败后的恢复能力，并减少了失败动作重复和状态-动作重现。这些结果表明，功能感知的记忆仲裁能使可访问信息更有效地指导行动。

## Abstract
Large language model (LLM) agents must retain and use cross-step information to act coherently in long-horizon tasks. Existing methods improve memory accessibility, yet action-relevant information may still fail to guide the current decision because it is poorly formed, organized, prioritized, or presented. We call this post-access failure the Memory-Action Gap. We propose MemArbiter, a function-aware memory arbitration framework that addresses the memory-management-induced component of this gap. MemArbiter decomposes interaction histories into atomic items, organizes them into five functional Memory Banks, and combines bank-level demand, item-level relevance, focal-ambient representations, and a temporal presentation gate to dynamically control memory salience. We evaluate MemArbiter on ALFWorld against Flat Retrieval and Flat Recency under unified per-step memory budgets. With an open-weight action-generation model, MemArbiter achieves success rates of 82.8% and 92.5% under 500- and 750-token budgets, outperforming the strongest baseline by 20.9 and 25.4 percentage points, respectively. It also improves post-failure recovery and reduces failed-action repetition and state-action recurrence. These results show that function-aware memory arbitration enables accessible information to guide actions more effectively.

### 1. 核心问题与整体含义

- **研究动机**：长视野（Long-Horizon）任务是 LLM 智能体应用的关键场景（如网页导航、具身交互、软件工程、多轮工具使用）。智能体必须跨步骤保留并灵活运用历史信息才能保持行为连贯性。
- **核心问题——记忆-行动差距（Memory-Action Gap）**：现有记忆管理方法大多聚焦于提高“可访问性”（即确保信息能够被存储和检索），但即使信息已经进入记忆管理流程、可供当前决策使用，仍可能由于**形成方式不佳、组织混乱、优先级错配、呈现形式不当**而无法有效指导动作选择。这种“可访问但不起作用”的现象，被称为记忆-行动差距。
- **与遗忘/检索失败的区分**：
  - 遗忘 = 信息未被保留；
  - 检索失败 = 信息虽保留但无法被定位；
  - 记忆-行动差距 = 信息已被记忆管线处理并可访问，但未能对行动产生足够影响。
- **研究价值**：填补了 LLM 智能体记忆研究中“存储和检索之后”的空白，将问题聚焦于记忆管理本身如何影响决策质量。该研究为构建更有效的智能体记忆系统提供了新视角和具体方案。

### 2. 方法论：MemArbiter 框架

**核心思想**：将记忆管理视为一个端到端的“仲裁”问题，涵盖记忆形成、功能组织、优先级调度和提示呈现四个环节。通过功能感知的记忆组织与动态显著性控制，使已存储的可访问信息真正驱动动作选择。

**关键技术细节**：

1. **原子记忆条目与五个功能记忆库**：
   - 将交互历史分解为不可再分的原子条目，每个条目在语义上单一、可独立更新。
   - 按决策功能分类存入五个 Memory Bank：
     - **Goal**：任务目标、完成标准——长期稳定，引导行动方向；
     - **Task State**：当前位置、持有物品、物体状态——频繁更新，反映当前情境；
     - **Constraint**：属性要求、位置限制、数量上限——在相关步骤内稳定，限制非法行为；
     - **Episodic**：已执行的动作与结果——持续累积，支持经验复用和失败恢复；
     - **Reference**：物体位置、标识符、URL 等——按需激活，提供环境知识。

2. **双波段表征（Dual-Band Representation）**：
   - 每个条目具有两种呈现形态：**焦点（focal）** 保留完整内容，直接支撑行动选择；**环境（ambient）** 使用确定性模板生成精炼线索，在低token开销下保留关键信息。
   - 双波段与功能库是两个正交维度，条目可在两波段间切换而无需重新提取或分类。

3. **决策相关性信号（Decision-Relevance Signals）**：
   - **库级需求** \( d_{b,t} \)：估计当前步骤对各功能记忆库的总体需要程度，决定该库是否参与本步呈现；
   - **条目级相关性** \( \eta_{i,t} \)：评估单个记忆条目对当前决策的贡献，引导条目级别的状态转换与排序。

4. **时间呈现门控（Temporal Presentation Gate）**：
   - 状态更新规则：\( z_{i,t} = G_{b(i)}(z_{i,t-1}, d_{b(i),t}, \eta_{i,t}, h_{i,t-1}) \)，其中 \( z \) 的取值是焦点（F）、环境（A）或隐藏（H）；
   - 结合上一状态（连续性）、当前相关性信号（即时需求）和相关性历史（区分持续趋势与瞬时波动），避免因单步波动导致重要记忆被过早降级或反复切换；
   - 角色特定规则：Goal 和 Constraint 受保护，只在完成或失效后才被降级；Task State 始终对应最新状态；Episodic 与 Reference 动态调整；
   - 输出带状态标注的记忆集供后续组装。

5. **提示组装（Prompt Assembly）**：
   - 按记忆库分组，同一库内焦点条目优先完整呈现、环境条目以精简形态随后呈现，同波段内按条目级相关性排序，隐藏条目不出现；
   - 最终在记忆预算约束下生成结构化的记忆提示 \( P_t \)，与当前观察共同输入动作生成模型。

### 3. 实验设计

- **基准环境**：**ALFWorld**——将具身家政任务映射为多步文本交互环境的基准，包含导航与物体操作任务，要求智能体跨长轨迹保持和使用信息。
- **数据集规模**：使用 `eval_out_of_distribution` 划分的全部 **134 个未见任务**，涵盖六类任务：Pick（24）、Look（18）、Clean（31）、Heat（23）、Cool（21）、Pick Two（17）。每集最长 50 步。
- **对比方法**：
  - **Flat Recency**：按时间序保留最近记录；
  - **Flat Retrieval**：BM25 检索（k1=1.2, b=0.75），查询由任务目标+前动作+最新观察拼接；
  - **MemArbiter（完整版）**；
  - **消融变体**：w/o Functional Banks、w/o Dynamic Signals、w/o Temporal Gate（仅在 500-token 下评估）。
- **统一预算**：所有方法在相同的 500 与 750 token 记忆预算下进行比较，使用统一的 `o200k_base` tokenizer 计量。
- **动作生成模型**：主实验用 Qwen3.6-27B-FP8（开放权重）；跨模型验证中，仅动作生成更换为 GPT-5.4（记忆写入与状态解析仍用 Qwen3.6）。
- **评估指标**：
  - 主指标：SR@50（134 个任务中 50 步内完成的比例）；
  - 中间阈值 SR@k 比较完成速度；
  - 机制诊断指标：一步恢复率、失败动作重复率、相邻动作重复率、状态-动作重现率，以及失败前后 Episodic 记忆的提示占比变化。

### 4. 资源与算力

- 文中提及的硬件：**单张 NVIDIA A100-SXM4-80GB GPU**；
- 推理框架：vLLM（PagedAttention）服务 Qwen3.6，最大上下文长度 4096 tokens；

### 5. 实验数量与充分性

- **实验组数**：
  1. 三种主要方法 × 两种预算（500/750 token）的完整对比；
  2. 跨模型验证（GPT-5.4 作为动作生成模型，500-token）；
  3. 三个消融变体（500-token）；
  4. 多维度机制诊断（失败恢复、重复行为、状态-动作重现、Episodic 占比变化）。
- **实验数量较为充分**，覆盖了整体性能、模块贡献、模型迁移性和行为机制四个层面。
- **公平性评价**：
  - 优点：所有方法在同一逐步骤记忆 token 预算下评估，且统一度量为同一 tokenizer，避免了“更多记忆 = 更好性能”的偏差；温度为 0、随机种子固定，保证可复现性；SR@k 曲线将失败任务保留在分母中，避免了仅选简单任务的偏差。
  - 不足：
    - 仅在单一基准（ALFWorld）上评估，未覆盖网页或多模态环境；
    - “常见失败任务”子集用于失败恢复分析（500-token 下 29 个、750-token 下 32 个），样本量中等偏小，可能影响统计稳健性；
    - 每个任务仅执行一次（单次运行），缺少多次重复运行的标准差或显著性检验；
    - 未报告 token 预算使用率或超限处理细节，部分隐藏逻辑的边界行为不透明。

### 6. 主要结论与发现

- **整体性能显著提升**：500 token 预算下 SR@50 达 **82.84%**，比最强基线 Flat Retrieval 高 **20.90 个百分点**；750 token 下达 **92.54%**，提高 **25.38 个百分点**。预算增加对 flat 基线提升有限，而对 MemArbiter 增益明显，说明关键不是更多记忆，而是更好的组织与呈现。
- **任务类型间增益分布**：六类任务中五类取得最优（500-token），750-token 下全部六类最优。**Pick Two** 类任务增益最大（0% → 58.82%/70.59%），该类任务需要协调多个中间状态，对记忆仲裁最为敏感。
- **步骤效率更高**：MemArbiter 在同一 step limit 下完成更多任务，说明其性能优势并非通过消耗更多交互步骤取得，而是更有效地利用了交互轨迹。
- **跨模型稳健**：GPT-5.4 作为动作生成模型时，MemArbiter 仍比基线高 12.69（vs Flat Retrieval）和 10.45（vs Flat Recency）个百分点。
- **消融结果**：移除功能库降 15.68 点、移除动态信号降 17.17 点、移除时间门控降 8.96 点（SR@50，500-token）。三个组件均具互补价值，且随交互增长贡献愈发显著。
- **失败恢复与行为质量**：MemArbiter 的失败后一步恢复率更高（500-token 下 +18.2 点、750-token 下 +34.8 点 vs Flat Retrieval），失败动作重复率显著降低（-20.4/-31.4 点），相邻动作重复与状态-动作重现率均为全场最低。
- **记忆呈现的适应性**：失败后，MemArbiter 的 Episodic 记忆提示占比上升（500-token 下 +3.3 个百分点），而无时间门控变体几乎没有变化（+0.2 点），提示时间门控在失败响应中发挥关键作用。

### 7. 优点

- **概念创新**：明确提出并形式化了“记忆-行动差距”，将问题定位在存储/检索之后的“仲裁”环节，为领域提供了新的分析框架，区分于遗忘和检索失败。
- **系统设计完整**：从原子化记忆形成→功能化组织→双层表征→相关性估计→时间门控→预算化组装，形成了端到端的闭环方案；五个记忆库的角色划分与决策功能高度契合，具备心理理论（如工作记忆）层面的合理性。
- **方法透明、可审计**：五个记忆库、库级/条目级信号、焦点/环境/隐藏三态均为显式设计，而非“黑盒”压缩，便于理解和调试。
- **实验对照严谨**：统一 token 预算、统一的 tokenizer、固定温度与随机种子，确保基线对比公平；SR@k 曲线避免了“以更多行动换成功率”的陷阱。
- **诊断实验有洞察**：不仅报告成功率，还深入分析失败响应、重复行为与记忆呈现变化之间的关联，揭示了方法背后的工作机理。

### 8. 不足与局限

- **单一环境评估**：仅在 ALFWorld 文本家政任务上验证，未覆盖 Web 导航（如 WebArena）、多模态具身环境或更开放的对话场景，结论的可迁移性尚不明确。
- **预定义功能角色**：五个记忆库及其相关性信号是人工预先设定的，虽然可解释性强，但面对新领域或新任务类型时可能需要重新设计角色体系，难以自适应扩展。
- **关联性而非因果性证据**：论文显示的失败恢复提升与 Episodic 记忆占比变化之间的关联，并未通过受控干预证明“提升某个记忆的呈现状态直接导致了更好的行动”。作者本人也承认这一局限。
- **统计验证不足**：每个任务仅运行一次，未提供多次运行的方差或显著性检验；Pick Two 类任务中扁平基线为 0% 成功率，可能暗示该类任务的记忆需求极端化，方法在这些任务上的优势虽大但样本仅 17 个。
- **计算代价未分析**：MemArbiter 每一步都要进行状态解析、候选写入、相关性估计与门控推理（均需调用 LLM），额外的 token 开销和延迟成本未与基线（特别是 Flat Recency 的零开销）进行系统对比。
- **其他未覆盖面向**：未讨论知识型记忆与任务无关长期记忆的整合；未涉及多智能体协作中的共享记忆仲裁；对记忆冲突、错误记忆固化等潜在风险未做分析。
