## 摘要
基于LLM的自主代理需要外部记忆来克服其无状态性和有限的上下文窗口，以实现长期交互和动态知识推理。然而，现有的记忆检索方法往往缺乏适应性和样本效率，并且难以从异构存储中检索正确的记忆混合。我们提出了探索性-同化反思（EAR），一个用于高初始检索性能和样本高效适应的框架。EAR结合了两种机制：探索性反思，它执行迭代搜索以启动检索并为每个查询收集有用经验；以及同化反思，它从经验缓冲区重放这些经验，以比仅依赖即时奖励的方法更有效地优化全局重排序器。实验表明，在两个长期对话基准上，EAR相对于基线检索器提高了高达17.9%的检索性能。我们还表明，EAR具有高度的样本效率和对噪声反馈的鲁棒性。

## Abstract
LLM-based autonomous agents require external memory to overcome their statelessness and limited context window for long-term interaction and dynamic knowledge reasoning. However, existing memory retrieval methods often lack adaptability and sample efficiency, and struggle to retrieve the right mixture of memories from heterogeneous stores. We propose Exploratory-Assimilating Reflection (EAR), a framework for high initial retrieval performance and sample-efficient adaptation. EAR combines two mechanisms: Exploratory Reflection, which performs iterative search to bootstrap retrieval and collect useful experiences for each query, and Assimilating Reflection, which replays these experiences from an Experience Buffer to refine a global reranker more efficiently than methods relying only on immediate rewards. Experiments show that EAR improves retrieval by up to 17.9% over the baseline retriever on two long-term dialogue benchmarks. We also show that EAR is highly sample-efficient and robust to noisy feedback.

## 2. 论文提出的方法论

### 2.1 核心思想

EAR 框架由**两个协同模块**组成，分别对应于认知科学中的工作记忆与长期记忆：

- **探索性反思（Exploratory Reflection，短期记忆）**：在单个查询内部执行迭代式深度搜索，构建丰富的证据集合，同时为全局适配器收集有价值的训练经验。
- **同化反思（Assimilating Reflection，长期记忆）**：利用经验缓冲区（Experience Buffer）存储历史探索经验，通过经验回放（experience replay）持续、高效地优化全局重排序器（reranker），而非仅依赖当前查询的即时奖励。

### 2.2 关键技术细节

**（1）残差检索适配器（Residual Retrieval Adapter）**

- 定义可训练参数 $\phi = \{W_q, W_m\}$，其中 $W_q, W_m \in \mathbb{R}^{d \times d}$。
- 通过残差变换对查询和记忆嵌入进行适配：
  - $e_q = \frac{(I + W_q) q}{\|(I + W_q) q\|_2}$
  - $e_{m_i} = \frac{(I + W_m) m_i}{\|(I + W_m) m_i\|_2}$
- 由适配器定义候选记忆集 C 上的分布 $p_\phi(i | x, C)$，用于衡量每个候选记忆被选中的概率。

**（2）探索性反思（Explorer 模块）**

- 每个候选记忆被视为“查询局部老虎机臂”（query-local bandit arm）。
- 维护各候选的选中次数 $N_i^{(t)}$ 和经验平均反馈 $\hat{\mu}_i^{(t)}$。
- 使用 **UCB（Upper Confidence Bound）** 公式计算探索奖励：
  - $U_i^{(t)} = \hat{\mu}_i^{(t-1)} + \alpha \sqrt{\frac{\log(1 + \sum_{\ell \in C} N_\ell^{(t-1)})}{1 + N_i^{(t-1)}}}$
- 定义多样性惩罚项 $D_i^{(t,j)}$（与已选记忆的最大余弦相似度），避免选入冗余记忆。
- 综合得分：$A_i^{(t,j)} = \lambda_{rel} e_q^\top e_{m_i} - \lambda_{div} D_i^{(t,j)} + \lambda_{exp} U_i^{(t)}$，逐轮选择得分最高的记忆（不放回），直至得到大小为 s 的子集。
- 外部评判者（critic）为每个选定记忆标注有效性标签 $y_i \in \{-1, +1\}$，并更新 UCB 统计量。

**（3）同化反思与经验回放**

- 经验缓冲区存储历史查询的探索经验：$e^{(n)} = (q^{(n)}, \{m_i^{(n)}\}, O^{(n)}, \{\tilde{y}_i^{(n)}\})$。
- 回放时，选择与当前查询嵌入最相似的 B 条历史经验（基于余弦相似度）。
- 对回放的每条经验，使用当前适配器重新计算嵌入，并采用 **Gumbel-trick** 实现随机化的样本选择。
- 训练损失包含两部分：
  - 当前查询损失 $L_{cur}(\phi)$：反馈加权排序目标，提升正反馈记忆的概率、降低负反馈记忆的概率。
  - 经验回放损失 $L_{rep}(\phi)$：对回放经验应用相同的排序目标。
  - 总损失：$L_{EAR}^{(n)}(\phi) = L_{cur}^{(n)}(\phi) + \lambda_{rep} L_{rep}^{(n)}(\phi)$，进行在线梯度更新。

**（4）推理模式**

- **仅适配器推理**：关闭 Explorer，直接根据适配后的相关性分数选择 top-s 记忆，无需额外 critic 调用，评估适配器自身已同化的知识。
- **探索辅助推理**：启用 Explorer，进行 T 轮探索后返回最终记忆集，提供额外查询级自适应，但需要额外的 critic 调用。

## 6. 论文的主要结论与发现

- **EAR 显著优于基线**：在 LongMemEval 上，EAR 相对基线检索器提升 Recall@5 最多 **17.9%**；在 LoCoMo 上提升 **12.5%**。相对 RL Update 基线分别提升 20.6% 和 29.1%。
- **下游 QA 准确率同步提升**：LLM-as-a-Judge 分数较基线检索器提升 10.4%（LongMemEval）和 9.0%（LoCoMo）。
- **样本效率高**：EAR 仅需 **80 个训练查询**即可超越静态检索器，而基线 RL Update 方法在 400 个查询下仍低于静态基线。即使按相同 LLM 调用预算对比，EAR 仍保持稳定领先。
- **噪声鲁棒性强**：即使在反馈精度/召回率降至 70/70 的高噪声条件下，EAR 仍优于基线检索器。
- **消融证明组件互补**：Explorer 主要缓解冷启动问题，Experience Buffer 加速学习轨迹，二者结合效果最优。
- **异构记忆混合能力**：EAR 能根据查询类型自适应调整情景/语义记忆的检索比例，例如 Temporal 查询下将问答准确率从 37.50 提升至 51.56。
- **EAR 是模型无关的**：可与大规模非 RL 重排序器（如 MonoT5）组合使用并进一步获得增益。
- **基线 RL Update 的失败**：在低资源条件下 RL Update 甚至会低于静态检索器，验证了其样本效率低下的核心缺陷。

## 8. 不足与局限

- **计算资源信息缺失**：论文未报告 GPU 型号、数量、训练时长等关键资源信息，不利于复现和计算成本评估。
- **消融实验覆盖有限**：消融和噪声实验仅在 LongMemEval 上报告，LoCoMo 上的消融仅给出 Recall@5 的单一数值，缺乏更全面的对比。
- **基线选择有限**：仅对比了 Tan et al. (2025) 的 RL 方法和静态检索器，未与其他自适应检索方法（如 Self-RAG、Adaptive-RAG 等）直接对比（虽然文中在相关工作部分有所讨论）。
- **RL Update 基线的不稳定性**：基线 RL Update 在多个条件下出现巨大性能退化（如 Contriever 在 LoCoMo 上 Recall@5 仅 25.97），虽然这佐证了 EAR 的优势，但也可能暗示基线实现或超参调优不够充分，对比公平性有待商榷。
- **大检索器效果受限**：在 LongMemEval 的少量训练数据下，EAR 对 GTE（7B 参数、3584 维嵌入）甚至未能超过静态基线。适配器参数量随嵌入维度平方增长（$2d^2$），限制了其在大规模检索器上的表现。
- **模拟反馈的局限性**：虽然使用概率模拟器保证了可复现性，但模拟的反馈噪声模型可能与真实 LLM 的偏差模式存在差异（论文已在附录中用 GPT 5 Mini 做了初步验证，但覆盖仍有限）。
- **单一语言和场景**：实验仅覆盖英文对话记忆场景，未验证多语言或其他任务类型（如代码辅助、工具使用）下的泛化能力。
- **经验回放策略仍有优化空间**：论文自己也指出，更复杂的采样或回放机制值得未来探索，当前相似度采样虽最优但可能不够精细。
- **端到端效果归因不够清晰**：虽然 EAR 在检索和 QA 指标上均有提升，但检索提升多大程度上转化为 QA 提升、以及 LLM 自身参数知识对结果的贡献，未被严格分离。
