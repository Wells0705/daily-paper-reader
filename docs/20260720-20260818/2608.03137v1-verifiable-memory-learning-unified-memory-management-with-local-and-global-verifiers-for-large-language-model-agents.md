## 摘要
大语言模型（LLM）智能体在长时程交互中必须保留可复用信息、控制有界活动上下文，并恢复早期证据。现有方法通常分别优化长期记忆（LTM）和短期记忆（STM），而统一策略往往主要依靠轨迹级反馈进行训练，这为单个记忆决策提供的信用信号较弱。我们提出可验证记忆（VerMem）框架，将LTM、活动上下文和情节历史表示为不同状态，并通过一个记忆操作策略加以控制。七个原子操作使策略能够对LTM条目进行添加、修订或软删除；将LTM检索至活动上下文；过滤或总结活动上下文；以及恢复选定的情节片段。VerMem通过监督微调进行初始化，并采用三阶段强化学习课程进行训练。局部验证器为可执行的记忆转换打分，全局验证器则在任务完成后评估证据连贯性与终端记忆一致性。这些分数通过分层信用分配与程序化计算的任务、证据召回、效率和约束信号相结合。验证器仅在训练期间使用。在五个基准和两个LLM骨干网络上，VerMem在绝大多数报告指标上取得最佳结果，并持续优于强记忆基线。在三个交互式基准的受控在线令牌预算下，它还在所比较方法中实现了最强的效率-性能前沿。代码可在https://github.com/Sun-SYSU-24/VerMem获取。

## Abstract
Large language model (LLM) agents must retain reusable information, control a bounded active context, and recover earlier evidence during long-horizon interaction. Existing methods commonly optimize long-term memory (LTM) and short-term memory (STM) separately, while unified policies are often trained primarily with trajectory-level feedback, which provides weak credit for individual memory decisions. We present Verifiable Memory (VerMem), a framework that represents LTM, active context, and episodic history as distinct states and controls them with one memory operation policy. Seven atomic operations let the policy add, revise, or soft-delete LTM entries; retrieve LTM into the active context; filter or summarize the active context; and restore selected episodic fragments. VerMem is initialized by supervised fine-tuning and trained with a three-stage reinforcement-learning curriculum. The local verifier scores executable memory transitions, and a global verifier assesses evidence coherence and terminal-memory consistency after task completion. These scores are combined with programmatically computed task, evidence-recall, efficiency, and constraint signals through hierarchical credit assignment. The verifiers are used only during training. Across five benchmarks and two LLM backbones, VerMem achieves the best result on the vast majority of reported metrics and consistently outperforms strong memory baselines. Under controlled online-token budgets on three interactive benchmarks, it also achieves the strongest efficiency--performance frontier among the compared methods. Code is available at https://github.com/Sun-SYSU-24/VerMem.

## 2. 方法论

### 2.1 核心思想

VerMem 将 LTM、活动上下文 Ct 和情节历史 Ht 保持为不同状态，用一个统一的记忆操作策略 πθ 协调三类记忆功能（LTM 维护、STM 控制、历史恢复）。通过七个原子工具实现状态转换，并用**局部验证器 + 全局验证器**的分层信用分配指导强化学习训练。验证器仅在训练阶段使用，推理时完全移除。

### 2.2 状态表示与策略公式化

- 概念状态：$s_t = (q, M_t, C_t, H_t)$，其中 q 为固定任务描述，Mt 为长期记忆，Ct 为活动上下文，Ht 为同一任务的情节历史。
- 策略可见的有界序列化：$x_t = g(s_t)$，在 8,192 token 限制内呈现 Mt、Ct、Ht 的预算化视图，不无界拼接 Ht。
- 记忆命令：$u_t = (v_t, \xi_t)$，其中 $v_t \in \mathcal{V} \cup \{\emptyset\}$，7 种原子操作类型加空操作。
- 记忆转换：$\tilde{s}_t = T_m(s_t, u_t)$；任务/环境转换：$s_{t+1} = T_e(\tilde{s}_t, b_t, z_{t+1})$，两者角色明确分离。

### 2.3 七个原子记忆工具

| 工具 | 目标 | 功能 |
|---|---|---|
| Add | LTM | 向 Mt 添加持久条目 |
| Update | LTM | 在 Mt 中创建修订版本（保留旧版本） |
| Delete | LTM | 软删除 Mt 中的条目 |
| Retrieve | STM | 将 Mt 内容检索至 Ct |
| Filter | STM | 过滤 Ct 中的低价值内容 |
| SelectEpisode | STM | 从 Ht 恢复相关片段至 Ct |
| Summarize | STM | 总结 Ct 以缩短上下文 |

关键设计：**SelectEpisode 与 Retrieve 区分**。Retrieve 从 LTM 获取持久知识；SelectEpisode 从同一任务的情节历史 Ht 恢复早期证据（观察、工具输出、中间结论），两者信息来源不同、用途不同。

### 2.4 训练流程

- **SFT 热身**：32,000 条训练数据，8 种目标（7 工具 + ∅）平衡覆盖。目标来自边界模板（50%）和冻结的 DeepSeek-V3.2 教师生成（50%），经过 7 项确定性检查过滤，包括工具合法性、参数完整性、引用存在性、无答案泄漏等。
- **三阶段 RL 课程**：
  - Phase A（1,000 更新）：训练 VLTM ∪ {∅}，即 LTM 维护（添加、修订、删除、不做操作）。
  - Phase B（1,000 更新）：训练 VSTM ∪ {∅}，即在干扰项下进行检索、过滤、总结、历史恢复。
  - Phase C（1,500 更新）：训练 V ∪ {∅}，完整任务中 LTM 与 STM 交替协同。
- 每个阶段只传递策略参数，记忆状态独立初始化。

### 2.5 分层信用分配（核心创新）

- **局部验证器**：对每个可执行的记忆转换评分，评估任务相关性、证据支撑、局部进展、信息保真度四个维度，每个维度 0–4 分。
- **全局验证器**：任务完成后评估证据连贯性 v_coherence 与终端记忆一致性 v_state，与程序化计算的任务正确性、支撑事实召回、效率指标共同构成复合全局得分。
- **层次优势**：
  - 全局优势在候选组内归一化：$A^{global}_k = (r^{global}_k - \mu^{global}_q) / (\sigma^{global}_q + \epsilon)$
  - 局部优势按操作类型归一化：$A^{local}_{t,k} = (r^{local}_{t,k} - \mu^{local}_{v_{t,k}}) / (\sigma^{local}_{v_{t,k}} + \epsilon)$
  - 最终信用：$A^{hier}_{t,k} = \lambda_{local} A^{local}_{t,k} + \lambda_{global} A^{global}_k - \lambda_{constraint} c_{t,k}$，三个 λ 均设为 1。
- **被拒命令处理**：局部优势为 0，保留全局优势，直接施加约束成本 c_t,k。
- **优化目标**：基于 PPO 剪裁 + GRPO 候选组归一化的 token 级目标函数，损失仅应用于记忆命令 token，排除任务求解器输出、环境观察、状态序列化 token。

### 2.6 奖励函数设计

复合全局轨迹奖励：$r^{global}_k = \frac{1}{4}(r^{task}_k + r^{evid}_k + r^{state}_k + r^{eff}_k)$，其中：
- r_task：基于答案正确性（HotpotQA 上为精确匹配与 F1 均值）。
- r_evid = ½(r_sup + v_coherence)：支撑事实召回与全局验证器证据连贯性。
- r_state = v_state：终端记忆一致性（全局验证器输出）。
- r_eff：效率项，仅在 r_task ≥ δ（δ=0.5）时生效，防止低成本失败获得效率奖励。
- 约束通道独立处理：无效工具/参数、不支持的写入、防护证据丢失、上下文溢出等硬违规。

- **存在的不足**：消融实验主要集中于 3 个基准（ALFWorld、SciWorld、HotpotQA），PDDL 和 BabyAI 缺少详细的组件级消融；HotpotQA 的 Jjudge 依赖固定 Qwen-Max 快照，第三方独立复现受限；效率实验仅使用 Qwen2.5-7B-Instruct，未在 Qwen3-4B 上验证。

## 6. 主要结论与发现

- **整体性能**：VerMem 在 Qwen2.5-7B 上平均分 48.01，超越 Base 19.96 分（相对提升 71.16%），超越最强外部基线 AgeMem 6.05 分；在 Qwen3-4B 上平均 59.85，超越 AgeMem 5.54 分。五个基准上绝大多数指标排名第一。
- **跨任务迁移**：仅用 HotpotQA 训练，在 ALFWorld、SciWorld、PDDL、BabyAI 上均超过最强基线（增益 3.67–7.84 分），表明学到的是可迁移的记忆操作行为而非任务特定模式。
- **效率-性能前沿**：在 S*=40.0 目标下，VerMem 的 TN@S* 为 2,080 token，比 AgeMem 降低 20.0%；在 B*=2,500 预算下 SR@B* = 44.30，超越 AgeMem 5.30 分。验证器推理时移除，无额外开销。
- **信用分配消融**：局部与全局信用分支各有独立贡献（局部在 ALFWorld/SciWorld 上更大，全局在 HotpotQA 上更大），联合使用效果最佳；完整 VerMem 相对 noVerify 提升 6.12（ALFWorld）/ 9.45（SciWorld）/ 9.67（HotpotQA）分。
- **奖励设计**：All-Returns 相比 Answer-Only 将 Jjudge 从 0.531 提至 0.628、MQ 从 0.491 提至 0.673，同时降低 7.14% token 开销；工具调用次数反而增加（4.47→5.63），说明 token 节省并非通过抑制记忆操作实现。

## 7. 优点

- **统一的记忆操作策略设计**：首次将 LTM 维护、STM 控制、历史上下文恢复集成在单一策略中，同时保留三者的独立状态表示，边界清晰。
- **SelectEpisode 的建模贡献**：明确区分"从 LTM 检索"与"从情节历史恢复"，填补了统一记忆中的功能空白——这对子目标切换后需要重新引用早期证据的复杂长时程任务尤为关键。
- **局部+全局分层信用分配**：操作级语义验证与轨迹级整体效用相结合，配合操作类型归一化，解决了"有用操作在失败轨迹中"和"有害操作在成功轨迹中"的信用误判问题。验证器只在训练阶段使用，不增加推理开销。
- **三阶段课程学习**：按 LTM→STM→协同的顺序渐进训练，降低了联合学习的复杂度，各阶段检查点独立传递参数。
- **程序化评估协议严谨**：隔离状态、统一解码、多 seed 报告、训练/评估分离（验证集、开发集、测试集不重叠）、效率分析固定阈值（S*=40.0, B*=2,500）后评估，整体方法论规范程度较高。

## 8. 不足与局限（续）

- **部分消融只在三个核心基准（ALFWorld、SciWorld、HotpotQA）上进行**，PDDL 与 BabyAI 缺少组件累积消融和信用分支消融，无法判断记忆操作策略在这些任务的性能增益中，各组件（LT、ST、验证器）的贡献结构是否与已测基准一致。
- **训练数据分布单一**：SFT 与全部三阶段 RL 均基于 HotpotQA 构建，虽验证了跨任务迁移能力，但七个原子工具的使用模式（如检索触发时机、总结粒度、删除决策）可能被多跳问答数据的分布特征所塑造，对工具调用密集、目标频繁切换或长对话交互场景的覆盖不足。
- **验证器依赖冻结外部 LLM，存在潜在偏差**：局部与全局验证器的语义打分依赖 DeepSeek-V3.2 等冻结模型，其四维度评分标准（相关性、证据支撑、局部进展、信息保真度）未被系统校准；不同模型族在验证器上的稳定性、跨域泛化性均未报告。HotpotQA 的 Qwen-Max 评估器同样存在快照固定性、与训练数据的潜在污染等隐患。
- **未报告训练成本与运行效率**：3,500 次策略更新、SFT + 三阶段 RL 的完整流程所需算力未被量化，缺 GPU 型号/数量/时长，影响复现成本评估；训练时验证器调用的总次数与离线缓存策略也未说明。
- **记忆状态质量缺少直接度量**：检索准确性、总结保真度、删除合理性、更新一致性等记忆本身的操作质量没有指标直接刻画，只能通过任务成功率间接推断；对"错误记忆策略导致失败"的样本级分析不足。
- **评估环境局限于文本/符号域**：五个基准均为文本式或符号式环境，未覆盖真实多模态、代码执行、API 调用等部署场景；记忆状态每集重置，未检验跨会话、跨任务累积记忆下的策略稳定性。

## 9. 总结

VerMem 的核心贡献在于：以单一策略统一长期记忆维护、短期上下文控制与情节历史恢复三类记忆功能，并用局部验证器（操作级语义）与全局验证器（轨迹级效用）的分层信用分配解决记忆操作效用延迟与信用稀疏问题。程序化验证表明，仅基于 HotpotQA 训练的通用记忆策略可稳定迁移至 ALFWorld、SciWorld、PDDL、BabyAI 等交互/规划基准，在性能、token 效率与推理开销（零额外验证器成本）上全面优于现有统一记忆基线。论文在实验协议（多 seed、确定性解码、数据集隔离、固定阈值效率分析）方面规范度较高，具有较强的可复现基础。

但其局限同样明显：训练数据单一、验证器外部依赖引入潜在偏差、消融覆盖不全、算力报告缺失，以及缺乏跨会话与真实环境评估，使其结论只能在受控场景下成立。总体而言，VerMem 为 LLM 智能体的记忆管理提供了一个结构清晰、验证扎实的新框架，是"记忆操作可学习、可训练、可验证"这一方向上值得关注的工作；其后续价值取决于能否在更广的数据分布、更多模型家族及真实部署环境中保持当前优势。
