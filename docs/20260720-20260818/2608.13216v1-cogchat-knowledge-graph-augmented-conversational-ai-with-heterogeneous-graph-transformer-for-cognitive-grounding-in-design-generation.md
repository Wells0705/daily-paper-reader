## 摘要
基于LLM的聊天系统已成为设计实践中的宝贵工具，能够实现快速构思和灵活的任务支持。然而，这些系统将设计师的表述作为通用序列处理，通过近因性而非说话者如何组织知识的模型来维持上下文。在设计对话中，这种差距会加剧：关系上下文在轮次之间衰减，相同的词语在不同设计师之间无法得到解析，对话循环或重启而非深化。我们提出了CogChat，一种实时聊天框架，将对话式AI锚定在从每位设计师输入构建的个人异构知识图谱中。该系统将类型化实体和关系提取到异构图中，然后应用HGT（异构图变换器）选择结构相关的节点以生成响应，并产生意图性和探索性的探询问题。技术评估表明，基于HGT的实体选择优于无锚定的LLM交互和朴素的KG增强，后者引入的噪声会降低响应质量。一项包含九位专业设计师的受试者内研究表明，将对话锚定在关系结构化、设计师特定的语义上下文中，可以改善上下文保持、个性化意图解释和对话深度，同时降低认知负荷。这些发现表明，将设计师表达的概念和关系结构化为动态知识图谱，可以保留跨轮次消失的关系上下文，为基于LLM的交互中的长期上下文管理提供了一种图谱锚定的方法。

## Abstract
LLM-based chat systems have become valuable tools for design practice, enabling rapid ideation and flexible task support. Yet these systems process designer utterances as generic sequences, maintaining context through recency rather than through any model of how the speaker organizes knowledge. In design conversation, this gap compounds as relational context decays between turns, identical words go unresolved across designers, and the conversation loops or restarts rather than deepens. We present CogChat, a real-time chat framework that grounds conversational AI in a personal heterogeneous knowledge graph constructed from each designer's input. The system extracts typed entities and relations into a heterogeneous graph, then applies a HGT (Heterogeneous Graph Transformer) to select structurally relevant nodes for response generation and to generate both intentional and exploratory probing questions. Technical evaluation shows that HGT-based entity selection outperforms both ungrounded LLM interaction and naive KG augmentation, which introduces noise that degrades response quality. A within-subjects study with nine professional designers indicates that grounding conversation in a relationally structured, designer-specific semantic context improves context retention, personalized intent interpretation, and conversational depth while reducing cognitive load. These findings suggest that structuring a designer's expressed concepts and relations as a dynamic knowledge graph can preserve relational context that fades across turns, pointing toward a graph-grounded approach to long-term context management in LLM-based interaction.

## 1. 核心问题与研究动机

- **背景**：基于 LLM 的对话系统已广泛应用于设计实践，但现有系统将用户视为"通用对话者"，仅依赖**近因性（recency）**维持上下文，而非用户如何组织知识。
- **核心问题**：在设计对话中，这种结构缺失引发三类连环失败：
  - **信息丢失**：跨轮次的关系上下文衰减，系统会忘记"warm"指的是触感肌理而非色温这类情境化含义；
  - **个性化失败**：相同词语在不同设计师手中含义不同（如"heavy"可指视觉密度或信息过载），系统只处理通用语义；
  - **低效循环**：缺乏保留的上下文和可解析的意义，设计师被迫反复解释已确立的共识，对话循环而非深化。
- **关键洞察**：这些问题并非独立缺陷，而是同一根源的表征——**缺乏对设计师认知空间的持久结构化表示**。设计认知本质上是异质的（感知、语义、功能元素共存于同一判断中），将其扁平化为 token 序列丢弃了使设计推理连贯的关系结构。

## 2. 方法论

- **核心思想**：CogChat 从每位设计师的输入中实时构建**个人异构知识图谱**，用 HGT 对图进行嵌入与结构化节点选择，将选定实体注入 LLM 上下文以生成响应和探询问题，从而将对话 AI 锚定在设计师个人的关系化认知结构中。
- **技术流程（每轮五阶段）**：

  **① 知识图谱构建（Structure）**
  - 基于 GraphRAG 从用户话语与助手响应中提取类型化实体与有向关系，实体类型覆盖 CONCEPT、DESIGN_ELEMENT、MATERIAL、PROPERTY、ACTION 等设计导向本体；
  - 节点初始特征为 512 维 CLIP 嵌入；跨轮通过字符串匹配与嵌入相似度增量合并，并以 `answered_by` 边显式连接问题与答案，保留设计师询问与系统回答之间的关联。

  **② 链接集构建与子图采样（Represent）**
  - 正样本：同话语内共现的实体对、设计师正反馈强化的实体对；
  - 负样本包括两类：**硬负样本**（结构邻近但无连接的同类型实体、被"不喜欢"反馈拒绝的实体、HDBSCAN 聚类内但无直接链接的实体）与**随机负样本**（两跳邻域之外均匀采样）；
  - 对当前话语涉及实体进行 1 跳与 2 跳邻域子图采样，按边权比例采样以保证反馈强化的连接更可能被纳入。

  **③ HGT 嵌入**
  - 采用异构图变换器（HGT）：对每个节点类型计算类型特定的 Query/Key/Value 投影，对每条边类型计算关系特定的注意力权重，注意力公式为：
    Attention(v, e, u) = softmax( (W_Q^τ(v)·h_v)^T (W_K^τ(u)·h_u) / √d_k · W_R^φ(e) )
  - 模型配置：3 层、8 注意力头，由 512 维 CLIP 输入产生 256 维嵌入；
  - 每轮基于当前链接集用 BCE 损失与排序损失增量训练，使嵌入空间持续适应用户概念结构的演化；冷启动时（<5 节点）跳过 HGT，直接注入全部节点。

  **④ 上下文接地响应生成（Act）**
  - 计算当前消息嵌入与所有节点 HGT 嵌入的余弦相似度 rel(v) = cos(h_q, h_v)，取 top-k（k≈20）实体注入 LLM 提示词，每个实体附带类型、关键关系及邻域自然语言摘要；
  - 连续性分数整合节点集重叠与平均嵌入相似度，低于阈值时向提示词附加上下文警告，以兼顾连贯性与话题转向。

  **⑤ 探询问题生成（Evolve）**
  - 对相似度分数做 min-max 归一化后，基于均值 μ 与标准差 σ 划分三个区间：
    - ŝ(v) ≥ μ+σ → **意图性（intentional）问题**：指向高相关但图内未充分说明的概念，解决歧义；
    - μ-σ ≤ ŝ(v) < μ+σ → **探索性（exploratory）问题**：指向结构相连但尚未讨论的邻近概念，开拓思维；
    - ŝ(v) < μ-σ → 排除，视为与当前轮无关。
  - 每个问题附带 2-3 个建议答案，设计者的回答反馈进入下一轮抽取，形成闭环优化。

## 6. 主要结论与发现

- **技术层面**：HGT 选择性实体锚定在所有基准上均优于无锚定 LLM 与朴素全图注入；朴素 KG 注入引入噪声反而降低响应质量（揭示的关键洞见是：**对话 LLM 的瓶颈不是记忆容量而是上下文策展——决定每轮应前置哪些关系**）。
- **RQ1（上下文保持）**：CogChat 将完成任务所需轮数从 Baseline 的 9.4 降至 5.1（↓45.9%），会话数由 2.1 降至 1.0（设计师不再因系统遗忘而重启会话）；BERTScore 与 Token IoU 均显著高于 KG-only，说明 HGT 不仅保留概念，还保留了设计师自己的词汇与关系；负反馈数从 3.67 降至 0.22，表明用户不满主要源于上下文丢失而非响应质量。
- **RQ2（个性化意图解释）**：CUQ 显著提升（46.7 → 77.8）；探询成功率从 0.17 提升至 0.70（≈4 倍），表明图接地问题比通用追问更相关；正反馈数显著增加；访谈中设计师报告系统能解读"水的属性"为波浪肌理而非透明度这类设计师特定语义。
- **RQ3（认知负荷与对话深度）**：NASA-TLX 心理需求、努力、挫败感显著降低（但 KG-only 与 CogChat 差异不显著，说明认知负荷降低主要来自上下文保持而非嵌入选择）；任务完成时间仅 CogChat 显著缩短（14.1 min vs 19.5 min，↓27.7%），说明效率增益需要个性化接地的加持而非仅有上下文记忆；8/9 参与者认为 CogChat 对话最深，主题围绕响应具体性、多视角参与和渐进细化。
- **核心论断**：真正起作用的是系统如何**组织**所记忆的内容——关系结构而非词汇表驱动了观察到的增益；CogChat 是"图接地对话个性化"，复用设计师表达的关系，而非建模其内部认知。
