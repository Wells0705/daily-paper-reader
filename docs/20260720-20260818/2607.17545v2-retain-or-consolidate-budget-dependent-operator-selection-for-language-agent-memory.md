## 摘要
语言智能体在交互过程中依赖记忆。然而，大型语言模型（LLM）有限的上下文窗口及其推理成本限制了单次可使用的记忆量。现有系统主要遵循两种策略：记忆保留与记忆整合。保留策略保存原始记录并保留确切细节，但在预算紧张时相关证据可能无法容纳；整合策略压缩并合并记录，提高了每个标记的覆盖率，但可能丢失对查询至关重要的细节。这两种策略均非普遍更优。这引出了两个核心问题：整合应在何时替代保留，以及应选择何种算子——合并、摘要还是重写？我们通过将每个算子的效用分解为对保留策略遗漏证据的覆盖效应，以及对已容纳原始证据的带符号替代效应，来形式化这一决策。两者的平衡解释了为何最优操作随相对预算压力而变化。我们通过离线抽象-安全性（OAS）机制实现该方法，这是一个轻量级学习器，利用生成前特征估计动作效用，并进行留出法危害校准。公开的LongMemEval和LoCoMo基准显示了相同的预算依赖模式。在LongMemEval上，预算紧张时整合可将绝对准确率提升高达48%，而预算宽松时保留策略更优；LoCoMo在更小预算下复现了这一交叉现象，与其较短的证据特征一致。在两个数据集上，当需要压缩时，跨笔记抽象和合并总体上优于局部重写。

## Abstract
Language agents depend on memory across interactions. However, the limited context windows of large language models (LLMs) and their inference costs constrain how much memory can be used at once. Existing systems mainly follow two strategies: memory retention and memory consolidation. Retention keeps raw records and preserves exact details, but relevant evidence may not fit under a tight budget; consolidation compresses and combines records, improving coverage per token but risking the loss of query-critical details. Neither strategy is universally preferable. This raises two central questions: when should consolidation replace retention, and which operator -- Merge, Abstract, or Rewrite -- should be selected? We formalize this decision by decomposing each operator's utility into a coverage effect on evidence omitted by retention and a signed replacement effect on raw evidence that already fits. Their balance explains why the preferred action changes with relative budget pressure. We implement this mechanism with Offline Abstraction-Safety (OAS), a lightweight learner that estimates action utilities from pre-generation features with held-out harm calibration. The public LongMemEval and LoCoMo benchmarks show the same budget-dependent pattern. On LongMemEval, consolidation improves absolute accuracy by up to 48% under tight budgets, whereas retention is preferable under loose budgets; LoCoMo replicates this crossover at a smaller budget, consistent with its shorter evidence. On both datasets, cross-note abstraction and merging generally outperform local rewriting when compression is necessary.

## 1. 论文的核心问题与整体含义（研究动机和背景）

- **核心问题**：在 LLM 上下文窗口和推理成本的预算限制下，语言智能体应如何管理记忆？具体而言，**何时应该用整合（Consolidation）替代保留（Retention），以及应选择哪种整合算子（Merge、Abstract、还是 Rewrite）**。
- **背景**：语言智能体的历史记录（对话、检索事实）不能无限累积。有限的上下文窗口与推理成本构成了一个实际部署中的"token 预算"。现有系统主要依赖两种策略：
  - **保留（Retention）**：保留原始记录，保留准确措辞、时间戳、修正记录等，但 token 利用效率低下，预算紧张时相关证据可能无法全部容纳。
  - **整合（Consolidation）**：通过摘要、合并或重写生成紧凑的替代记录，提高每个 token 的证据覆盖率，但可能丢失关键细节、模糊时间顺序、丢弃修正或引入无根据内容。
- **核心洞见**：两种策略各有利弊、均非普遍最优。决策的关键在于**相对预算压力**——相关原始证据能否在预算内完整容纳，而不是一个固定的 token 阈值。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 2.1 统一形式化：四动作决策

- 将记忆保留与三种整合算子（Merge、Abstract、Rewrite）放入同一决策空间，目标为最大化条件期望答案效用。
- **合并（Merge）**：将多条笔记整合为一条紧凑的事实性记录。
- **摘要（Abstract）**：跨输入合成一条更高级别的笔记。
- **重写（Rewrite）**：独立改写每条笔记后按预算打包。
- 定义**整合增益**（Definition 1）：

$$\Delta_o(z) = u_o(z) - u_{ret}(z),\quad u_o(z) = u(q, R_B(q, T_{C,o,B}(M)))$$

即整合前后、同一检索器/预算/答案模型/评判器下的答案效用差。

- 最优策略（式 4）：

$$a^\star(z) = \begin{cases} ret & \text{若 } \Gamma(z) \le 0 \\ o^\star(z) & \text{若 } \Gamma(z) > 0 \end{cases}$$

其中 $\Gamma(z)$ 为最佳生成优势。**"何时"与"选择哪个算子"是同一个决策问题**。

### 2.2 机制模型：覆盖效应与替代效应（Proposition 1）

- 通过理想化代理效用 $U_B(M) = \mathbb{E}_F[s_B(q, M)]$，将每个算子的效用变化分解为两项：

$$\Delta U_{B,o} = C_{B,o} + R_{B,o}$$

- **覆盖效应（Coverage Effect）** $C_{B,o}$：整合生成的记录覆盖了保留策略遗漏的查询（$X_{B,o}$），在此区域保留贡献为零。
- **替代效应（Replacement Effect）** $R_{B,o}$：整合记录替换了原本已适应的原始证据（$J_{B,o}$），其符号取决于生成记录与原始记录的保真度差。
- 预算 B 缩小 → 保留策略的原始证据支持区域 $G_B$ 缩小 → 覆盖效应增强 → 整合更有利；预算 B 增大 → 替代效应主导 → 保留更有利。**该机制预测了实验中观察到的"交叉"现象**。

### 2.3 OAS（Offline Abstraction-Safety）：离线学习路由

- **核心思想**：生成的压缩记录及其效用是反事实的、在部署时不可观测。OAS 在离线阶段用相同检索器、预算、答案模型、评判器评估全部四种动作，得到每个动作的效用标签。
- **特征向量**：11 维，包含 7 个标量特征（归一化预算、证据条数、token 压力、预算拟合分数、会话数、不一致代理、平均余弦相似度）与 4 维查询类型独热编码。
- **效用估计**：为每个动作独立拟合岭回归响应，选择预测效用最高的动作；MLP 作为非线性容量对照。
- **风险校准**：在留出验证集上选择使"有害生成选择"为零的操作阈值（Calibrated OAS，实际上是一种保守的决策规则）；否则用 Direct OAS（阈值为零）。

## 6. 论文的主要结论与发现

- **预算交叉（Q1）**：预算紧张时整合明显优于保留（LongMemEval 上 Abstract 在 32 预算下比保留高 48.0 个百分点）；预算宽松时保留优于所有整合算子（8%–11%）。GLM-5.2 和全历史检索设置下均复现此反转。
- **算子选择（Q2）**：需要压缩时，**跨笔记的 Abstract 和 Merge 总体上优于局部 Rewrite**；但 Abstract 与 Merge 之间无统计显著差异，不构成普遍优劣。知识更新型问题中整合危害最集中。
- **路由学习（Q3）**：OAS 在受控评估的预算紧张场景中显著优于保留并取得路由收益；校准可减少有害选择但以部分效用为代价。
- **核心验证**：交叉现象由**相对预算压力**（证据长度与预算之比）而非绝对 token 阈值决定。LoCoMo 在更小预算下交叉与其较短证据一致，印证了 Proposition 1 的机制预测。
- **局限声明**：独立全历史评估中，OAS 的 full-history 变体未超越最强固定策略（Fixed Merge 45.7% vs Direct ridge 44.7% vs 回溯 oracle 50.3%）——受控评估支持可学习的 when–which 结构，但端到端可迁移路由尚未确立。
